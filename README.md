# 그루터기

사진과 영상을 가져와 날짜, 지역, 사람별로 보고 앨범과 일기로 기록하는 로컬 앱입니다. 원본 사진과 영상은 가져오기 및 위치 분석 과정에서 수정하지 않습니다.

## 가독성 개선 진행 상황

대상 브랜치: `feature/warm-journal-v2`

- 공통 글자 크기 기준을 만들고 주요 버튼, 탭, 입력 컨트롤의 높이와 줄바꿈을 조정했습니다.
- 달력의 날짜와 사진 개수를 키우고, 대표 사진을 더 큰 영역에 표시합니다. 일정은 한 건만 짧게 표시하고 나머지는 개수로 알립니다. 메모가 있는 날은 좁은 화면에서도 표시와 접근성 이름으로 구별합니다.
- 앨범 책 보기, 챕터·감상문, 사진 상세, 일기장, 날짜 검색, 사람·반려동물, 추억 지도의 작은 글자와 보조 색상을 조정했습니다. 모바일 앨범 책의 공간을 넓혀 사진과 촬영 날짜가 함께 보이도록 수정했습니다.
- CSS에서 11px 이하로 남긴 글자는 지도 출처와 앨범 표지의 축소 미리보기뿐입니다.
- 프런트엔드 빌드와 단위 테스트 85개를 통과했습니다. GitHub Actions의 브라우저 검증은 모바일 앨범 레이아웃 수정 후 다시 확인해야 합니다.

## 다음 작업

1. **모바일 앨범 책 보기 확인:** 사진 1·2·4장 배치에서 날짜와 캡션이 잘리지 않고 사진이 식별되는지 확인합니다. 특히 화면 폭 320~393px에서 페이지 넘김 버튼, 책 안쪽 여백, 가로 넘침을 확인하고 필요한 CSS만 보완합니다.
2. **달력 조합별 확인:** 사진 0·1·2~3·여러 장과 메모·일정이 함께 있는 날짜를 살펴봅니다. 대표 사진의 `cover` 자르기로 얼굴이 과도하게 잘리는 사례가 있으면 미리보기 정책을 조정합니다.
3. **화면 크기별 수동 점검:** 1080×720, 1440×960, 1920×1080 및 좁은 모바일 화면에서 앨범, 감상문, 사진 상세, 일기장, 검색/필터, 사람·반려동물, 추억 지도의 실제 표시를 확인합니다. 버튼·라벨 줄바꿈, 글자 잘림, 가로 넘침, 대비를 수정합니다.
4. **자동 검증 마무리:** GitHub Actions의 데스크톱·모바일 브라우저 시나리오와 기존 기능 흐름을 통과시키고, 실제 앱 화면에서 크게 보기 모드와 기본 크기를 비교합니다.

이번 가독성 작업에서 Windows 설치파일 및 실행파일은 만들거나 테스트하지 않습니다.

기존 설계와 구현 배경은 [`docs/`](docs/) 및 프로젝트 루트의 작업 로그를 참고하세요.
