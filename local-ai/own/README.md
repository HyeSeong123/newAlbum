# 곰고미 전용 AI

현재 기본 AI는 이 폴더의 자체 학습기와 `src/features/characters/ownAi/`의 자체 추론기다. 가중치를 무작위로 초기화하고 다음 단어를 학습한다. 순전파·역전파·학습 갱신도 `neural.py`에 직접 구현했다. 외부 사전학습 가중치·어댑터·토크나이저·추론 엔진을 사용하지 않고, 학습과 앱 실행 중 모델 API를 호출하지 않는다. 학습 문장에는 사용자 원문과 이 작업의 AI 개발 도우미가 작성한 초안이 포함된다. 이전 모델의 생성 시험 결과를 학습하거나 초안을 사람이 작성·승인한 자료라고 표시하지 않는다. PC에서 NumPy는 행렬 곱셈 같은 수학 계산에만 사용하며 앱에는 포함하지 않는다. 일반 앱 라이브러리인 React·Tauri 등은 별도다.

## PC 실행

### PC 학습실

Windows에서는 저장소 루트의 **`곰고미-AI-학습.cmd`**를 더블클릭하면 브라우저가 열립니다.
브라우저가 열리지 않으면 실행 창에 표시된 `http://127.0.0.1:…` 주소를 같은 PC에서 여세요.
학습이 진행되는 동안 실행 창을 열어 두세요. 브라우저만 새로고침해도 학습은 계속됩니다.

기존 학습용 `.venv`가 있으면 그대로 사용합니다. 처음 준비하는 PC에서는 Python 3.12 설치 후
아래 명령을 저장소 루트의 PowerShell에서 실행하세요. 패키지 설치에는 인터넷이 필요할 수
있으며, 준비 후 자료 입력과 학습은 PC 안에서 진행합니다.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r local-ai\own\requirements.txt
```

macOS/Linux에서는 준비한 Python 환경에서 `python local-ai/own/studio.py`로 실행하세요.
**대사 비교**를 사용하려면 Node.js와 저장소 의존성이 필요합니다. Node.js 설치 후 저장소
루트에서 `npm ci`를 한 번 실행하세요.

1. **학습 자료**에서 공유 모델 또는 도롱이 전용 모델을 선택하세요. 캐릭터, 행동, 친밀도,
   대사를 입력해 **예시 추가**를 누르거나 해당 모델의 UTF-8 JSONL을 가져오세요.
   평소 고미는 친밀도 60 미만에서 말없이 반응합니다. 이 상태의 말하는 예시는 추가할 수 없습니다.
   공유 모델 학습에는 기존 `user-examples.jsonl`도 포함됩니다.
2. **빠른 확인 · 1회**로 저장까지 되는지 확인하고, 필요하면 **기본 · 180회**로 학습하세요.
   반복과 손실값은 학습기에 표시된 수치입니다. 손실값은 대사의 자연스러움을 평가한 점수가 아닙니다.
   중지한 학습을 다시 시작하면 새 실행으로 처음부터 학습합니다.
3. **대사 생성**으로 화면에서 고른 조건의 기본 모델과 최근 완료 결과를 비교할 수 있습니다.
   새 행동 ID는 학습실에서 시험할 수 있으며 앱에서 사용하려면 해당 행동을 호출하는 버튼 연결이 필요합니다.

완료 결과와 실행 당시 추가한 예시는 `local-ai/runs/own-studio/<실행 ID>/`에 저장됩니다.
기본 앱 모델과 원본 자료는 이 화면에서 덮어쓰지 않습니다. 추가 예시 목록은 같은 브라우저 탭에서
새로고침해도 복원됩니다. 학습을 시작하면 실행 폴더에도 사본이 저장됩니다.
결과를 Android 앱에 쓰려면 검토 후 빌드에 별도로 반영해야 합니다.

### 기존 명령 메뉴

기존 `곰고미-AI-실행.cmd`의2번은 자체 모델을 처음부터 학습하고3번은 같은 자체 추론기로 반응을 생성한다. 메뉴의 어떤 항목도 외부 모델을 내려받지 않는다.

직접 명령:

```powershell
.\.venv\Scripts\python.exe local-ai\own\train.py --epochs 180
node scripts/prepare-own-character-ai.mjs
node scripts/own-character-ai.mjs --character gomi
```

학습기는 `src/features/characters/ownAi/model.json`을 내보낸다. 앱은 이 가중치를 검증해 Worker에서 단어별로 새 문장을 생성한다. 대사 목록을 검색해 고르는 경로와 실패를 감추는 고정 대사 대체 경로는 없다. 원문·옛 실험·가중치는 보관하지만 새 학습기나 앱에서 읽지 않는다.

현재 내부 ID는 `own-character-v3`, 형식은 `gomgomi-own-wordnet-v3`다. 두 번째 문장에서도 최근4단어 이력을 유지한다. 상황과 의도별로 학습한 연속3단어 연결 안에서 다음 단어를 신경망 확률로 생성해, 수면/간식에 놀이 말이 섞이는 경로를 차단했다. 완성 대사 목록을 고르거나 문장을 억지로 이어 새 문장처럼 만들지 않는다. 최대 두 문장·50자이며, 이 방식도 모든 한국어 표현의 정확성을 보증하지는 않는다.

최근12개 대사를 우선 피한다. 학습된 표현 수가 적어 모두 소진된 경우에도 최근3개는 피하면서 같은 상황 안에서 다시 단어를 생성한다. 두 탐색 합계 최대512회 순전파·700ms 안에서 종료하며 다른 행동이나 고정 대사로 바꾸지 않는다. 두 문장에서 같은 표현을 되풀이하는 경우도 걸러낸다.

## 이번에 반영한 고미 행동

사용자가2026-11-15에 알려준 기준을 우선했다. 자다가 간식/밥을 주면 눈을 게슴츠레 뜨고 멍하니 있다가 먹으러 오고, 너무 피곤하면 계속 잔다. 활력0은 극심한 피로,1은 졸림으로 구분한다. 수면 중 활력2이상도 졸린 상태로 처리한다. 고미 친밀도는0·20·30·60·90의5단계를 유지한다.

PC3번 메뉴에서 `간식 75 잠`, `간식 75 피곤`, `밥 75 잠`, `밥 75 피곤`을 비교할 수 있다. `잠`은 활력1, `피곤`은 활력0이다. 마지막 숫자로 활력을 직접 지정할 수도 있다(예: `간식 75 잠 0`). 앱에는 기존 간식 버튼을 사용하며 식사 감지나 별도 밥 버튼을 추가하지 않았다.

## 새 행동과 추가 자료

다음처럼 사용자 작성 자료를 JSONL로 만든다. 같은 행동의 말투·친밀도·상태별 예시를 여러 개 넣는 것이 좋다.

```json
{"characterId":"gomi","action":"greeting","affection":80,"mood":"calm","energy":3,"sleeping":false,"reply":"집사, 왔으면 내 옆에 있어."}
```

```powershell
.\.venv\Scripts\python.exe local-ai\own\train.py --extra 나의자료.jsonl
node scripts/prepare-own-character-ai.mjs
```

새 행동 ID가 모델에 자동으로 등록된다. 앱에서 새 행동을 누르는 버튼을 추가할 때 그 ID를 전달한다. 등록되지 않은 행동은 학습되지 않았다고 실패하며 다른 행동으로 몰래 바꾸지 않는다. 모델의 어휘와 표현 범위는 제공한 자료에 한정되며, 자유로운 범용 한국어 대화 능력을 갖췄다고 주장하지 않는다.

PC **5번**은 `local-ai/own/user-examples.jsonl`을 메모장으로 연다. 저장 후 **2번**을 누르면 새 자료도 포함해 다시 학습한다. 이 개인 추가 자료 파일은 Git에서 제외한다. 한 줄에JSON 하나를 넣고 행동·친밀도·수면·활력별로 일관된 짧은 대사를 여러 개 적는다. 상반된 뜻은 `meaning`을 구분한다. 이 값은 의도별 단어 연결을 구분하는 학습 표지다.

```json
{"characterId":"gomi","action":"treat","affection":75,"sleeping":true,"energy":1,"meaning":"drowsy-snack-approach","reply":"간식이야? 잠깐만, 나도 갈게."}
{"characterId":"gomi","action":"treat","affection":75,"sleeping":true,"energy":0,"meaning":"exhausted-skip-snack","reply":"너무 졸려. 간식은 나중에 줘."}
```

위 예시는 이 작업의 AI 도우미가 쓴 초안이다. 사용자가 더한 파일이라는 이유로 모든 문장을 사람의 원문이라고 표시하지 않는다. 추가한 새 행동·상태에 학습된 연결이 없으면 `AI_SCENE_UNTRAINED`로 실패하므로 실제 사용할 상태별 자료도 추가해야 한다.

## 계보와 배포

- `corpus.json`: 실제 사용 자료·제외 사유·원본 해시. 기존 원문 파일은 수정하지 않는다.
- `action-drafts.json`: 새 초안의 저자·출처. 외부 모델 출력에서 증류한 자료가 아니다. 사용자 검토 완료 자료로 표시하지 않는다.
- `training-result.json`: 무작위 초기화·부모 모델 없음·학습 코드/자료 해시·실제 학습 시간.
- Android 배포 검사는 외부 캐릭터 GGUF/LoRA와 llama/ggml 추론 라이브러리의 부재 및 자체 가중치 해시를 검사한다.

갤럭시26의 목표는 행동 후 문장 전체가1초 안에 표시되는 것이다. PC·에뮬레이터 측정을 실기기 결과로 대신하지 않는다. 기존 사진의 얼굴·반려동물 인식은 별도 모델·권리 기록이며 자체 캐릭터 AI를 만들었다고 앱 전체의 권리 문제가 해결됐다고 표시하지 않는다.
