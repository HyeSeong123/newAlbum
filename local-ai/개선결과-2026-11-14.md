## 남은 품질 한계와 출력 검사

검사 전 원시 생성의 보수적 에이전트 평가: 새15개 장면에서 HF11/15, Q4 native7/15. 한국어/역할/장면/조건/성격을 따로 읽었으며 사용자 독립 평가는 아니다. 이전16개 진단셋의 Q4는 이번에도9/16이었다. 전체 의미 품질이 좋아졌다고 이 숫자로 주장하지 않는다. 이 결과를 참고해 정책을 보완했으므로15개도 이후에는 개발 진단 자료로 취급한다.

앱에는 확실한 간식 제공자 역전, 자기 이름을 상대처럼 부르는 출력, 일부 명확한 동사 활용 오류와 수면 우선순위 위반을 검사하는 작은 규칙을 추가했다. 어긋나면 같은 로컬 모델에 이유를 알려 최대3회 새로 생성한다. 준비된 대사로 바꾸지 않는다. 검사도 실패하면 기존 홈의 오류 상태를 표시한다. 이 검사는 전체 한국어 문법이나 성격을 보증하는 판정기가 아니다. 원시 실패 출력과 시험 내역을 `quality-v3/`에 보존했다.

## 앱 용량과 연결

모델은 HyperCLOVAX-SEED-Text-Instruct-0.5B(약0.57B)에 학습 어댑터를 병합한 Q4_K_M **368,181,952바이트**다. SHA256 `76ca3369dcf9dea018eff58f3f5762506cac380b1c94fff2b72cd01851827934`. 기존 기본 모델이나 어댑터 없이 실행한다.

`models/gomi-action-v3/runtime.json`을 기준으로 새 Android 빌드에 포함하도록 연결했다. 고미의 홈 행동에서만 적용하며 별도4B 다운로드나 옛 v4 LoRA를 사용하지 않는다. 다른 캐릭터·자유 입력 경로는 기존 공유 모델을 유지한다. 앱에 PC Python/CUDA 환경이나 학습 자료는 넣지 않는다. Android는 모델을 검증한 뒤 앱 전용 파일에 설치하므로 APK 외에 모델용 저장 공간도 필요하다.

기본 반응은 문장을 생성한다. 새 행동은 작은 행동 레지스트리와 앱 버튼을 확장할 수 있다. 앱이 실제 추위·아픔·방문객을 감지하는 기능을 추가한 것은 아니다.

필수 라이선스·NOTICE·파생 모델 조건을 함께 포장했다. 해당 모델은 Apache-2.0가 아닌 HyperCLOVA X SEED Model License Agreement를 따른다. 앱에는 Powered by 표시를 넣었다. 의미 품질·실기기 성능·공개 출시 승인은 여전히 별도다.

## APK와 브랜치

설치 버전은0.9.52로 올렸고 기존 패키지 ID·영구 서명키를 유지한다. GitHub Actions가 저장소 Secrets의 기존 키로 서명하고 실제 APK의 모델·고지·인증서, Android 에뮬레이터의 오프라인 native 실행을 최종 검증한다. 실제 빌드 결과와 APK 경로는 작업 폴더 `outputs`의 완료 보고에 기록한다. 소스 연결을 APK 생성 성공으로 표시하지 않는다.

삭제 전 모든 Git 이력을 검증한 번들에 보존하고 개인키 파일이 브랜치에 없는지 확인했다. 원격6개 브랜치를 예상 HEAD 일치 조건으로 삭제했으며, 원격·로컬 모두 `final`, `master`만 남겼다. 복구 번들과 삭제 증거는 `outputs/newAlbum-branches-before-cleanup-2026-11-14.bundle`, `outputs/branch-cleanup-2026-11-14.json`에 있다. 병합하지 않은 다른 프로젝트 변경을 final에 임의 합치지 않았다.

사용자 요청에 따라 중간 재검증·추가 비교 실험을 중단하고 남은 변경의 최종 검증과 APK 빌드로 마무리한다.
