# 0.9.23 캐릭터 버튼 도움말

## 기존 UX와 변경 이유

기획자 관점에서 이전 주제별 도움말은 실제 버튼과 설명을 연결하지 못했다. 일반 사용자는 설명을 닫은 뒤 어떤 버튼을 눌러야 하는지 다시 찾아야 했다. 기능별 별도 도움말도 진입 위치와 말투가 일관되지 않았다. 기존 화면을 유지하고 실제 버튼 하나를 밝히는 공통 안내로 교체했다.

## 공통 구조와 보존 사항

- `HelpProvider`: App의 화면·인물/반려동물 탭·선택 상태와 현재 활성 팝업/메뉴를 연결한다. 우측 하단 48px `?`를 표시하고 주변 조작부와 충돌을 피한다. 사용자가 요청하기 전에는 시작하지 않는다.
- `helpContent`: 의미가 등록된 실제 활성 DOM 컨트롤만 수집한다. 숨김·비활성 버튼과 배경 화면의 버튼은 제외하고 반복 항목은 하나의 단계로 안내한다. 기존 FunctionHelp의 설명은 숨겨진 데이터로 공통 안내에 연결한다.
- `HelpOverlay`: 검정 82% 배경과 실제 버튼 위치의 구멍, 부드러운 테두리, 이전/다음/건너뛰기/종료/단계 표시. 배경은 inert 처리하여 삭제·저장·탭 전환을 실행하지 않는다.
- `helpGeometry`: 좌우 여유 공간을 우선하고 부족하면 상하 배치한다. ResizeObserver, scroll, visualViewport 변화에 대응하고 화면 밖 대상은 스크롤한다.
- `helpDialogue`: 기능 설명은 고정하고 캐릭터별 5개 친밀도 말투를 선택한다. 기존 17종, 이름, 성장 단계, 호감도 경계 0·20·30·60·90과 CharacterVisual 리소스를 재사용한다. 열람으로 교감이나 호감도 저장을 호출하지 않는다.

SQLite/API/인식 모델/사진 원본/앱 ID/영구 서명키 변경은 없다. 기존 고미의 교감 단계와 성장 조건도 유지한다. 도움말 종료 시 원래 스크롤, 포커스, 선택과 작성 중 입력을 보존한다.

## 화면 연결

| 범위 | 안내 대상 |
|---|---|
| 인물·반려동물 | 탭, 등록, 감지, 미확인 검토, 이름, 사진 연결, 분석 상태, 결과 수정 |
| 사진 목록·즐겨찾기 | 검색·필터, 날짜, 사진 열기, 선택·전체 선택·해제, 앨범 만들기, 내보내기, 삭제 |
| 사진 상세·확대 | 제목, 저장, 하트, 별점, 사진 이동, 배율, 지역 지정, 삭제 |
| 앨범 | 만들기·편집·표지색·사진 관리·저장·보기·삭제 |
| 일기 | 작성·날짜·제목·내용·날씨·기분·사진·앨범 연결·저장·삭제 |
| 추억·지도·달력 | 각 보기 전환과 실제 존재하는 날짜·기록·지역 조작부 |
| 홈·도감·설정 | 실제 홈 바로가기·교감·도감·대표 변경·이름·관리 동작 |
| 팝업·메뉴 | 가장 위 계층의 입력·저장·취소 등 활성 조작부만 안내 |

정적 설명은 가져오기 방식 소개, 앨범 편집 소개, 일기·도감·설정의 중복 소개에서 간소화했다. 오류, 저장 결과, 분석 상태, 빈 상태의 필수 다음 행동, 저장 공간과 원본 보존·데이터 손실 안내는 남겼다. 사용할 동작이 없는 화면은 버튼을 만들어 설명하지 않고 짧은 빈 안내를 제공한다.

## 검증 범위

Node 테스트는 17종×5단계 대사, 정보 불변성과 경계, 작은/가로/이동된 viewport의 비중첩 배치를 검증한다. 브라우저 테스트는 실제 React 화면과 버튼을 사용하며 네이티브 파일·DB 호출만 fixture로 대체한다. 도움말 후 실제 제목 저장/사진 이동, 인물·반려동물 선택·이름 저장, 메뉴·팝업 복귀와 파괴적 작업 차단을 확인한다.

Android의 실제 설치·갤러리·원본 보존·사진 선택·인식은 별도 Actions 에뮬레이터 게이트에서 검증한다. 최종 실행 결과는 전달 보고서에 기록한다. 브라우저의 모바일 viewport 검증을 실기기 검증으로 간주하지 않는다.

실제 TalkBack 음성·스위치 접근, 사용자의 물리 Android 휴대폰(키보드/제스처/디스플레이 컷아웃), Windows 네이티브 설치·업데이트, 실제 초보 사용자 연구는 별도 검증이 필요하다. 임의의 아직 등록하지 않은 새 컨트롤에는 기능을 추측하는 설명을 만들지 않으므로 새 기능 추가 시 Registry와 테스트도 연결해야 한다.
