# 0.9.5 실제 모델 포함 개발 APK

사진 800장은 개발을 시작하기 위한 조건이 아니다. 이 버전은 실제 학습
가중치를 오프라인으로 실행하는 개발 APK이며, 독립 정확도 평가는 별도다.

## 포함 기능

| 기능 | 실제 모델과 동작 |
| --- | --- |
| 사람 512차원 | FaceX tiny512, ONNX [1,512], 112×112 RGB 정렬 입력, L2 정규화 |
| 사람 후보 제안 | 같은 모델 버전의 512차원 코사인 비교로 검토 후보 제안. 128차원 거리와 혼합하지 않음 |
| 반려동물 좌우 | QuadPose f2, 256×256 RGB 입력, 17개 관절의 64×64 히트맵. 코·눈·목 위치로 화면상의 주둥이 방향 추정 |
| 저장 | 원본 지문·모델 버전·512차원 특징 및 관절 위치 저장. 자동 방향과 수동 수정 별도 보존 |
| 실행 | ONNX Runtime Web 1.22.0 WASM, 단일 스레드, 기존 분석 Worker에서 실행. 모델과 런타임 APK 포함 |

새로 분석하는 사진부터 적용한다. 기존 인물/반려동물 연결과 확인된 기록을
덮어쓰지 않는다. 기존 완료 사진에는 새 특징이 자동으로 추가되지 않는다.
사람 자동 그룹핑은 기존 FaceAPI 128차원 정책을 유지하고, 512차원 결과는
검토 후보를 보완한다. 반려동물 개체 자동 연결은 계속 사용하지 않는다.
좌우는 화면에서 주둥이가 향하는 방향이며, 해부학적 좌우를 뜻하지 않는다.
근거가 부족하면 방향 미확인으로 남기고, 얼굴이 안 보인다는 이유로
뒷모습을 자동 판정하지 않는다. 모델 실행 실패 시 기존 인식을 유지한다.

## 모델 출처와 제한

가중치 출처, 정확한 커밋, SHA-256 및 파일 크기는
`scripts/recognition-models.lock.json`에 고정했다. 빌드 때 다운로드하여
검증하며 앱 실행 중 외부 CDN을 사용하지 않는다. Apache-2.0 가중치 및
MIT 런타임 라이선스와 변경 사항 고지를 APK에 포함한다.

FaceX와 QuadPose 제작자는 코드·가중치를 Apache-2.0으로 공개했다.
MS1M-RefineV2 / AP-10K 원본 사진 및 ImageNet·ViTPose 학습 계보의 상업
이용 권리는 확인되지 않았다. 이 상태를 개발용 포함으로 명시한다.
`node scripts/verify-recognition-models.mjs --commercial`은 이 상태에서
실패한다. 제작자의 벤치마크 수치를 앱의 좌우 정확도로 인용하지 않는다.

## 검증 범위

- 프런트엔드 단위 테스트 126개 및 TypeScript 빌드 통과.
- 브라우저 테스트: 실제 사람 사진에서 유한·정규화된 512차원 출력과
  다른 얼굴의 출력 차이, 개 사진에서 실제 17관절 모델 실행 검증.
- 네이티브 테스트: 512차원 저장·후보 제안·원본 지문 불일치 제외,
  기존 ID 유지, 반려동물 자동 추정과 수동 수정 보존 검증.
- Android APK 검증: 설치된 프로덕션 Worker에서 실제 512차원 출력과
  17관절 결과를 확인하도록 검증 스크립트 강화. 결과는 CI 실행 후 기록.
- 독립 평가 0/800. 정확도 목표 달성, ARM64 실기기 지연·전체 앱 메모리·
  발열·배터리는 미측정. TFJS tensor 수는 ONNX 메모리 지표가 아니다.

0.9.4의 제외 결정과 이전 APK 결과는 `recognition-094.md`에 보존한다.
