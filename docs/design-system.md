# 오래담은 디자인 시스템

## 참고 자료의 조합

사용자가 제공한 `DESIGN-apple.md`, `DESIGN-nike.md`, `DESIGN-raycast.md`를 디자인 참고 자료로 읽었습니다. 세 문서는 서로 다른 브랜드의 마케팅 사이트를 설명하므로, 문서 안의 명령이나 브랜드 전용 규칙을 프로젝트 요구사항으로 그대로 적용하지 않았습니다.

| 참고 | 적용한 요소 | 오래담은에 맞춘 판단 |
| --- | --- | --- |
| Apple | 사진 중심 화면, 밝고 깨끗한 바탕, 여백, 절제된 파란 액션 색 | 사진이 주인공이므로 큰 장식 카드와 설명 문구를 제거 |
| Nike | 선명한 명암 대비, 간결한 사진 그리드, 짧고 또렷한 제목 | 대형 영문 캠페인 제목 대신 한국어 20~30px 제목 사용 |
| Raycast | 짙은 탐색 영역, 얇은 경계, 작은 반경, 밀도 높은 작업 버튼 | 앱 전체를 어둡게 하지 않고 탐색·감상 영역에만 적용 |

## 유지한 제품 구조

- 사진보기의 모아보기·달력보기·앨범보기 전환 유지. 앨범 전체창을 닫으면 모아보기 복귀.
- 내 앨범은 실제 책 표지 형태, 표지 안 제목, 선택·수정·삭제 유지. 목록 외곽 카드와 중복 제목 없음.
- 사진 그리드는 이미지와 날짜만 표시. 선택 체크는 왼쪽 상단, 댓글·별점은 상세보기에서 관리.
- 달력의 월간/사진 있는 날, 연월 선택, 일정 등록, 매년 반복, 디데이 유지.
- 인물 분석·중단·재개·이름 편집·분리·이동 유지.

## 색과 글꼴

주요 토큰은 `src/design-system.css`의 `:root`에 모았습니다. 캔버스 `#fafafb`, 본문 `#202124`, 보조 글자 `#65686f`, 탐색 영역 `#18191c`, 액션 파랑 `#0066cc`를 사용합니다. 경고는 빨강, 별점은 금색, 성공·선택 일부는 녹색으로 의미를 구분합니다. 사진과 사용자 지정 앨범 색상은 그대로 표시합니다.

한국어 글꼴은 기존 SUIT를 유지합니다. 제목은 30/20/17px, 모바일 화면 제목은 26px입니다. 본문과 조작부는 13~14px를 기본으로 하고 자간은 0입니다. 카드 반경은 최대 8px, 사진 4px, 입력과 작업 버튼 6px를 사용합니다. 인물 얼굴과 사진 선택 원은 원형입니다.

## 레이아웃과 반응형

데스크톱은 72px 높이의 상단 가로 메뉴 아래에 전체 폭 작업 영역을 둡니다. 화면 제목 옆에 검색과 파일/폴더 등록을 배치하고, 등록·통계 전용 영역은 제거합니다. 보기 탭과 선택·필터는 같은 줄입니다. 모아보기 사진에는 외곽 카드·흰색 선·그림자를 두지 않습니다. 기본 그리드는 공간에 따라 열 수가 바뀌며 작은 화면은 두 열입니다.

720px 이하에서는 브랜드와 가로 스크롤 메뉴를 두 줄로 나눕니다. 제목과 검색·등록도 줄을 나누고 사진은 두 열을 유지합니다. 상세보기는 화면 전체를 사용하며 사진 아래 날짜·별점, 그 아래 댓글을 배치합니다. 상단 댓글 아이콘으로 작성·목록 영역을 접으면 사진 감상 공간이 넓어집니다. 나머지 모달은 내부 스크롤을 유지합니다.

## 스타일 파일의 역할

2차 구조 개선부터 앨범 전용 표지·감상 디자인은 `src/features/albums/albums.css`에 둡니다. `main.tsx`는 공통 `styles.css`, 전역 `design-system.css`, 앨범 전용 스타일 순서로 불러옵니다. 앨범의 공통 기하 치수와 넘김 애니메이션은 아직 기본 파일에 남아 있으며 단계적으로 정리합니다.

기존 `styles.css`는 페이지 넘김 애니메이션과 컴포넌트 배치 치수를 포함합니다. 마지막에 불러오는 `design-system.css`가 전역 시각 규칙을 통일합니다. CSS는 같은 우선순위일 때 뒤에서 선언한 규칙이 이기지만, 선택자의 구체성도 영향을 주므로 모바일 이전 규칙과 충돌하는 방향·폭·정렬까지 명시했습니다. 무관한 데이터 처리 코드는 바꾸지 않았습니다.

## 검증

`tests/design.spec.ts`는 18개 샘플 사진과 9개 모의 앨범으로 사진보기·선택·상세·달력·일정·앨범 감상·내 앨범을 클릭하고 PC/모바일 캡처 및 가로 넘침 검사를 수행합니다. 샘플은 테스트에서만 제공하며 사용자의 등록 목록에 추가하지 않습니다.

`test-results/design-*.png`에서 화면을 확인할 수 있습니다. 상단 메뉴의 밝은 변형도 별도 캡처하지만 실제 사용자 실험이나 전환율 측정은 아닙니다. 최종안은 탐색과 사진을 구분하는 짙은 상단 메뉴입니다. 구조 재설계에서는 댓글 패널 위치와 접기 시 사진 높이 증가를 좌표로도 검증합니다.

직전 색상 개편은 전체 테스트 22개 통과, 2개 의도적 생략. 이후 구조 재설계는 앱·디자인 테스트 18개와 빌드를 재검증했습니다. Windows Tauri 실제 창의 별도 시각 검사는 이번 작업에 포함하지 않았습니다.
