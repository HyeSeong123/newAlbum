# 0.9.9 반려동물 화면과 요청 기반 분석

- 사진 가져오기, 신규 반려동물 등록, 이름·사진 수정은 사진/연결만 저장한다. 앱 시작 시 이전 대기열은 읽어서 안내하며 자동으로 실행하지 않는다.
- 최초 반려동물을 등록한 뒤 `등록된 사진에서 찾기 → 사진 찾기 시작`, 더보기의 재학습, 또는 `이어서 분석`으로 사용자가 요청해야 분석한다. 기존 오프라인 Worker, 결과 캐시 및 영구 대기열을 사용한다.
- 목록은 등록/찾기, 상세는 수정/찾기를 중심으로 표시한다. 재학습과 삭제는 상단 더보기에 모았다. 상세의 사진 직접 등록은 수정 화면으로 통합했으며, 저장 시 자동 분석 이벤트를 제거했다.
- 분석 상태는 현재 화면에 한 번만 표시한다. `반려동물 확인`은 현재 화면과 관계없이 실제 결과 선택 창을 연다. 사진 찾기를 실행하지 않고 저장된 후보부터 확인할 수 있다.
- 결과는 개체별 영역을 보여 준다. 여러 후보, 현재 페이지 전체, 다른 페이지의 후보를 함께 선택하고 `선택한 사진 연결`로 저장한다. 일부 저장이 실패하면 완료한 연결을 유지하고 남은 선택을 재시도할 수 있다. 여러 동물이 나온 사진은 선택한 개체만 확정한다.
- 버튼, 알림, 사진 카드의 모서리·여백·색을 기존 따뜻한 톤에 맞췄다. 선택 버튼은 눌림 상태를 전달하고 모바일 세로 스크롤을 유지한다.

검증: `pet-review.spec.ts`, `manual-photos.spec.ts`, `pets.spec.ts`, `media-import.spec.ts`, `mutations.spec.ts`, `mobile-polish.spec.ts`, `people-controls.spec.ts`. 안드로이드 설치 검사는 등록 직후 분석 결과/대기열이 없는지 확인한 뒤 사진 찾기를 직접 시작한다.
