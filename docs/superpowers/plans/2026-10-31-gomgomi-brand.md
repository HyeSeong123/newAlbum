# 곰고미 이름·로고 적용

사용자가 앱 이름을 감자싹에서 곰고미로 바꾸고 웃는 고미를 로고로 지정했다. 이는 구체적인 승인된 변경 요청이며 재승인 없이 적용한다. 기준 final/ac5d31d, 앞선 학습 작업 파일은 보존한다.

- [x] 기존 고미 happy.png의 외형·색연필 질감을 확인했다. 내장 이미지 생성 도구로 같은 웃는 얼굴·귀만 있는 투명 정사각형 로고를 만들었다. 고미 캐릭터 원본 파일은 보존한다.
- [x] 앱 헤더를 웃는 얼굴 + 실제 텍스트 곰고미로 바꾼다. 브라우저 title/favicon, Android/Windows 표시 이름·실행 아이콘·네이티브 사진 선택 화면·관련 안내를 일치시킨다.
- [x] 기존 Android ID com.oraedameun.album.next, Windows ID com.oraedameun.album, binary gamjassak, NSIS 설치 registry identity 그루터기, localStorage/DB/서명 설정을 보존한다. 감자 캐릭터 자체의 이름 감자싹은 변경하지 않는다. Windows 기존 감자싹 바로가기 정리는 기존 IsShortcutTarget 보호 매크로로만 수행한다.
- [x] 기존 브랜딩 UI 검사에서 새 이름/얼굴 자산을 검증하고 모바일320/393 및 데스크톱에서 로고 클릭·폭 넘침·첫 안내·이전 일기를 확인한다. 프런트 빌드와 영향 범위 Android 검사도 수행한다.
- [x] 두 변경·검증 뒤 학습 진행량을 한 번 확인해 보고한다. 학습 파일을 변경하거나 GPU 학습을 중단하지 않는다.

기획자: 좁은 헤더에서도 얼굴과 이름이 함께 보이고 기존 홈 이동 버튼 역할을 유지한다. 사용자: 처음 안내·설정·원본 보존/삭제 안내에서 같은 앱 이름을 보며, 로고를 눌러 홈으로 돌아올 수 있다. Android APK/Windows 설치본의 실제 빌드·설치는 별도 검증이며 하지 않았다면 보고한다.

최종: 프런트 빌드 통과, UI4개/영향 단위30개 통과, 별도 검토 중요 지적 없음. 모바일과 데스크톱 렌더링·로고 클릭·기존 일기/첫 안내 보존을 확인했다. 초기 의존성 누락·첫 개발 서버 로딩 시간 초과·단위 검사 임시 경로 접근 제한은 원인을 확인하고 각각 복원/준비 후 재실행/권한 재실행으로 해결했다. 변경 완료 뒤 학습115/117단계 확인. [변경 결과와 미검증 범위](../../gomgomi-brand-2026-10-31.md)에 기록했다.
