# 조용한 AI 반응·수면 교감·표지 여백

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans.

**Goal:** 홈 생각 중 표시를 완전히 없애고 수면 중 행동·기분·친밀도를 일치시키며 모바일 표지 사진과 제목 사이 간격을 확보한다.

**Architecture:** 기존 Qwen3 응답은 같은 말풍선에서 조용히 교체한다. 고미의 실제 수면 자세를 기분·반응·AI 문맥의 기준으로 사용한다. 친밀도 변화는 기존 IPC와 SQLite 트랜잭션으로 저장하며 DB v21에 추가 원장만 만든다.

**Spec:** 이 대화의 최신 사용자 요청. ‘생각 중’ 문구는 지연 표시가 아니라 완전 제거한다. 기존 사진·앨범·일기·캐릭터 ID·원본 그림·AI 모델·서명은 유지한다.

## 결정

- 잠든 고미에게 산책·간식·쓰다듬기·놀이를 요청하면 잠든 자세에서 짜증을 낸다. ‘함께 쉬기’는 다시 편히 잠들게 한다.
- 잠을 방해하는 행동은 친밀도 -1, 하루 최대 -3, 최소 0이다. 가벼운 터치 두 번은 수면을 유지하고 친밀도를 올리지 않는다. 세 번째부터 수면 방해에 포함한다.
- 깨어 있을 때의 하루 한 번 친밀도 +1은 별도로 유지한다. 반응 대사와 AI는 저장된 실제 친밀도를 사용한다.
- 모바일 표지 사진은 제목 위에 최소 8px 여백을 둔다. 두 열·44px 더보기 조작은 유지한다.
