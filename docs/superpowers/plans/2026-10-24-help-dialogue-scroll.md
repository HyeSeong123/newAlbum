# 도움말 위치·대사 정비

**목표:** 스크롤된 실제 버튼과 강조 표시를 일치시키고, 현재 캐릭터 성격과 호감도에 맞는 설명/대화 변주를 제공한다.

기획자 기준은 기능 설명의 정확성·화면 좌표의 일치·선택 캐릭터의 일관성이다. 사용자 기준은 내리던 화면에서 도움말을 열어도 같은 버튼을 가리키고, 닫으면 원래 위치·입력·선택으로 돌아오며 같은 한마디가 계속 반복되지 않는 것이다.

- [x] 위치: 내부 잘림 재현과 부모 영역 측정·다음 프레임 좌표·공통 오버레이 원점 반영. 기존 강조를 위치 변경 중 숨김.
- [x] 도움말 대사: 17종 × 5단계 변주와 고미의 작업별 대사. 최초 단계별 문장을 보관하여 이전/다음·크기 변경·단계 제거 때 유지.
- [x] 고미 대화: 기존 5단계를 유지하며 일상 40개·상황 40개 추가. 하루 인사·수면 반응·호감도 규칙 유지.
- [x] 검증 준비: 좌표/대사 단위 26개 통과, 타입/웹 번들 통과. 스크롤·수평 목록·대사 재방문 브라우저 시나리오 준비. 리뷰의 빈 도움말 반복 갱신과 이전 강조 잔류를 수정.

초기에는 커밋·APK를 보류했다. 2026-10-25 후속 요청에서 전체 수정의 커밋과 APK 생성을 명시했으므로 0.9.26으로 묶어 업로드한다. 실제 UI·Android 결과는 원격 검사 뒤 기록한다. DB·원본·인식 모델·캐릭터 외형은 이 도움말 작업에서 변경하지 않는다.
