# 사람·반려동물 조작 정비 계획

> 실행: 현재 작업 공간에서 직접 수정한다. 앞선 화면 변경을 보존하고 커밋·푸시·APK는 만들지 않는다.

**목표:** 사진이 중심인 기존 화면 안에서 버튼의 목적·묶음·우선순위를 맞춘다.
**구조:** React/TypeScript의 기존 목록·상세·공통 편집창을 보완한다. 인식 엔진·큐·DB·원본 파일의 처리 규칙은 유지한다.
**기준:** AGENTS.md, 개발 단계 경량 검증 정책, 기존 따뜻한 종이/올리브 토큰. 사용자가 화면 정비 판단을 위임했으므로 추가 디자인 승인 없이 진행한다.

## 기획자와 사용자 관점

- 목록: 추가/더보기는 제목 옆, 찾기와 미확인 확인은 관련 작업끼리 묶는다. 선택 중에는 다른 작업과 정렬을 접는다.
- 상세: 사진 연결·이름 변경을 가까이 두고, 사진 선택과 얼굴 선택의 범위를 구별한다. 대표 사진 선택은 별도 상태를 표시한다.
- 선택: 취소 → 선택 범위 → 적용 작업 순서의 공통 하단을 사용한다. 삭제/제외를 위험색으로 구분한다.
- 편집: 저장을 강조하고 닫기/X/뒤로가기는 수정 중인 내용을 확인한 뒤 버린다. 오류에서는 초안을 유지하고 저장 후 조회 실패를 재저장으로 처리하지 않는다.
- 모바일: 최소 44px, 6px 작업 버튼/8px 카드, 긴 이름과 글자 확대, 내부 스크롤, 고정 도움말 간격을 확인 대상으로 삼는다.

## 작업

- [x] 공통 선택 표시와 이름 지정창: 한국어 수량 단위, 빈 기존 대상 선택 방지, 초안 보호. SSR 2개 실패 재현 → 통과. 취소 정책은 실제 UI 검사로 준비했다.
- [x] 사람·반려동물 목록/상세: 상태별 버튼 묶음, 중복/무의미 버튼 정리, 미확인 선택을 공통 하단으로 이동, 상세 복귀 초점.
- [x] 편집/후보/진행 화면: 저장·취소 동작, 3버튼 푸터, 선택/진행 중 잠금, 공유 스타일과 도움말.
- [x] TypeScript·관련 단위 29개/저장소 8개·프런트엔드 번들 검사 및 변경 diff 검토. 브라우저 31개 수집만 확인했다. 실제 브라우저/Android 확인은 사용자가 정한 묶음 커밋 시점까지 보류한다.

별도 읽기 전용 소스 리뷰에서 구체적인 중대/주요 회귀 없음. 실제 화면 합격으로 간주하지 않는다. 상세 근거는 `docs/people-pets-controls-review-2026-10-24.md`에 기록했다.

## 버튼별 기대 동작

| 상태/행동 | 피드백/결과 | 취소·실패 |
| --- | --- | --- |
| 목록에서 선택 | 추가·찾기·정렬을 접고 범위와 선택 하단 표시 | 취소하면 목록/상세 그대로 |
| 미확인 인물 묶음 선택 | 얼굴 개수와 이름 지정·제외를 하단에 표시 | 대상과 원본 보존 |
| 이름/사진 수정 후 닫기 | 버림 확인 | 거절하면 이름·사진 선택 그대로 |
| 저장 | 저장 중 표시, 중복 제출 차단 | 실패 시 초안 유지, 저장 완료 후 조회 실패는 조회만 재시도 |
| 반려동물 감지 진행 | 기존 큐의 진행/중단 표시 | 중복 감지 시작 차단, 탭 이동으로 중단하지 않음 |

## 검토 집중점

등록 대상 0명, 이름 없는 인물, 긴 이름/320px, 미확인 목록 선택 중 탭 이동, 저장 성공 후 조회 실패, 사진 선택/대표 선택 중 뒤로가기를 집중 확인한다. 실제 시각·키보드·Android 확인은 실행 근거 없이 통과라 쓰지 않는다.
