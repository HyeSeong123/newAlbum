# 캐릭터 자유 대화 구현 계획

**Goal:** 기존 교감 기능에 로컬 AI 자유 대화와 사용자 첨부 캐릭터 그림을 연결한다.
**Architecture:** React 대화창 → 허용된 Tauri 명령 → Android Kotlin → 고정 버전 llama.cpp JNI. 모델은 전 캐릭터가 공유하고 첫 다운로드 이후 오프라인 실행한다. 캐릭터 ID·성장·친밀도·사진·일기·서명은 보존한다.
**Spec:** 사용자 최신 요청과 `docs/companion-ai-home-0.9.27.md`의 후속 구현. Android 스마트폰 RAM 8GB 이상. 별도 서버·API 키를 추가하지 않는다.

## 작업
- [x] 첨부 원본을 로컬 에셋으로 포함하고 SVG viewBox로 각 캐릭터만 표시한다. 한글은 4616, 고구마는 4613, 감자는 4615 우측 그림이다. 저장 ID와 6단계 성장 상태는 유지한다.
- [x] 캐릭터별 대화 기록 검증·최대 길이·문맥 구성·중단·저장 실패를 단위 검증한다. 사진·GPS·일기 본문을 프롬프트에 자동 포함하지 않는다.
- [x] 홈 ‘대화하기’와 키보드/뒤로가기/포커스 복구 가능한 대화창을 구현한다. 모델 미준비·다운로드·실패·중단·재시도를 구분한다. 생성 실패를 실제 AI 답변으로 표시하지 않는다.
- [x] 고정 Qwen3 1.7B Q4_K_M 다운로드, SHA-256/크기 검증, 임시 파일/완료 파일 분리, 취소, 8GB 확인, 단일 JNI 추론·시간/토큰 제한·중단/메모리 반환을 연결한다.
- [x] Android 준비 스크립트에 Kotlin/CMake 배선을 멱등적으로 추가하고 라이선스 안내를 포함한다. 새 서명키·DB 마이그레이션은 만들지 않는다.
- [x] 관련 단위·프런트 빌드·모바일 버튼/전후 화면을 검증한다. Android SDK/실기기가 없으면 네이티브 빌드·8GB 실측은 미검증으로 명시한다.

## 중점 검토
- 닫기/화면 이동 중 완료된 오래된 응답이 다른 캐릭터의 기록을 덮지 않아야 한다.
- 다운로드 취소·잘린 파일·오프라인 실패가 준비 완료로 표시되지 않아야 한다.
- 손상/사용 불가 저장소와 빈 입력, 과도한 입력을 처리한다.
- 대화와 활동은 기존 하루 한 번 친밀도 규칙을 바꾸지 않는다.
- 이미지 시트의 다른 캐릭터가 보이지 않으며 작은 Android 화면에서 입력창이 넘치지 않아야 한다.

## 판단
기존 지역 코드 KR-46은 전남·광주 통합 코드다. 새 지역/캐릭터 ID를 임의 생성하지 않고 기존 16개 지역 친구와 고미를 유지한다. 경북은 하회탈, 제주는 귤을 사용한다. 사용자가 전남·광주 통합특별시를 고구마 하나로 통합한다고 확인했으므로 광주 수박을 별도 친구로 만들지 않는다. 외형 이름은 화면 표시용이고 사용자 지정 이름을 우선한다.
