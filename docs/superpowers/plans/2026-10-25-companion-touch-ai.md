# 캐릭터 터치 AI 반응으로 전환

사용자 정정: 직접 입력하는 대화가 아니라 캐릭터를 터치하면 기분에 따라 자연스럽고 다양한 대사가 나와야 하며, 준비한 AI 모듈을 사용한다.

기획자: 홈 말풍선이 결과이고 캐릭터 터치가 진입점이다. ‘대화하기’/입력창 대신 ‘AI 반응 설정’에서 모델만 준비한다. 일반 사용자: 터치 즉시 표정·기본 대사를 보고, AI 준비 완료 기기에서는 새로 생성한 한두 문장을 같은 말풍선에서 듣는다. 생각 중·중단을 표시하고 화면 이동/연속 터치는 오래된 응답을 덮지 않는다.

- [x] 성격·친밀도·기분·활력·최근 행동·시간대·현재 반응·최근 대사를 포함하는 터치 프롬프트와 짧은 출력/중복 제거를 검사한다. 사진·일기·GPS를 포함하지 않는다.
- [x] 600ms 터치 묶기와 직렬 AI 실행 큐를 만들고 취소/페이지 이탈/늦은 응답을 검증한다. 모델 로딩은 실제 터치 후에만 한다.
- [x] 홈의 터치 및 함께하기 행동에 AI 반응을 연결한다. 잠든 고미의 기존 표정·호감도 규칙을 유지하면서 현재 반응에 맞게 대사를 변주한다.
- [x] 직접 입력 UI를 모델 준비 화면으로 교체한다. 기존 대화 저장 데이터·교감 기록·캐릭터 ID·사진·SQLite·서명을 보존한다.
- [x] 변경 기능 단위 검사·모바일 실제 터치/설정/취소/화면 이동·빌드 후 커밋한다. 이전 업로드 요청을 이어 final 반영 여부를 확인한다.

기준: final 23569b0, 열린 PR 없음. Qwen3 1.7B Q4_K_M와 기존 JNI를 그대로 사용한다. 모델 미준비/실패 시 기본 반응은 유지한다. 캐릭터별 최근 AI 대사 최대 12개만 로컬에 보관하여 반복을 줄인다. 저장 실패는 같은 세션에서만 기억하고 핵심 기록에는 영향을 주지 않는다.
