# 고미 추가 대사 240개 학습 실행 계획

사용자는 첨부한 추가 대사를 기존 자료와 합쳐 실제 학습까지 마칠 것을 요청했다. 기존 준비된 4B/WSL 환경을 그대로 사용하고 이전 결과를 보존한다. 앱 배포는 요청 범위에 없다.

## 실행 범위

- [x] 첨부 원문을 보존하고 6주제 × 40개의 상황·대사를 빠짐없이 파싱한다. 대사는 고치지 않는다.
- [x] 기존 학습 105개에 새 원문 240개를 추가한다. 기존 평가 24개에 원문과 중복되지 않는 별도 상황 24개를 더한다.
- [x] 방문객은 귀찮아서 피함, 식사는 집사의 숟가락질 기대, 애정이 높아도 자기 주장 유지 등 최신 사용자 성격 규칙을 반영한다.
- [x] 입력·답변 분리, 원문 보존, 원문 전량 학습 포함, 평가 누출·640토큰 제한을 검증한다.
- [x] 같은 고정 4B 원본에서 2 epoch를 학습한다. 매 epoch 평가와 체크포인트를 남기고 평가 loss가 가장 낮은 epoch를 최종 어댑터로 선택한다.
- [x] 새 어댑터 저장·재로딩·가중치 변경을 확인한다. 이전 v2 어댑터도 동일한 새 평가 자료로 측정하고 실제 새 상황 출력과 함께 보고한다.

## 제약과 판단

GTX1660 6GB, Python3.11, 기존 고정 NF4 4B, FP32 계산, rank8 및 기존 optimizer 설정을 유지한다. 같은 답변을 평가에 섞지 않고 평가 입력에 정답 대사를 넣지 않는다. 추가 240개는 모두 학습에 포함하며 별도 평가 문답은 에이전트가 작성한 미승인 검증 초안으로 표시한다. 모델 가중치·캐시·실행 결과는 Git에서 제외한다. 원본 파일·사용자 DB·앱 다운로드 URL·APK·서명은 변경하지 않는다.

2회 학습과 최저 평가 loss 선택은 기존 한 번 학습에서 성격 반영이 약했던 점을 고려한 이번 실험 설정이다. loss 감소만으로 대사 품질 합격을 선언하지 않는다. 실제 출력에 존댓말·지문·행동 주체 혼동이 남으면 그대로 보고한다.
