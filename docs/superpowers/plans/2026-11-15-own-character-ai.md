# 곰고미 전용 AI 새 구현

사용자 확정 조건: 외부 사전학습 모델·가중치·추론 엔진 없이 전용 생성 AI를 새로 만든다. 외부 모델의 출력으로 증류하지 않는다. 갤럭시26에서 행동 후 짧은 문장 전체가 1초 이내 표시되는 것을 목표로 한다. 상업 배포에 필요한 계보와 라이선스를 기록한다. 기존 final에서 진행하고 final/master 외 브랜치는 만들지 않는다. 구축 방식은 사용자가 위임했다. 중간 반복 검증은 생략하고 마지막에 묶어서 검증한다.

## 설계 결정

직접 구현한 행동 조건부 단어 신경망을 무작위 초기화부터 학습한다. 최근 단어 4개의 임베딩과 캐릭터·행동·친밀도·수면 상태 임베딩을 작은 전결합 신경망에 넣어 다음 단어를 생성한다. 분류한 완성 대사 목록을 고르는 방식이 아니다. 어휘·문법과 행동 범위는 학습 자료에 한정된다. 범용 자유 대화 능력을 주장하지 않는다. 새로운 행동은 자료를 추가하고 다시 학습해 확장한다.

기존 고미 자료와 새로 명시적으로 작성한 초안을 사용한다. 외부 모델 캐시·LoRA·생성 결과 파일은 새 학습 코드가 읽지 않는다. 학습의 순전파·역전파·AdamW도 전용 코드로 구현하고 PC의 NumPy는 행렬 계산에만 사용한다. 앱에는 직접 작성한 TypeScript 추론기와 새로 학습한 작은 가중치만 포함한다. 앱의 React/Tauri 같은 일반 라이브러리는 유지하고 해당 고지를 보존한다.

0.57B 모델의 옵션 최적화는 자체 모델 요구를 충족하지 못해 제외했다. 준비된 대사를 고르는 방식도 새 문장 생성 요구에 맞지 않아 제외했다. 소형 신경망의 한국어 품질은 별도 최종 표본으로 확인하며 성공을 미리 보장하지 않는다.

## 구현 순서

1. `tests/own-character-ai.test.mjs`: 실제 작은 모델의 생성·취소·등록되지 않은 행동·가중치 손상·유한 시간 검사를 작성한다. 사용자 요청으로 중간 실행은 생략한다.
2. `local-ai/own/`: 자료 정리, 자체 tokenizer/feature contract, 무작위 초기화 학습, 양자화 내보내기와 학습 계보를 만든다. 이전 가중치를 읽는 경로를 두지 않는다.
3. `src/features/characters/ownAi/`: 직접 작성한 다음 단어 신경망, Worker, 상태·시간 측정, 짧은 생성과 최근 문장 회피를 구현한다. 홈의 600ms 대기와 외부 모델 호출을 제거한다.
4. Android 준비와 CI를 새 모델로 전환한다. 이전 GGUF·LoRA·llama.cpp와 다운로드 기능을 APK에서 제외한다. 이전 연구 자료·라이선스는 PC/소스 보관본에 보존한다. 기존 DB·사진·서명키는 바꾸지 않는다.
5. 외부 모델 제거, 출처·라이선스, 타입/빌드, 실제 생성과 설치 APK 오프라인 지연을 마지막에 한 번 묶어 확인한다. 실기기가 연결되어 있지 않으면 갤럭시26의 1초 달성을 미검증으로 기록한다. 기존 얼굴/반려동물 인식 모델의 남은 권리는 별도로 명시한다.
6. 검증한 변경을 커밋·푸시하고 기존 영구 서명키로 APK를 만든다. 실제 크기·지연·남은 품질 문제를 기록하고 완료 메일을 보낸다.

## 진행 기록

- 시작 HEAD: 95be2f38c2ccc442398d0a8a8733c816549bb37f. 작업 트리 clean, 브랜치 final.
- 이전 지연: 입력 338토큰 처리58.1초, native 생성 전체115.8초. 이 실행 기록을 새 모듈의 속도로 사용하지 않는다.
- PC의 `adb devices`에 연결된 기기가 없다. 에뮬레이터를 갤럭시26 실기기로 표시하지 않는다.
- 자체 학습기(수동 역전파 포함), 자체 TypeScript 신경망, Worker, 홈 연결, PC 메뉴, APK 제외 정책 구현. NumPy 수학 계산만 사용하는 버전으로 처음부터 다시 학습 중.
- Ruling: final 브랜치와 기존 checkout을 유지한다. 사용자 브랜치 제한과 비용 축소 지시를 따른다.
- Ruling: 사용자 지시에 따라 중간 테스트 실행은 생략하고 최종 묶음에서 실제 생성·학습 미분·앱 빌드·배포를 확인한다.
- 자체 수동 미분·학습 갱신 검사2개 통과. 관련 모듈·수송·Android 준비 검사15개 통과. 타입 검사와 프런트 빌드 통과.
- 29개 개발 입력의 생성 모두 성공. 수면 중 간식의 어색한 단어 연결은 학습 자료 기반의 단어 연결 제약과 행동 검사를 추가해 수정했다. 이후 중앙값0.724ms, 관측 최대4.377ms(PC 엔진만). 실제 앱의 터치→전체 문장 표시 및 휴대폰 성능과 구분한다.
- 전체 로컬 Node 검사에서 오래된 Java fixture의 Windows 기본 문자 인코딩/심볼릭 링크 권한 제한과 변경된 서비스의 이전 테스트 로더 문제를 확인했다. 서비스 테스트를 새 Worker 취소·재사용 동작으로 교체해 관련 검사를 통과했다. Linux CI 전체 결과는 별도로 확인한다.
- 사용자는 지금 휴대폰 연결이 어렵다고 답했다. 갤럭시26 실기기1초 달성은 미검증으로 남긴다.
- 코드 리뷰·커밋·서명 APK 생성은 다음 단계다.
- 최종 외부 코드 리뷰에서 새싹의 햇살 선물/고미의 간식 의미 차이와 Tauri의 frontendDist 바이너리 임베딩에 맞는 실제 자산 검증을 보완했다. ZIP은 외부 엔진·가중치의 부재만 검사하고 설치 앱이 실제 제공한 모델·고지 바이트의 SHA를 소스와 비교한다. 오프라인 전환 뒤 페이지를 새로 열어 초기 Worker 로드도 오프라인에서 수행한다.
- Ruling: 완성 대사의 재현에 치우치지 않도록 학습한 문장 경계 제어와 문장 내부 이력 초기화를 추가했다. 모델이 두 문장을 단어 단위로 새로 조합하는지도 검사한다. 수학 알고리즘과 학습·추론 행렬 배치는 동일하며 외부 모델은 추가하지 않는다.
- 첫 서명 APK 설치 시험에서 낮은 친밀도·수면 상태의 연속 터치가 대사 생성 실패를 보였다. PC 재현에서도 최근9개 대사 뒤 동일 오류를 확인했다. 16회 독립 재시도가 같은 탈락 후보를 재선택하는 것이 원인이었다. 다음 단어를 중복 탐색하지 않는 제한된 되짚기 방식으로 수정하고, 해당 재현과 sleepy/irritated 각각16회 연속 생성 검사를 포함한8개 검사 및 타입 검사를 통과했다. 실제 APK 시험은 수정 커밋으로 다시 수행한다.
- 마지막 생성 표본에서 쓰다듬기 중단 요청 뒤 모순된 두 번째 문장에 탐색이 몰리는 경우를 추가로 확인했다. 모순 검사를 생성 도중에도 적용해 그 분기를 즉시 제외한다. 멈춤 요청 뒤 긍정적인 쓰다듬기 요청을 연결하지 않도록 재현 검사를 추가했다.
