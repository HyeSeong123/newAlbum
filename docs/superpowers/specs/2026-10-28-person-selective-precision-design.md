# 필요한 사진만 정밀 얼굴 분석

사용자는 첫 분석 속도를 유지하면서 놓친 사진을 다시 찾을 때만 구역별 탐색과 원본 얼굴 정밀 분석을 사용하고, 확인한 기준 얼굴 선택도 보완하는 방식을 승인했다.

## 범위와 선택

- 모든 사진에 추가 추론을 실행하는 방식은 분석 시간 때문에 선택하지 않았다. 기존 `못 찾은 사진 다시 찾기`를 명시적으로 누른 사진에만 정밀 모드를 적용한다. 같은 작업에 섞인 새 사진은 기존 기본 모드로 처리한다.
- 기본 모드의 해상도·추론 횟수·모델·자동 연결 기준은 유지한다.
- 정밀 모드는 전체 탐색 후 겹치는 4개 구역을 순차 탐색한다. 좌표를 원본 기준으로 복원하고 중복 얼굴을 합친다. 불확실한 얼굴은 최대 4개만 원본의 얼굴 부분으로 다시 분석한다. 추가 검출은 확인 대상으로 유지하며 자동 연결 범위를 넓히지 않는다.
- 기존 여러 기준 얼굴 비교는 유지하면서 최근 정면 사진만으로 32장 한도가 채워지지 않도록, 사용자가 확인한 정면·좌·우·미확인 방향을 고르게 선택한다. 모델 학습이나 안경 판별 모델을 추가하지 않는다.
- 원본·이름·얼굴 ID·기존 연결·대표 사진·DB 구조와 서명은 보존한다. 이미 얼굴이 있는 사진을 초기화하거나 자동 재분석하지 않는다.

## 기획자와 사용자 확인

기존 버튼을 유지하고 정밀 분석 중이라는 진행 문구를 표시한다. 사용자는 시작 → 진행률 → 중단/완료 → 기존 이름과 새 미확인 얼굴 확인 흐름을 사용한다. 초기 사진 가져오기나 앱 재진입으로 정밀 분석을 자동 시작하지 않는다. 실패한 사진은 완료로 저장하지 않는다.

## 구현 판단과 검증

원본은 정밀 모드에서만 Worker로 소유권을 이전하고 작업 종료 시 해제한다. 구역과 얼굴 부분은 한 장씩 최대 1600px로 처리한다. 같은 TFJS/FaceAPI 가중치를 유지한다. 구역 경계 중복, 이웃 얼굴 오대체, 잘못된 좌표, 최대 얼굴 수, 취소/오류 해제와 기본 경로 추론 횟수를 검사한다. 실사진 정확도와 실제 ARM64 시간은 별도 실측 전까지 미검증이다.

## Android 백그라운드 문의

사용자가 이어서 앱을 내려도 분석할 수 있는지 문의했다. 가능성 확인은 진행하되 현재 WebView Worker에 포그라운드 알림만 붙여 화면 꺼짐·프로세스 종료까지 보장한다고 표시하지 않는다. 실제 지속 실행에는 Android 서비스와 추론 실행 수명, 알림·중단·대기열 복구의 별도 구현 및 기기 검증이 필요하다. 이번 정밀 분석 구현만으로 백그라운드 실행이 완성됐다고 보고하지 않는다.
