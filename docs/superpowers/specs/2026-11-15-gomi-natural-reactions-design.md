# 고미의 자연스러운 행동 반응 재학습

사용자 요구: PC에서 직접 학습하고 외부 모델/API/AI 엔진 없이 짧고 자연스러운 반응을 생성한다. 앱의 크기와1초 반응 목표를 유지한다. 새 행동에 대한 학습 자료를 추가할 수 있어야 한다. 중간 검사는 최소화하고 마지막에 묶어 검사한다. 기존 구축 방식 위임과 계속 진행 요청에 따라 추가 설계 승인 질문 없이 구현한다.

2026-11-15 사용자 추가 기준: 자다가 간식이나 밥을 주면 눈을 게슴츠레 뜨고 멍하니 있다가 먹으러 온다. 너무 피곤하면 계속 잔다. 이것은 사용자가 제공한 행동 기준이며 아래 예시 대사는 AI 개발 도우미가 쓰는 파생 초안이다.

## 현재 결함

- energy0/1이 같은 low feature여서 심한 피로와 일반적인 졸림을 구분할 수 없다. 같은96개 seed의 출력이 두 상태에서 모두 같았다.
- 홈 간식 동작은 실제로 먹지 않아도 energy를 먼저 올리고 잠을 방해한 관계 변화로 처리한다.
- 모든 행동·캐릭터가 전역 단어 연결을 공유한다. 두 번째 문장 시작 때 이력을 초기화하므로 문장 사이 뜻이 이어지지 않는다.
- 기존 검사32개는 생성 성공과 길이 위주다. 사용자가 지적한 의미 오류와 새 피로 조건을 별도로 검사해야 한다. baseline 무작위608개에서는 보고된 놀이 제안을 재현하지 못했으므로 특정 seed를 재현했다고 기록하지 않는다.

## 접근 비교와 선택

기존 단어 금지 정규식만 늘리는 방법은 같은 뜻의 다른 표현이 새면 반복 수정이 필요하다. 외부 언어모델로 바꾸는 방법은 사용자의 직접 구축 조건에 맞지 않는다. 자체 신경망과 학습기를 유지하며 전체 문맥·상황별 학습 연결을 사용하는 방법을 선택한다. 이는 구축을 맡긴 범위에서 내린 구현 판단이다.

## 구현

1. 기존 원문과 이전 모델은 보존한다. 고미 행동 초안을 완성된 짧고 일관된 발화로 다시 작성한다. awake/sleepy/exhausted, 간식/밥, 친밀도5단계, 수용/거절 등의 의도를 표시한다. 초안을 사용자 원문이나 승인 자료로 표시하지 않는다.
2. 자체 단어 신경망을 PC의 기존 Python/NumPy 환경에서 새로 학습한다. 역전파·AdamW는 자체 코드를 사용한다. 문장 경계에서도 최근4단어 이력을 유지하고 exhausted/low/normal과 행동·상태 결합 feature를 학습한다.
3. 학습 자료에서 상황·의도별 다음 단어 연결을 만든다. 실행 시 해당 상황의 의도와 끝까지 맞는 단어만 신경망 확률로 생성한다. 완성 대사 목록을 APK에 넣어 고르는 방식은 사용하지 않는다. 외부 어휘나 다른 캐릭터의 대사를 끌어오지 않는다.
4. 간식은 행동 전 피로로 판단한다. 일반 졸림에는 peek 후 rest-front로 깨어나고 극심한 피로에는 수면 유지·활력 미증가로 처리한다. 간식을 준 것 자체에 잠 방해 친밀도 감소를 붙이지 않는다. 새로운 밥 행동은 학습/PC 시험에서 지원하며 앱에 새 식사 감지나 버튼은 임의 추가하지 않는다.
5. PC에서 한국어 행동·졸림·극심한 피로를 시험하고 JSONL 추가 자료를 포함해 다시 학습할 수 있게 한다. 기존 일반 앱·사진·DB·서명·final/master는 보존한다. 가중치와 제약을 합쳐2MB 상한을 유지한다.

## 완료 기준

자는 중 간식/밥: 일반 졸림은 졸린 기색과 먹을 의사, 극심한 피로는 계속 자겠다는 말. 다른 행동·갑작스러운 놀이·역할 전환이 없어야 한다. 거절/수용과 친밀도도 일치해야 한다. 서로 다른 seed·연속 반응과 경계값을 마지막 검사에서 포함한다. 자동 의미 검사와 개발자의 실제 대사 검토를 구분하고 모든 자연스러움을 보증하지 않는다. 갤럭시26 실측은 연결이 없어 미검증으로 남긴다.
