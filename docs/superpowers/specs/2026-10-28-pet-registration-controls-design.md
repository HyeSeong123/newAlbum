# 등록한 반려동물 중심 인식과 종류 오류 복구

사용자 요청: 독립적인 ‘사진에서 반려동물 감지’ 진입점과 선택 창·도움말을 제거하고, 등록 사진의 ‘인식 기준 갱신’과 그 기준을 이용하는 사진 찾기를 남긴다. 모바일 버튼을 정렬한다. 이름 지정 시 자동 개·고양이 분류 때문에 막힌 결과를 사용자가 수정할 수 있어야 한다.

기획자 관점: 추가와 인식 기준 갱신이 주요 작업이다. 사진 찾기·미확인 결과·선택은 같은 크기의 보조 버튼으로 배치한다. 미확인 화면에는 목록 검색 도구를 남기지 않는다. 사용자 관점: 사진 등록만으로 분석하지 않고 기준 갱신을 직접 눌렀을 때 실행한다. 잘못 분류된 선택 결과는 이름 지정 창에서 종류를 명시적으로 바로잡을 수 있다.

선택한 인식 결과에만 명시한 종류를 이름 연결과 같은 SQLite 트랜잭션에서 적용한다. 실패 시 둘 다 롤백하고 선택을 유지한다. 기존 대상의 다른 결과는 수정하지 않는다. 기존 등록 자체가 잘못 분류된 경우 사진 상세의 종류 수정 기능을 쓴다. 강아지로 수정하면 고양이 정면 전용 자동 얼굴 정보는 해제하고 원래 탐지 종류는 보관한다. 제외한 구형 자세 정보는 활성화하지 않는다.
