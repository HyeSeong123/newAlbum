# 일기장과 친구들의 기본 움직임

사용자 요청: 모바일 일기를 원래처럼 넓게 보기, 현재 캐릭터 구성에 맞는 메뉴 이름,
고미 외의 친구들에게도 다양한 기본 행동 제공.

## 적용 범위

- 모바일 일기 목록은 한 줄에 한 편. 본문·사진·날짜·더보기를 좁은 두 열에 넣지 않는다.
  앨범 목록의 두 열 배치는 유지한다. 일기 저장·상세·수정 흐름은 바꾸지 않는다.
- 메뉴명은 구현 판단으로 `친구들`을 사용한다. 홈 바로가기·접근성 이름·도움말·대표/이름
  문구를 함께 맞춘다. 캐릭터 ID와 저장 데이터는 그대로 사용한다.
- 고미 외 16명은 홈 진입 시 둘러보기·끄덕이기·기지개·흔들기 중 하나를 짧게 보인 후
  편안한 기본 움직임으로 돌아온다. 터치 반응은 성격별로 순환하고, 다섯 함께하기는
  각각 다른 움직임을 쓴다. 휴식은 다음 행동 전까지 조용한 상태로 유지한다.
- 승인된 원본 그림과 SVG 클립을 그대로 사용한다. 몸짓 애니메이션을 추가하며 그림을
  다시 그리거나 새로운 수면 그림·수면 친밀도 규칙을 도입하지 않는다.
- 홈의 기본 움직임은 AI 호출·친밀도 저장을 유발하지 않는다. 고미의 기존 수면/친밀도
  규칙, 기존 모델 세션, 사진·SQLite·설정·서명·패키지 ID를 보존한다.

## 접근 방식

이번 요청은 기존 화면과 Motion 컴포넌트를 확장한다. 새 일기 보기 모드나 새 캐릭터
이미지 체계를 만드는 방식은 필요하지 않으므로 선택하지 않는다. 메뉴명과 몸짓 종류는
위에 명시한 구현 판단이며 사용자가 이름이나 세부 동작을 지정한 것으로 기록하지 않는다.

## 확인 기준

320/393px에서 일기가 한 열로 보이고 제목과 버튼이 겹치지 않아야 한다. 친구들 메뉴로
이동·대표 변경·이름 변경이 유지되어야 한다. 다른 친구의 원본 DOM은 터치/행동 중에도
유지되고, 각 행동이 다른 몸짓으로 나타나야 한다. 화면 이탈 시 타이머를 정리하고
움직임 줄이기 설정에서는 변형 애니메이션을 멈춘다. AI 생각 중 문구를 추가하지 않는다.
