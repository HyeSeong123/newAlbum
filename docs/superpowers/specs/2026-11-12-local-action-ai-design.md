# 곰고미 PC 행동 반응 학습 환경

사용자는 외부 AI API 없이 자신의 RTX 5070 12GB / RAM 32GB PC에서 학습과 실행을 원한다. 완성 앱은 캐릭터 성격을 유지하며 행동마다 새로운 짧은 문장을 생성해야 한다. 새 행동도 설정과 자료 추가로 지원한다.

구축 방식은 사용자에게 위임받았다. 대사 선택 방식은 사용자가 제외했다. Qwen3-0.6B 공개 가중치를 로컬 PyTorch에서 직접 LoRA 학습한다. 기존 4B보다 작은 시험 후보이며 한국어·성격 품질 합격을 미리 가정하지 않는다. 원본 사전학습부터 자체 개발한 모델이라는 의미는 아니다.

PC 전용 Python/CUDA/모델 캐시와 앱 배포물을 분리한다. 앱에 PyTorch나 PC 가상환경을 포함하지 않는다. 4비트 앱용 파일의 용량·속도는 변환과 기기 검사 전 미확인이다. 이번 범위는 PC 학습·생성 환경이며 기존 앱의 다운로드 정책, DB, Android/Windows 패키지, 서명은 수정하지 않는다.

실제 final c8b5e10의 17종 메타데이터를 사용한다. 18번째 캐릭터나 다른 캐릭터의 정답 대사를 임의 생성하지 않는다. 고미의 최신 성격 기준을 명시한다. 고미 v4 원문 학습465/평가64는 동결 복사본으로 보존하고, 기존 4B 프롬프트를 소형 모델용 행동/장면 입력으로 명시적으로 변환한다. 기존 4B 어댑터는 로드하지 않는다.

캐릭터별 설정, 행동 사전, 추가 JSONL 예시는 별도 파일이다. 미등록 행동·캐릭터와 데이터 누출·잘림·기존 결과 덮어쓰기는 거부한다. 추가 대사에는 출처와 train/validation 구분이 필요하다. 고미 학습본을 다른 캐릭터에 자동 적용하지 않는다.

검증은 순수 입력/변환 테스트, GPU LoRA 실제 역전파·저장·재로딩, 동결 자료 무결성, 행동 생성 표본과 길이·반복 검사다. 학습 loss나 형식 검사만으로 캐릭터 품질을 승인하지 않는다. 앱 연결과 실제 Android 용량·속도 검사는 별도 후속 작업이다.
