# 감자·고구마 그림과 반응 개편

사용자가 선택한 2안과 후속 구현·커밋 요청을 기준으로 한다. 고미의 원화는 유지하고, 두 형제의 외형과 표정·동작을 새로 제작한다.

## 디자인

- 고미 원본의 거친 색연필 채색, 부드러운 회갈색 선, 작은 눈과 따뜻한 저채도 색을 공유한다.
- 감자: 낮고 둥근 노란 몸. 호기심과 행동력이 앞서는 동생. 신남·당황·억울함이 잘 드러나고 먼저 움직인다.
- 고구마: 길쭉하고 묵직한 보라색 몸. 덤덤한 현실주의 형. 곁눈질과 작은 눈썹 변화로 태클을 걸지만 결국 함께한다.
- 고미는 자기 취향과 요구가 강하고, 고구마는 감자의 행동에 현실적인 반응을 한다. 같은 시니컬한 말투로 합치지 않는다.
- 제작자 판단: 모자·안경·옷을 더하기보다 몸의 비율·눈매·자세로 구분한다. 감자는 작은 두 잎, 고구마는 작은 하트 잎을 식별점으로 사용한다.
- 캐릭터마다 투명 배경 원화 시트 한 장에 12개 표정·포즈를 제작한다. 기본, 눈 감기, 미소, 환호, 속상함, 당황, 삐침/곁눈질, 머쓱함, 인사 두 프레임, 쉬기, 수면을 포함한다.

## 비교한 접근

1. 기존 외형에 선·질감·표정만 수정: 변화 폭이 작지만 현재 불만인 비율과 몸짓의 한계가 남는다.
2. 감자·고구마의 정체성을 유지하면서 기본 디자인부터 재설계: 사용자가 선택. 새 그림을 별도 파일로 추가해 기존 원본을 보존한다.

## 구현과 보존

- 현행 홈 터치 네 가지와 함께하기 다섯 가지 입력에 새 표정 프레임을 연결한다. 감자는 큰 반응, 고구마는 절제된 반응을 사용한다.
- 새 시트의 좌표를 SVG viewBox로 선택하며 원본 PNG를 재채색하거나 잘라서 덮어쓰지 않는다.
- 모션 줄이기에서는 포즈·표정을 유지하고 프레임 반복과 몸 움직임을 멈춘다. 백그라운드·일시정지에서는 타이머를 정리한다.
- 고미와 다른 14종의 그림과 정의, 캐릭터 ID, 이름, 호감도, 성장 조건·기록, 대표 선택, DB와 서명 설정은 유지한다.
- 현재 코드가 성장 단계와 무관하게 형제 원화를 보여 주는 방식을 유지한다. 기존 여섯 단계 성장 자산은 삭제하지 않는다.
- 캐릭터 소개·기존 상황 대사·상호작용 대사에 새 성격을 적용한다. AI 모델 자체 재학습은 포함하지 않는다.

## 확인할 사용자 흐름

기획자 관점: 새 메뉴 없이 기존 홈·도감·함께하기에서 두 형제의 차이가 드러나야 한다.
사용자 관점: 친구 선택 → 홈 진입 → 터치/함께하기 → 해당 표정·동작 → 원래 홈 자세 복귀. 재생과 미리보기는 호감도 저장을 추가 호출하지 않는다. 그림이 로드되지 않으면 기존 원화를 유지한다.

## 검증과 전달

프레임 선택·유한 반응·수면·모션 줄이기·정지 동작의 회귀 검사를 추가한다. 관련 단위 검사, 프런트 빌드, Android 크기 브라우저의 홈·도감·함께하기를 확인한다. 실제 앱 컴포넌트로 여러 동작의 미리보기를 제공하고 검증된 변경을 final에 커밋한다. APK 설치와 실기기 검증은 이번 범위가 아니다.
