# 도움말 위치와 캐릭터 대사 정비

기준: `final` / `e3d99b3`. 앞선 홈·사진·앨범·일기·추억·사람·반려동물 수정을 보존한 상태에서 적용했다. 사용자의 후속 요청으로 전체 묶음을 커밋하고 0.9.26 APK를 생성한다.

## 변경

- 기존 도움말은 캐릭터·호감도마다 문장 하나만 사용했다. 17종 × 5단계마다 3개 후보로 늘리고 고미는 삭제·선택·기록·분석·추억·사진 보기·돌아가기별 문장 35개를 더했다. 총 290개 후보 문장이다. 기능 설명은 변주하지 않는다.
- 같은 세션의 대사는 최초 단계 목록을 기준으로 보관한다. 이전/다음, 크기 변경, 사라진 단계 제외로 같은 버튼의 대사가 바뀌지 않는다. 다시 열면 다른 후보를 고르고, 연속 단계에서는 직전 문장을 피한다.
- 고미의 일상 대사는 호감도별 8→16개, 사진 추가·장소·대표 선택·슬픈 상황 대사는 각 단계 2→4개로 늘렸다. 기존 무심함·까칠함과 가까워진 상대를 챙기는 성격을 유지했다. 하루 인사, 호감도 경계, 수면 반응과 행동 조건은 그대로다.
- 스크롤 좌표가 창 안에 있어도 편집창 본문 위로 잘린 버튼을 드러내지 않던 사례를 재현했다. 이제 부모 스크롤 영역까지 확인하고, 스크롤이 반영된 다음 프레임에서 실제 보이는 범위를 측정한다.
- 강조 표시와 말풍선은 같은 오버레이 좌표를 사용한다. 위치가 바뀌면 이전 강조를 숨기고 재측정한다. 도움말 내용 자체를 읽는 스크롤은 배경 위치 갱신으로 취급하지 않는다.
- 종료 시 기존 창·본문·가로 목록의 스크롤과 입력·선택 보존 정책을 유지한다. 별도 리뷰에서 발견한 빈 도움말의 반복 갱신 문제도 수정했다.

## 확인

- 원래 함수에서 내부 영역에 잘린 대상의 자동 스크롤이 실행되지 않는 실패를 재현했다. 새 좌표 검사 3개 통과: 내부 잘림/정착, 중첩 가로·세로 영역, 시각 뷰포트·헤더·오버레이 원점.
- 대사 다양성·직전 반복 방지 검사를 먼저 실패로 확인한 뒤 통과했다. 도움말·고미·캐릭터 관련 단위 26개 통과. 전체 프런트 단위 171개와 관련 SQLite 13개도 통과했다.
- TypeScript 및 프런트엔드 번들 확인. 기존 500kB 초과 청크 경고는 남는다.
- 브라우저 시나리오는 내부 스크롤 편집창, 가로 잘림, 대사 재방문/이전/다음, 빈 도움말을 포함한다. 로컬에는 Chromium·ADB·Cargo가 없어 실제 브라우저·Android·Rust 검사를 실행하지 못했다. 이번 묶음 커밋의 GitHub Actions에서 확인한다. 수집만 성공한 검사를 실행 통과로 세지 않는다.

도움말 열람은 교감/호감도 쓰기를 호출하지 않는다. 사진 원본·SQLite 구조·AI 모델·캐릭터 외형은 이 도움말 변경에서 수정하지 않았다.
