# 0.9.28 캐릭터 AI 자유 대화

기준: final 66fa0f9. 사용자 이전 AI 기획 및 이번 첨부 원본 기준으로 실제 소스를 연결했다.

## 전후 차이와 두 관점

- 기획자: 홈에서 ‘대화하기’로 진입한다. 기존 ‘함께하기’ 활동과 자유 입력을 구분하고 다운로드·오류·중단·재시도 상태를 표시한다.
- 사용자: 문장을 입력하고 전송하면 생각 중 표시 후 답변을 받는다. 생성 실패 시 입력한 말은 남으며 ‘답변 다시 받기’로 중복 없이 재시도한다. 닫기·뒤로가기·앱 비활성화 시 작업을 취소한다.
- 기존 사진·앨범·일기 SQLite와 캐릭터 ID·사용자 이름·친밀도·성장 수치·하루 한 번 친밀도 규칙·앱 식별자·서명 설정을 보존한다.

## 실제 AI 연결

React → 허용된 Tauri 명령 → Android Kotlin 플러그인 → llama.cpp JNI CPU 추론으로 연결한다. 고정 모델은 Qwen3 1.7B Q4_K_M, 최초 약 1.1GB 다운로드 후 오프라인 동작한다. 전체 친구가 모델 하나를 공유한다. 원 모델은 Qwen, GGUF 양자화는 Unsloth 배포본이다. 공식 Qwen GGUF 저장소에는 Q8_0만 있어 이전 기획의 4비트 조건을 지키도록 양자화 배포본을 고정했다.

- 모델 revision·크기·SHA-256 및 엔진 commit·아카이브 SHA-256: `scripts/companion-model.lock.json`.
- HTTPS만 허용하고 리디렉션 호스트도 제한한다. 임시 파일을 해시·크기 확인한 뒤 완료 파일로 바꾼다. 모델 가중치는 APK/Git에 포함하지 않는다.
- Android ARM64 스마트폰, 시스템 예약 RAM을 고려한 7GiB 이상 실제 총 메모리(광고 사양 8GB 이상), 태블릿 제외. 여유 메모리 1800MiB 미만에서는 다른 앱을 닫도록 안내한다. Windows/브라우저에는 지원 환경 안내를 표시한다.
- 문맥 4096토큰, 답변 최대 192토큰, 추론 60초 제한, 최대 4 CPU 스레드. 생성 완료·실패·취소 시 context·KV cache·model을 모두 반환한다.
- Android Activity 재생성에도 요청 ID가 중복되지 않도록 프로세스 공통 번호를 사용한다. 이전 화면의 늦은 응답이 새 대화를 덮지 않는다.
- 대화는 캐릭터별 최대 40개 발화를 WebView 로컬 저장소에 보관하고, 최근 6개 발화와 최근 교감 행동만 프롬프트에 사용한다. 저장 불가를 안내한다. 사진·GPS·일기 본문을 읽거나 전송하지 않는다. AI가 앱 명령을 실행할 수 없도록 분리했다.
- Apache 2.0/MIT 원문과 모델 출처를 `public/notices/`에 포함한다. Android 프로젝트 준비 시 Kotlin/CMake가 복사되며 CI에 CMake 3.22.1을 설치한다.

## 검증

- 통과: 프런트 프로덕션 빌드(TypeScript/Vite/기존 AI 패키지 검증), 전체 등록 단위 검사 184개, 관련 Android 준비 검사. 기존 교감 검사의 ‘3글자 이상’ 조건은 고미의 정상 대사 ‘……’(2글자)를 허용하도록 보정했다.
- 통과: 새 대화 시나리오 3개(지원 환경 안내·닫기/포커스 복구, 전송/기록복구/실패재시도/중단 후 늦은 응답 무시, 다운로드/취소/320px 전송·도움말 분리). 원래 Playwright 테스트 콜백을 같은 프로세스 Vite 환경에서 실행했다. 별도 프로세스 webServer 방식은 환경의 네트워크 격리로 준비 대기 시간이 초과되어 같은 프로세스 실행으로 검증했다.
- 통과: 실제 고정 llama.cpp로 JNI 공유 라이브러리 Linux 컴파일, Java JNI 호출로 취소·모델 없음 오류 확인.
- 통과: 실제 고정 Qwen3 1.7B Q4_K_M 1,107,409,472바이트 다운로드 및 SHA-256 일치, 같은 JNI를 통한 실제 한국어 생성. 테스트 입력 ‘안녕! 오늘 산책 갈까?’에 ‘안녕! 산책을 함께할 수 있어!’ 응답을 관찰했다. 이 결과는 Android 실기기 결과가 아니다.
- 화면: 같은 393px 홈의 변경 전/후, 감자 대화창, 320px 다운로드 화면, 전체 도감(모바일/데스크톱)을 캡처하고 확인했다. 전송 버튼·도움말 버튼 겹침과 시트 여백에서 이웃 그림이 보이는 문제를 수정했다.
- 코드 검토: 별도 검토자가 JNI 수명·Kotlin 취소·개인정보 경계·그림 배치를 확인했고 Activity 재생성 요청 번호 문제를 수정했다.
- 추가 기존 홈/도감 Playwright 회귀는 이 환경에서 브라우저 재사용 시 socket 권한 제한으로 프로세스가 종료되어 중단했다. 전체 UI 회귀 통과로 간주하지 않으며 CI 확인 대상으로 남긴다. 새 대화 시나리오 3개는 각 브라우저를 새로 여는 방식으로 모두 통과했다.
- 미검증: Android NDK/Kotlin 전체 APK 빌드 및 설치·업데이트, 8GB 실제 스마트폰의 응답 속도·최대 RAM·발열·한글 키보드 표시, 실제 모델 다운로드 실패/취소의 Android 계측. 로컬 환경에는 Android SDK/Rust 도구 체인이 없어 CI/실기기 확인을 구분한다.
