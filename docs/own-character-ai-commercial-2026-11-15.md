# 새 전용 AI의 배포 권리 범위

이 문서는 권리 범위를 기록하며 앱 전체의 상업 출시 승인서가 아니다.

| 구성 | 실제 출처와 처리 |
| --- | --- |
| 전용 신경망·학습 알고리즘·앱 추론 코드 | 이 프로젝트에서 새로 구현. 전용 학습기는 무작위 초기화, 순전파·수동 역전파·AdamW를 구현한다. |
| 전용 가중치 | 새로 학습한다. 기존 HyperCLOVA/Qwen 가중치·LoRA·토크나이저·생성 시험 결과를 가져오지 않는다. |
| 학습 자료 | 제공된 고미 원문30개, 기존에 출처를 표시한 AI 도우미 행동 초안300개, 새 AI 도우미 초안. `corpus.json`에 실제 사용·제외·출처·해시를 기록한다. AI 초안을 사람이 작성·승인했다고 표시하지 않는다. 자유 장면217개는 홈 행동에 명확히 대응하지 않아 이번 작은 모델에서 제외하며 원문은 보존한다. |
| PC 수학 계산 | NumPy를 계산 도구로 사용한다. 미분·학습 알고리즘 자체는 프로젝트 코드이며 NumPy/Python은 APK에 포함하지 않는다. |
| Android 캐릭터 AI | 자체 TypeScript 추론기와 자체 가중치만 사용. 외부 캐릭터 AI 모델 다운로드와 JNI 엔진을 제거하고 APK 내부 검사로 확인한다. |
| 일반 앱 코드와 사진 인식 | React·Tauri·TensorFlow.js·FaceAPI 등 기존 구성과 고지를 유지한다. 캐릭터 전용 AI를 새로 만든 것과 앱 전체를 외부 코드 없이 만든 것은 구분한다. |

AI 도우미가 작성한 코드·초안도 생성물이다. [OpenAI 이용 약관](https://openai.com/policies/terms-of-use/)에는 당사자 사이의 출력 권리와 함께 제3자 권리·경쟁 모델 개발 등의 조건이 있다. 출력 소유 조항만으로 모든 학습·배포 목적의 무조건적인 허가를 주장하지 않는다. 이 모델은 앱의 등록된 행동에 대한 작은 반응 생성기이며 범용 대화 모델로 표시하지 않는다. 모델 API나 별도의 교사 모델을 호출하는 학습 단계는 없다.

기존 얼굴·반려동물 인식의 학습 자료 권리에는 [별도 남은 확인 사항](face-model-rights-evidence-2026-10-19.md)이 있다. 현재 `public/notices/ai-release-status.json`의 `commercialRightsVerified: false`를 임의로 승인 상태로 바꾸지 않는다. 사용자 제공 원문·캐릭터 그림의 사용 권한과 새 초안의 적합성도 배포자가 확인해야 한다.

[Google Play 생성형 AI 정책](https://support.google.com/googleplay/android-developer/answer/13985936)과 [적용 범위 안내](https://support.google.com/googleplay/android-developer/answer/14094294)에 따라 생성형 콘텐츠의 제한·신고 요건과 앱의 실제 적용 범위를 출시 전에 확인해야 한다. 자체 모델이라는 이유로 앱 심사나 법률 문제 전체가 해결됐다고 보고하지 않는다.

최종 빌드 보고에는 자체 모델 해시, 외부 캐릭터 모델/엔진 제외, APK 서명, 오프라인 생성, 전체 문장 지연을 따로 남긴다. 실제 갤럭시26을 측정하지 않았다면1초 달성을 미검증으로 표시한다.
