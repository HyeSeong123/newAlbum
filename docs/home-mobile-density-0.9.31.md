# 0.9.31 홈 반응과 모바일 목록

## 사용자 요청과 변경

- 캐릭터를 누르거나 함께하기를 실행할 때 그림이 반짝이는 문제: 감자 등 원본 그림의 반응별 노드 교체, 고미의 fade-out/in, AI 상태 표시가 삽입되며 생기는 위치 이동을 브라우저에서 재현했다. 그림 노드는 그대로 두고 Motion controls로 동작을 다시 실행한다. AI 상태 행은 항상 같은 높이를 사용한다.
- 고미의 새 자세는 전체 프레임을 디코딩한 뒤 교체한다. 로딩 실패 또는 취소 시 기존 그림을 유지하고, 늦게 끝난 이전 요청은 적용하지 않는다. 기존 잠자기·짜증·친밀도·손/혀 동작을 유지한다.
- 모바일 내 앨범·일기장 목록은 한 줄 두 개다. 앨범의 책 표지와 일기의 종이 디자인을 유지하며 긴 제목은 두 줄로 요약한다. 일기 본문과 사진은 작은 미리보기로 줄이고 원문·원본 사진은 기존 열기 동작으로 확인한다.
- 모바일 앨범의 더보기는 카드 아래 왼쪽에 44px 영역으로 둔다. 작은 카드의 제목 폭을 유지하면서 고정 도움말 버튼과 겹치지 않게 했다.

## 기획자·사용자 확인

터치 직후 기존 대사와 동작이 보이고, 준비된 AI의 응답은 같은 말풍선에 표시된다. 생각 중 표시와 멈추기는 같은 자리를 사용한다. 기존 하루 한 번 친밀도 규칙과 함께하기의 기분 저장을 그대로 사용한다.

320/393/720px에서 두 열, 긴 한글·공백 없는 제목, 사진 있는/없는 일기, 44px 메뉴, 실제 열기·닫기·선택, 가로 넘침을 확인했다. 1440px에서도 기존 목록 동작을 확인했다. 393px 샘플의 첫 카드 높이는 앨범 328px, 일기 338px이다. 작은 320px에서는 일기 날짜·기분이 줄바꿈된다.

## 검증

- 반짝임 재현 3건: 수정 전 실제 DOM 교체/불투명도 감소/AI 상태 행 이동, 느린 고미 그림의 조기 교체로 실패 → 수정 후 통과.
- `tests/companion-chat.spec.ts`: 기존 5건과 신규 3건, 총 8건 통과. 네이티브 호출 경계만 테스트 응답으로 제공하며 실제 React/Motion·이미지 디코딩·레이아웃을 실행했다.
- 기존 고미 잠자기 4건과 친밀도 높은 고미의 손·혀 프레임 동작 1건 통과. 움직임 줄이기·친밀도 저장 규칙 포함.
- 도움말 높이에 오른쪽 앨범 메뉴를 맞춰 포인터가 가려지는 실패를 재현했다. 메뉴 위치 수정 후 실제 클릭과 메뉴 열기가 통과했다(`tests/design.spec.ts`).
- `node --test tests/gomi-behavior.test.mjs tests/companion-touch.test.mjs`: 17건 통과.
- `npm run build`: TypeScript·Vite·기존 모델 패키지 무결성 검증 통과. 기존 청크 크기 안내는 남아 있다.
- 모바일 브라우저 화면 확인과 Android 실기기 검증은 구분한다. 이 로컬 검증은 Chromium이며 새 APK의 설치 검사는 후속 Actions 결과로 확인한다.

기존 캐릭터 ID·친밀도·기분 기억, SQLite·앨범·일기·사진, AI 모델과 영구 서명 설정을 그대로 사용한다.
