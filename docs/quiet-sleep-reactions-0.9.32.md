# 0.9.32 조용한 AI 반응과 수면 교감

## 반영한 요청

- 홈의 ‘친구가 생각 중…’ 문구와 대기 행을 완전히 제거했다. 기존 AI는 준비된 경우 같은 말풍선에서 조용히 응답하며 설정·다른 행동·화면 이동으로 취소할 수 있다.
- 고미의 실제 수면 자세를 현재 기분과 대사의 기준으로 사용한다. 잠들어 있으면 이전에 저장한 호기심 대신 ‘자는 중’으로 표시하고, 깨우는 행동 뒤에는 ‘자는 중 · 짜증’으로 표시한다. 홈 첫 진입·재진입에서도 깨어 있는 인사가 수면 대사를 덮지 않는다.
- 수면 중 산책·간식·쓰다듬기·놀이는 친밀도 -1, 하루 최대 -3, 최소 0이다. 일반 터치 두 번은 조용히 눈만 뜨며 친밀도를 올리지 않는다. 세 번째부터는 수면 방해로 처리한다. ‘함께 쉬기’는 잠을 유지한다. 깨어 있을 때의 하루 한 번 +1과 감소 한도는 별도로 저장한다.
- 모바일 앨범 표지의 사진 끝과 제목이 겹치던 문제를 수정했다. 두 열을 유지하면서 사진 높이를 줄여 최소 8px 이상의 여백을 확보했다.

## 저장과 비동기 처리

DB v21은 기존 v20 기록에 `character_sleep_day` 원장만 추가한다. 기존 이름·성장·친밀도·사진·앨범·일기와 서명·AI 모델은 그대로 사용한다. 친밀도 감소와 날짜별 횟수는 하나의 IMMEDIATE 트랜잭션으로 저장한다. 저장 요청을 직렬화하고 AI는 실제 저장 결과를 사용한다. 이전 요청이나 설정을 열기 전에 대기하던 AI 응답은 나중에 재개하지 않는다.

## 검증 근거

- 문구 반짝임, 수면/호기심 불일치, 표지 겹침, 저장 중 취소 후 늦은 AI 시작, 첫 진입·재진입의 깨어 있는 수면 인사를 각각 재현한 뒤 같은 검사에서 통과했다.
- 관련 브라우저: 반응·수면·취소 14건, 기존 고미 수면/친밀도 경계·손/혀·작은 화면 도움말 10건, 표지 여백/메뉴 1건 통과.
- 320/393/720px 두 열·긴 제목·열기·선택·메뉴·가로 넘침 및 1440px 영향을 확인했다. 캡처에는 별도 샘플만 사용했다.
- 관련 단위 29건, 실제 운영 SQL의 SQLite 데이터 보존·0 하한·하루 한도·재실행·날짜 변경 5건 통과.
- TypeScript·Vite·기존 모델 패키지 무결성 빌드 통과. 기존 청크 크기 안내는 남아 있다.
- Native Rust의 v20 업그레이드/실패 롤백 및 친밀도 검사와 새 APK의 Android 설치는 후속 Actions 결과로 확인한다. 로컬에는 Rust/Android 실행 환경이 없으며 실기기 검증과 구분한다.

코드 검토에서 수면 인사가 먼저 초기화되는 결함을 확인해 초기 자세가 정해진 뒤 대사·일일 인사를 초기화하도록 수정했다. 검토의 다른 중요 결함은 없었다.
