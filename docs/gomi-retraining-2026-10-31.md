# 고미 성격 대사 합본 재학습 결과

사용자 요청에 따라 기존 초안과 직접 제공한 고미 성격 대사를 합친 v2 데이터로 4B 어댑터를 새로 학습했다. 학습 실행·저장·재로딩 검증은 끝났으나 대사 품질은 앱 적용 기준에 미달한다.

## 실행과 데이터

| 항목 | 결과 |
| --- | --- |
| 모델 | Qwen3-4B-Instruct-2507, 같은 원본의 Unsloth NF4 배포본 |
| 모델 revision | f12db89cd5156e090618dded9b4367f23f8f3b33 |
| 학습 | 기존 파생 초안 96개 + 사용자 원문 9개 = 105개 |
| 평가 | 별도 파생 초안 24개 |
| 무대사 행동 | 혼났을 때의 회피 행동은 참고 자료로 보존, 임의 대사 생성 없음 |
| 설정 | 새 어댑터, 1 epoch, rank 8, 배치 1/누적 4, learning rate 0.0002 |
| optimizer 실행 | 27회 |
| 학습 전 원본 → 새 어댑터 loss | 4.496366 → 2.340999 |
| 최대 GPU 할당 | 3916MiB, 다른 앱의 사용량 제외 |
| 학습·저장·재평가 시간 | 864.6초 |
| 확인 | 저장 어댑터 재로딩 성공, 288 tensors 변경, LoRA B 144개 모두 nonzero |

이번 실행은 이전 어댑터에 이어 학습한 것이 아니라 같은 4B 원본에 합본 자료로 새 어댑터를 만든 것이다. 이전 결과는 보존했다. 새 어댑터 SHA256은 `7efe15f5bf6a87efb1ef3898615fc09c5c409bd73c10cddf2de263991d86b352`이며 Windows 복사본도 일치했다.

## 같은 평가 자료에서 비교

v2에서는 산책·간식 대사 일부가 수정돼 v1 보고서의 2.381423과 바로 비교하지 않는다. 이전 어댑터와 새 어댑터를 **동일한 v2 평가 24개**에 다시 실행했다.

| 어댑터 | 동일 v2 평가 자료의 token 평균 loss |
| --- | --- |
| 이전 v1 | 2.372915 |
| 새 v2 | 2.340999 |

소폭 감소했으며 평가율이나 대사 품질 합격률을 의미하지 않는다. 새 어댑터의 독립 재로딩 평가가 학습 스크립트의 최종 지표와 일치했다. 비교 자료 SHA256은 `865395fd476d54b85866c399680d78570b51b1c7bb4823d215d1a8e278771fbe`다.

## 실제 대사 확인

먼저 기존 앱 입력에 해당하는 평가 표본에서 졸림은 '잠깐만. 좀 더 자고 싶어.', 수면 방해는 '잠깐만. 그만. 잠들었잖아.'로 나왔다. 반면 간식에서는 '지금은 괜찮네. 다음엔 놓아줘.'처럼 모호한 표현이 남았고, 낮은 친밀도에서 지나치게 먼저 다가가는 반응도 있었다.

추가로 사용자 원문을 넣었던 장면 9개를 검사했다. **이 장면들은 학습에 포함됐으므로 새로운 상황에 대한 일반화 평가가 아니다.** 단일 seed의 생성 표본이며 사례별 합격률도 산출하지 않았다.

| 장면 | 새 모델의 실제 출력 | 검토 |
| --- | --- | --- |
| 가족 지인인 낯선 손님 | 네, 좀 더 살펴볼게요. | 고미 말투·상황 미달 |
| 가족도 낯설어하는 방문객 | 집 안 못들어오네? | 경계·짖는 반응이 불명확 |
| 밥 먹기 | 밥 먹기 쉬워지게 해줘 | 집사에게 편의 요구는 반영, 표현 보강 필요 |
| 입에 사료 묻음 | 입 닦는 건 좀 싫어! | 상황과 거부 의도 부합 |
| 산책 후 발 닦기 | 발 닦고 들어오면 나 진짜 좋아해 | 행동 주체와 발을 닦아달라는 요구가 어긋남 |
| 산책 재촉 | 집사, 지금 나가고 싶어요! | 나가고 싶은 의도는 있으나 존댓말 |
| 목줄 채우기 | 목줄은 나 떨어지게 해. | 의미·자연스러움 미달 |
| 양치 | 양치 안 해줘요! | 반말·자연스러움 미달 |
| 주인 뒤에서 다른 동물 보기 | (고미는 주인 뒤에서 눈을 보며) 그거 뭐야? | 지문이 섞이고 허세가 약함 |

추가한 실제 앱 산책 평가 입력에서도 '잠깐만. 나만 데려가줄게.'가 나와, 산책을 재촉하는 반응과 행동 주체를 더 분명히 가르쳐야 한다.

## 결과와 다음 보강 기준

재학습 파이프라인은 정상 실행됐지만 고미의 성격이 안정적으로 반영됐다고 판정하지 않는다. `qualityApproved=false`, `deployedToApp=false`를 유지한다. APK·앱 프롬프트·다운로드 모델 URL·사진·일기·DB·서명은 변경하지 않았다.

다음 비교에서는 사용자 원문의 말투를 유지한 다양한 상황 예시, '산책은 재촉/목줄은 회피'와 '가족 지인/낯선 방문객'의 대조, 집사와 고미의 행동 주체를 명시한 문답을 보강할 필요가 있다. 학습 설정도 비교 대상으로 두되 단순히 더 오래 학습하면 해결된다고 보장하지 않는다.

## 보관 위치

- WSL: `~/gomi-training/runs/gomi-4b-persona-v2/`
- 입력 원본: `~/gomi-training/persona-v2/data/`
- Windows 결과: `gomi-training-output/gomi-4b-persona-v2/`
- 핵심 파일: `report.json`, `persona-comparison.json`, `before.json`, `after.json`, `adapter/`, `data/`

학습 데이터 파일 해시, 원문 참고 자료와 파생 초안까지 보존했다. Windows 결과 폴더의 가중치는 Git에서 제외돼 있다. 전체 결과는 실제 WSL2/GTX1660 실행이며 Android 설치·실기기 품질 검사는 아니다.
