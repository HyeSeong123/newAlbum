# Android 고미 즉시 반응 모드 0.9.47

## 문제와 측정
사용자 제공 실제 Android 화면: 모델 로딩 0.3초, 대화 메모리 준비 0.1초, 첫 글자까지 83.4초, 전체 반응 85.7초, 앱 메모리 최대 약 2994MB. '첫 글자까지'는 입력 프롬프트 처리를 포함하므로 83.4초를 단순 모델 로딩 시간으로 해석하지 않는다.

현행 Android Qwen3 4B GGUF와 고미 v4 LoRA는 CPU 추론이다. 같은 모델의 즉석 신규 생성 결과를 1초 안에 보장할 근거가 없다. 작은 프롬프트나 디코딩 옵션 변경만으로 85.7초를 1초로 줄인다고 주장하지 않는다.

## 기획자와 사용자의 기대
- 기획자: 앱 홈에서 행동하면 즉시 말풍선과 그림으로 응답해야 하며 기기 RAM/배터리를 소모하는 AI 생성은 분명히 선택할 수 있어야 한다. '준비된 문장'을 'AI 생성 문장'으로 표시하지 않는다.
- 사용자: '고미 터치 → 1초 이내 반응'을 기본으로 기대한다. 기다리다가 85초 후 갑자기 말풍선이 바뀌는 경험을 피한다. 실제 모델로 새로운 말을 원하면 직접 AI 생성 모드를 고른다.
- 기존 데이터·친밀도·수면 중 방해 반응·모델 파일·다운로드·서명 정책은 그대로 둔다.

## 구현
- 고미의 최초 기본 모드는 `instant` (상황·친밀도별 기존 준비된 대사, 네트워크/Native AI 생성 호출 없음). 다른 캐릭터의 기존 생성 동작은 변경하지 않는다.
- AI 반응 설정에서 두 버튼: '즉시 반응 · 추천'과 'AI 새 대사 생성 · 느림'. 각 버튼은 aria-pressed와 48px 이상 터치 높이를 갖고, 설정은 기존 앱 로컬 저장소에 별도 키로 보존한다. 데이터베이스는 변경하지 않는다.
- 빠른 모드로 전환하면 진행 중인 AI 생성을 취소하고 세션 모델을 해제한다. 이후 터치/산책/놀이 시 새 추론을 시작하지 않는다.
- AI 모드에서는 기존 4B/Gomi LoRA v4를 그대로 사용한다. 새 대사의 생성 시간은 사용자 기기에 따라 길 수 있고, 먼저 보여 주는 기본 대사는 계속 표시된다.
- 화면의 기본 대사 / AI가 만든 말 출처 라벨을 유지한다. 이전 실행 기록은 실시간 fast-mode 측정이 아니라 과거 AI 실행 시간임을 밝힌다.
- 다른 캐릭터/모델 본체, 사진, SQLite, 앨범, 일기, 반려동물, 서명 키는 변경하지 않는다.

## 테스트와 실제 검증 구분
- 단위: `tests/companion-response-mode.test.mjs`, 복구/저장/기본값.
- 모바일 브라우저: `tests/companion-chat.spec.ts`, 393px 폭에서 터치 후 DOM 말풍선 변경까지 1000ms 이내, 모델 생성 명령 호출 0회, 설정 저장/모드 전환, live mode 선택 시 생성, 진행 중 생성 취소/해제, 가로 넘침 확인.
- 0.9.46 CI의 기존 변경 후 오래된 기대값 두 건(`나가기 싫어`, `'함께 산책' 행동`)을 해당 상황과 일치하도록 수정한다. 다른 캐릭터 행동은 기존 테스트 경로 유지.
- 통과 여부는 0.9.47 CI 기록을 통해서만 확정한다. Android 실기기 1초 응답 시간, 4B 실제 모델 생성 시간, 대사 품질은 실행 전 미검증. **즉시 반응은 실시간 AI 생성이 아니며, 모델이 1초 안에 출력한다고 주장하지 않는다.**
