# 0.9.37 일기장 폭과 친구들 움직임

기준 `final` 0.9.36 (`f6985a08cc089a507fa607b053eb7e1f733afdcd`).

## 변경

- 모바일 일기는 두 열에서 한 열로 바꾸고 본문·날짜·사진·제목에 여백을 복원한다.
  앨범 목록은 변경하지 않는다.
- `새싹 도감`을 `친구들`로 통일한다. 홈 진입 버튼, 전체 메뉴, 화면 제목, 접근성 이름,
  대표 친구·친구 이름과 해당 도움말을 함께 수정한다. 내부 캐릭터 ID/DB/경로는 유지한다.
- 고미 외 16명의 홈 진입 몸짓(둘러보기·끄덕임·기지개·흔들기), 성격별 터치 순환,
  다섯 함께하기의 서로 다른 움직임을 추가한다. 휴식은 다음 행동 전까지 유지한다.
- 승인된 원본 그림을 그대로 변형 애니메이션으로 움직인다. 캐릭터 그림 노드를 유지해
  대사·움직임이 바뀔 때 그림을 다시 로드하지 않는다.
- 고미 수면·친밀도와 기존 AI 세션 규칙, 사용자 사진·일기·앨범·인물·반려동물·별명·대표
  설정·다운로드 모델·SQLite·앱 ID·서명 체계는 변경하지 않는다.

## 구현 판단과 검토

메뉴명은 전체 캐릭터를 포함하는 `친구들`로 정했다. 기본 행동은 기존 원본 그림의 몸짓
확장으로 해석했으며 원본의 다른 포즈를 다시 그리는 작업은 별도이다. 모바일 일기는
최근 두 열 변경을 되돌려 한 편을 넓게 읽는 방식으로 적용했다.

독립 소스 검토에서 Critical/Important 지적은 없었다. 작은 보완 의견은 휴식 중 새 터치의
끄덕임에 기존 하트가 잠시 나타나는 점이었다. 휴식은 수면으로 취급하지 않으며 명시적
터치의 기존 친밀한 반응은 유지한다는 판단으로 남겼다. 수면·친밀도 규칙은 확장하지 않는다.

## 검증 기록

- 관련 Node 검사 33개 통과. 새 순수 동작 검사 5개는 16명의 진입/반복 터치/다섯 행동/
  성격별 강도/변형 복귀를 확인한다.
- TypeScript 및 프로덕션 빌드·패키징 자산 검증 통과. 기존 chunk 크기 안내만 남는다.
  로컬에 남아 있던 불완전한 생성 자산 복사본 때문에 첫 패키징은 실패했으며, 정상 모델
  파일의 존재·크기를 확인하고 미완성 복사본만 정리한 뒤 통과했다.
- 로컬 Playwright 브라우저 다운로드는 실행 환경에서 HTML 응답으로 대체되어 사용할 수
  없었다. 모바일 일기·친구 동작의 실제 브라우저 검사는 CI 대상으로 추가했다.
- 첫 CI에서 다섯 행동·휴식·원본 유지 검사는 PC/모바일 모두 통과했다. 배경 복귀 검사의
  두 기대값은 감자의 수줍은 성격(`bashful-peek`)이 사용하는 끄덕임을 뛰기로 잘못
  기대해 실패했으며, 실제 성격과 지속 시간에 맞게 검사만 보정했다. 기능 APK 소스는
  `aa92f12dbd09071c2535cf3381e53c4caca5cae8`이며 이 보정은 앱 실행 코드를 바꾸지 않는다.
- 배경 복귀 검사는 이후 통과했다. 움직임 줄이기 검사에서는 Motion의 기존 훅이 화면
  진입 때의 설정을 보관한다는 구현을 확인했다. 다른 기존 검사와 같이 진입 전 설정을
  켜는 독립 검사로 분리해 진입 시와 함께하기 반응에서 모두 변형이 없는지 확인한다.
- Android 설치 검사에는 실제 친구들 메뉴/대표 전환/다섯 행동/그림 노드 유지/친밀도 보존을
  확인하는 `friend-motions-smoke.mjs`를 추가했다. 최종 실행 결과는 같은 커밋의 Actions로
  확인한다. 실물 휴대폰은 이번 환경에서 확인하지 않았다.
