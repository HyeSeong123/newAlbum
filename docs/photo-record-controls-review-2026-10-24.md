# 사진 기록 목록·상세·등록·수정 점검

기준: `final`, `e3d99b3`. 시작 시 열린 PR 없음. 앞서 수정한 홈 변경을 보존하며 커밋·푸시·APK 생성 없이 누적한다.

## 적용한 판단

- 기획자: 사진이 주인공인 기존 색·모서리·간격을 유지한다. 저장과 취소의 우선순위를 구별하고 상세 하단까지 동일한 버튼 표현을 적용한다.
- 일반 사용자: 글자만 있는 조작부도 버튼으로 구분할 수 있게 한다. 작은 닫기·검색 지우기·더보기의 터치 영역을 확보하며, 취소한 수정값이 다음 편집에 남지 않게 한다.

- 통과: `tsc --noEmit`, 변경 공백 검사, 사진 필터·정렬·등록·저장 보존 관련 단위 검사 31개.

- 미실행: 위 브라우저 검사, 기존 상세·제목·지역·등록 회귀, 수정 전후 캡처, Android 실기기 터치·키보드·갤러리·권한·저장·뒤로가기. 사용자 요청대로 사람과 반려동물 수정분을 커밋할 때 묶어 실행한다.
