## 버튼 디자인과 도움말

- 따뜻한 종이·올리브 토큰을 유지한다. 저장·적용은 진한 올리브(`--secondary`), 삭제·제외는 기존 위험색으로 구분한다.
- 작업 버튼은 6px, 카드·편집창은 8px 반경으로 정리한다. 조작부는 최소 44px이며 긴 하단 버튼은 높이가 늘어나도록 고정 높이를 해제했다.
- 후보 검색 범위·후보 선택 입력, 얼굴 확인 체크, 모달 닫기의 터치 영역과 키보드 초점 표시를 보완했다.
- 모바일 후보 검색 푸터, 편집 푸터와 선택 하단은 기존 고정 `?` 공간을 유지한다. 실제 가림과 줄바꿈은 브라우저 검증 항목으로 남긴다.
- 선택 취소, 미확인 묶음 선택, 분류 변경·제외, 저장 후 재조회 도움말을 실제 동작에 맞췄다. 재조회 버튼에서 ‘사진 저장’ 도움말이 잘못 선택되지 않게 했다.

브라우저와 실제 앱 확인은 사용자가 정한 사람·반려동물 변경의 묶음 커밋 시점으로 보류했다. 추가/수정한 시나리오는 목록·상세 선택 전환, 미확인 묶음 범위, 이름 초안의 닫기 거절/버림, 저장 후 재조회에서 쓰기 1회 유지, 320/393px 버튼·후보 검색 푸터다. 이 문서는 소스 정비와 수행한 경량 검사 기록이며 전체 디자인 QA 합격 기록은 아니다.

인식 모델·알고리즘·작업 큐·SQL 스키마·기존 연결 API·파일/권한·서명 설정은 이번 작업에서 변경하지 않았다.
