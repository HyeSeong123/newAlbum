# 도움말 조작부와 고정 진입점 보완

기준: final 8c74510. 새 `docs/development-validation-policy.md`의 개발 모드를 적용한다. 사용자 제공 Android 화면에서 각진 이전/다음 버튼과 스크롤에 따라 움직이는 ?를 확인했다.

## 두 관점과 수정 기준

- 기획자: 기존 온보딩/인물 화면의 둥근 버튼, 세이지 액션 색, 44px 이상 터치 영역과 여백을 재사용한다. 새 디자인 체계는 만들지 않는다.
- 일반 사용자: ?는 같은 화면을 스크롤하는 동안 같은 우측 하단 위치에 있어야 한다. 분석 표시나 선택 작업 막대가 있으면 그 고정 영역만 비워 둔다. 일반 카드가 지나간다는 이유로 이동하지 않는다.
- 현재 원인: 모든 화면 버튼의 실제 좌표를 매 스크롤마다 충돌 검사하여 일반 흐름의 홈 카드까지 회피한다. 도움말 조작부는 반경·배경·간격을 명시하지 않아 전역 사각 기본 버튼이 노출된다.

## 적용과 확인

1. 홈에서 여러 스크롤 위치의 ? 좌표가 달라지는 실패를 먼저 재현한다. 실제 분석 표시와 선택 도크가 있는 경우도 확인한다.
2. 회피 대상은 명시한 고정 도크와 실제 고정된 모달 조작부로 제한한다. 뷰포트·안전 영역·키보드는 유지하고 일반 콘텐츠를 회피하지 않는다.
3. 기존 첫 사용 안내의 둥근 조작부를 기준으로 도움말 버튼을 정리하고 카드/내용/푸터 사이 여백을 늘린다. 좁고 짧은 화면은 별도로 확인한다.
4. 도움말 이전·다음·건너뛰기·종료, 원래 선택/스크롤 복원, 사진 상세/확대 닫기의 실제 동작을 검사한다. Android 설치는 기존 CI에 맡기며 Work에서 전체 회귀를 반복하지 않는다.

DB·사진 원본·호감도·캐릭터·영구 서명키는 변경하지 않는다. 버그 수정 APK는 0.9.24로 구분한다. 테스트 결과와 실기기 미검증은 전달 시 구분한다.

## 0.9.24 적용 결과

- 이전·다음은 기존 둥근 버튼과 세이지 색을 사용한다. 카드 안쪽 여백, 캐릭터와 말풍선 사이, 내용과 조작부 사이 간격을 늘렸다. 320px/짧은 가로 화면은 별도 간격을 적용한다.
- 일반 카드·입력을 따라 움직이던 회피 계산을 고정 도크 기준으로 바꿨다. 홈 스크롤만으로 ?가 이동하지 않는다. 실제 분석 표시/펼친 진행 패널, 사진 선택 막대, 앨범 편집 저장부에는 자리를 비운다.
- 재현: 기존 구현에서 스크롤 위치 6개 검사 실패 → 수정 후 6개 통과. 추가로 펼친 분석 패널과 겹치는 실패도 재현한 뒤 수정했다.
- 최종 관련 모바일 검사: 10개 통과. 버튼/화면 확인을 위해 추가 실행한 4개도 통과(이 중 홈·작은 화면 2개는 앞 검사와 중복). 전체 앱 회귀는 반복하지 않았다.
- 실제 클릭: 이전·다음·건너뛰기·종료, 분석 패널 열기/접기, 선택 취소, 모달 뒤로가기, 사진 제목 저장/다음 사진, 확대 닫기. 도움말 중 삭제 명령 미실행과 종료 후 선택/스크롤 보존을 확인했다.
- 화면 확인: 390×780 홈 전후, 320×568·430×780·640×360 도움말의 경계/대상 비가림. 좁은 화면의 긴 대사는 내용 영역에서 스크롤한다. 캡처는 브라우저 모바일 환경이며 Android 실기기 화면이 아니다.
- `npm run build`: TypeScript·Vite·오프라인 자산 검증 통과. 기존 큰 청크 경고는 남아 있다. `git diff --check` 통과.
- 자동 브라우저 검증 환경에서 실행 파일이 잘린 것을 복구했다. 실행 헤더만 남았던 이전 전체 실행은 통과 건수에 포함하지 않았다.
- 미검증: 이번 버전 Android 설치·실기기/시스템 내비게이션·TalkBack·Windows. APK/설치 CI 결과는 해당 실행 결과를 따르며 로컬 브라우저 검사를 설치 통과로 간주하지 않는다.

주요 소스: `HelpProvider.tsx`, `help.css`, `AnalysisActivity.tsx`, `EntitySelectionBar.tsx`, 두 앨범 편집 컴포넌트. 회귀 시나리오는 `tests/help-spotlight.spec.ts`, 네이티브 상태 대체는 `tests/fixtures/helpSpotlight.ts`다. 버전 파일 5개를 0.9.24로 일치시켰다.
