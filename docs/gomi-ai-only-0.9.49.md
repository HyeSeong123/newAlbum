# 고미·친구들 홈: 실제 AI 대사만 표시 (0.9.49)

기준: `final` 0.9.48. 사용자 요청: "기본 대사는 안나오게 해주고 무조건 ai 대사가나와야해".

## 의미와 범위
- **캐릭터의 실제 말풍선은 온디바이스 AI가 새로 생성한 유효한 응답으로만 표시한다.**
- 앱이 캐릭터 대사를 재빨리 보여주려고 만든 고정 인사, 수면 대사, 기본 대사, 즉시 대사 선택 옵션은 홈에서 사용하지 않는다.
- 휴대폰에 모델이 없거나, RAM이 부족하거나, 시간 초과·중단·생성 실패라면 **가짜 AI 대사를 보여주지 않고**, 말풍선과 구별되는 상태 문구를 보여준다. 실제 AI가 실패했는데도 반드시 대사가 나온다고 속이지 않는다.
- 캐릭터 모델 본체, 고미 v4 LoRA, 사진/앨범/일기/인물/반려동물 SQLite 데이터, 행동·친밀도·수면 및 도움말은 보존한다. AI 설치는 사용자 의사로만 수행한다.

## UX 검토
- 기획자: 기존에는 고정 대사가 먼저 나오고 AI 결과에 따라 나중에 교체돼 '학습된 AI 대사'를 구별하기 어려웠다. 이제 성공 여부만 말풍선과 직접 연결된다. 실패를 빈 화면으로 감추지 않는다.
- 일반 사용자: 터치 후 'AI가 대사를 생성하고 있어요' 안내를 별도로 보고, 성공 시 고미 말풍선에 AI 문장을 보며, 실패 시 이유·재시도 동선을 이해할 수 있다. 85.7초가 측정된 기기라면 이 시간 동안 별도의 대사는 없으며 모델 자체가 1초 이내에 답한다고 약속하지 않는다.
- Android: 너비 320~393px 말풍선 자리를 고정해 위치 튐을 줄이고, 상태 안내를 캐릭터 대사와 다른 글꼴 크기로 표시한다. 도움말과 설정 버튼·캐릭터 이미지는 그대로 유지한다.

## 누르기 전후 동작
| 시점 | 홈 화면 | 내부 상태 |
|---|---|---|
| 최초 홈 진입 | 비대사형 안내 "친구를 터치하면 AI가 새로운 대사를 만들어요." | 모델 추론 없음, 고정 환영 인사 없음 |
| 터치 / 함께하기 | 비대사형 상태 "AI가 대사를 생성하고 있어요." | 기존 관계/행동/수면 상태 저장 후 실제 모델 생성 요청 |
| 생성 성공 | **AI가 생성한 문장만** `.homeSpeech[data-source="on-device"]`에 출력 | 최근 AI 반응 결과 기록 및 최근 생성 문장 관리 |
| 생성 실패 / 모델 없음 | 오류 안내 표시, `.homeSpeech` 없음 | 고정 대사로 대체하지 않으며 홈 터치 재시도/AI 설정 다운로드 가능 |
| 이동/취소 | 중단된 이전 생성 결과는 복귀 후 나타나지 않음 | 기존 요청 취소·모델 해제 및 사용자 데이터 보존 |

## 수정 사항
- `HomeView.tsx`: 기본 첫 인사·자기 전 대사·모든 행동 시 기본 대사 출력 제거. 준비된 문장은 AI 생성 중 반복 방지용 내부 입력으로만 사용; **보이는 말풍선에서는 전혀 사용하지 않는다.**
- `useCompanionReactions.ts`: 실제 AI 결과뿐 아니라 실패도 전달. 성공만 말풍선으로 공개하고 실패는 별도 오류 상태로 처리.
- `CompanionAiSetup.tsx`, `home.css`, `companion-chat.css`: 즉시/AI 선택 버튼 제거. 출처/최근 LoRA 실행 결과와 Android 사용성은 유지.
- 과거 `gamjassak:companion-response-mode:v1:*` 값을 DB·로컬 스토리지에서 삭제하지는 않지만 더는 읽지 않는다. 'instant'를 저장한 사용자도 최신 홈 동작은 AI만 요청한다.
- `companionChatService.ts`, `companionLlm.ts`, Android JNI/Kotlin 에러 텍스트에서 "기본 반응으로 대체"라는 거짓 안내를 제거한다.
- 기존 `companionResponseMode.ts`와 해당 단위 테스트는 제거한다(메뉴에서 즉시 모드가 사라짐).
- 타 화면의 버튼 도움말과 AI 입력을 구성하는 내장 캐릭터 성격 정보는 보존한다.

## 검증 지침
- Android 모바일 393px 브라우저: 홈 초기 상태·터치 → pending → 실제 AI → 말풍선, legacy instant 설정 무시, 5개 함께하기, 낮잠/수면, 모델 미설치/실행 실패/완성하지 못한 응답, 뒤로가기·모달 열기·재시도를 검사. 테스트에서 AI 응답은 mock이므로 실제 LoRA 품질은 이 테스트로 검증되지 않는다.
- 320px 폭 및 접근성: 더보기, AI 설정, 말풍선/오류 안내 가로 넘침과 화면 위치 확인. 가능하면 변경 전후 캡처.
- `npm run version:check`, Node 단위, TypeScript/Vite, 선택 Playwright/Android 빌드는 CI 증거로 통과 여부 기록.
- 아직 측정하지 않은 실기기 AI 생성 속도·장시간 안정성·AI 말투·기기 메모리 안전성을 검증 완료라고 쓰지 않는다.
