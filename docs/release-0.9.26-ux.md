# 감자싹 0.9.26 화면 정비

사용자가 화면별로 요청한 변경을 하나의 묶음으로 반영한다. 2026-10-25 후속 요청에 따라 커밋·APK 생성과 미뤄 둔 브라우저/Android 검증을 진행한다.

| 영역 | 변경 |
| --- | --- |
| 홈 | 시작하지 않은 분석 완료/대기 표시 숨김, 캐릭터 상시 설명과 원본 접근 실패 안내 제거 |
| 사진 기록 | 상세·등록·수정·분류 버튼 디자인과 터치 영역, 확대창 초점과 지역 편집 취소 정비 |
| 내 앨범 | 갤러리 버튼 글자 유지, 사진 폴더 시작 힌트, 편집·책 감상·선택·내보내기 조작부 정리 |
| 일기 | 읽기 전용 상세 후 명시적 수정 진입, 배고픔·보고싶음·사랑함과 표정 아이콘, 선택·편집 정비 |
| 추억 | 그날 다시·시간 산책·추억책 펼치기 등 이름 정리, 세부 화면 복귀·검색 범위와 여행 경계 보완 |
| 사람·반려동물 | 찾기/관리/편집 버튼 묶음, 공통 선택 하단, 수량 단위, 미저장 보호·조회 재시도·뒤로가기/초점 |
| 도움말·고미 | 내부 스크롤 강조 좌표, 빈 도움말 갱신, 캐릭터/호감도/상황 대사 확장과 반복 완화 |

## 로컬 검증

- 전체 프런트 단위 171개, 앨범·사람·반려동물 SQLite 13개 통과.
- TypeScript·프런트엔드 번들·변경 스타일 파싱·공백 오류 확인. 기존 큰 청크 경고는 남음.
- 버전 파일 5개를 0.9.26으로 맞춘다. Android 영구 서명 정책·앱 ID·Secrets는 유지한다.
- 로컬 Chromium·Rust/Cargo·ADB가 없어 실제 UI/설치 검사는 미실행. 원격 Actions의 실제 결과는 후속 기록에서 별도로 표시한다.

개별 점검 문서의 ‘커밋/APK 미수행’은 각 화면을 수정하던 시점의 기록이다. 최종 사용자 요청은 이 묶음의 커밋과 APK 생성으로 갱신되었다. 설치 검사는 에뮬레이터와 실물 휴대폰을 구별하며, 실제 결과 없이 디자인·출시 합격으로 표시하지 않는다.

## 첫 원격 검사와 후속 수정

`0c8b121`에서 Rust 저장소 128개 및 수정 후 편의성 흐름 22개가 통과했다. 도움말 검사는 135개 통과·14개 실패·7개 제외였다. 고정 팝업이 뒤쪽 스크롤 패널의 잘림을 상속하는 것으로 계산한 오류를 단위 검사에서 실패로 재현하고, 고정 팝업 경계에서 계산을 멈추도록 수정했다. 도움말 테스트는 재측정 중 일시적으로 숨겨진 ‘다음’을 마지막 단계로 오해하지 않도록 준비 상태와 실제 마지막 버튼을 구별한다.

수정 전 비교의 일기 3개 실패는 구버전의 클릭 즉시 편집 흐름에 새 상세→수정 단계를 적용한 검사 조건 때문이었다. 구버전 분기만 보정했다. 반려동물 사진 편집 취소 검사도 미저장 버림 확인을 명시적으로 수락하게 했다. 실패 결과를 삭제하거나 통과로 세지 않고 같은 시나리오로 재검사한다.

후속 코드에서는 전체 화면 안에 들어간 도움말이 자신의 DOM 변화를 관찰하지 않도록 제외한다. 위치 재측정 중에는 강조만 잠시 숨기고 이미 열린 말풍선은 유지해 키보드 초점을 잃지 않게 했다. 연결 사진이 없는 반려동물의 사진 찾기 진입도 유지하며, 안내창 안에서 사진 연결이 필요함을 알리고 실제 찾기 시작은 비활성화한다.
