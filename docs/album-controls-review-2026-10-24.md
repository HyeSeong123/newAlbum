# 내 앨범 검수·수정 기록

기준 `final` / `e3d99b3`, 시작 시 열린 PR 없음. 홈·사진 기록의 기존 미커밋 변경을 보존한다. 커밋·푸시·APK 생성 없이 누적하며 브라우저·실기기 검증은 사람과 반려동물 수정분 커밋 시 함께 진행한다.

## 두 관점의 판단

- 기획자: 앨범 표지와 기존 책 디자인은 유지한다. 버튼 이름을 한 줄로 읽을 수 있고 저장·취소·삭제를 구분할 수 있어야 한다.
- 일반 사용자: 폴더 선택은 사진을 찾기 쉬운 위치에서 시작하고, 검색한 뒤 보이지 않는 앨범이 삭제 대상으로 남지 않아야 한다. 작성 중인 편지·챕터는 실수로 닫아도 내용을 버릴지 선택할 수 있어야 한다.

## 확인 범위와 수정

| 범위 | 소스에서 확인한 문제·조치 |
| --- | --- |
| 공통 가져오기 | 도움말 여유 공간 때문에 ‘갤러리 열기’ 버튼이 좁아져 문구가 줄바꿈됨. 문구는 한 줄로 유지하고 공간 부족 시 버튼 전체가 다음 행으로 이동하도록 수정 |
| 폴더 가져오기 | Android IPC→Rust→Kotlin에 시작 위치 힌트를 전달. 가져오기는 `DCIM`, Windows 등 데스크톱은 OS 기본 사진 폴더로 설정. 내보내기는 기존 위치 선택 방식 유지 |
| 폴더 취소·실패 | 취소 시 등록 호출 없음. 데스크톱 사진 폴더 경로 조회 실패 시 기본 선택기로 대체. 기존 권한 요청·파일 복사·원본 보존 경로 유지 |
| 앨범 목록 | 표지·제목·정렬·검색·선택·더보기·수정·내보내기·삭제 연결 검토. 작은 제목·메뉴·정렬 버튼 터치 영역 보완. 검색어 변경 시 이전 선택 초기화, 삭제 버튼 구분 |
| 앨범 만들기 | 제목·표지색·달력 옵션·만들기·취소 검토. 긴 내용은 스크롤하고 하단 작업행이 남도록 보완. 저장 동작 강조, 닫기·색상 선택 크기 통일 |
| 앨범 수정 | 정보·사진 관리·선택 삭제·페이지·저장·취소·X·뒤로 가기 검토. 기존 초안 보존·실패 재시도 유지. 저장/삭제 표현 및 터치 영역 보완 |
| 앨범 감상 | 이전/다음·이동 막대·챕터/편지 추가·상세·보기 옵션 연결 검토. 하단 버튼·이동 막대 크기와 그에 필요한 하단 높이 보완 |
| 편지·챕터 | 삽입 위치·본문·저장·삭제 검토. 수정 중 취소·X·뒤로 가기에서 버림 여부 확인. 계속 작성하면 초안 유지 |
| 내보내기 | 경로 선택·취소·내보내기·완료 닫기 검토. 버튼 크기/줄 배치 보완. 키보드 초점 순환, 완료 후 닫기 버튼 초점 추가 |

이 표는 소스 검토 결과이며 실제 화면·클릭 검증을 뜻하지 않는다. 원본 사진·앨범 기록·일기 연결·앱 버전·서명 설정을 변경하지 않는다.

## 검증 상태

- 통과: TypeScript 검사, 변경 공백 검사, 폴더 가져오기/취소·내보내기 분리·경로 조회 실패 대체 검사와 앨범 내용/순서 보존·Android 준비 검사 총 36개.
- 추가한 폴더 선택 검사: `tests/media-folder-picker.test.mjs`. `npm run test:unit`에도 포함했다.
- 브라우저 검증 준비: 가져오기 버튼 한 줄/넘침 검사, 편지 초안의 X·취소·Escape 복구 검사. 테스트 수집만 확인하고 실행은 보류한다.
- 미검증: 320/393px 실제 배치·도움말 겹침·버튼 클릭·전후 캡처, 네이티브 Rust/Kotlin 빌드, Android 시스템 선택기 시작 위치·선택/취소·권한 거부, Windows 기본 사진 폴더 동작, 실기기 저장/재진입.
- Android 시작 위치는 시스템 선택기에 전달하는 힌트다. 해당 위치를 찾지 못하면 제조사/제공자 기본 위치가 열릴 수 있으므로 실기기에서 확인해야 한다.

구현 근거: [Android DocumentsContract.EXTRA_INITIAL_URI](https://developer.android.com/reference/android/provider/DocumentsContract#EXTRA_INITIAL_URI), [Tauri pictureDir](https://v2.tauri.app/reference/javascript/api/namespacepath/#picturedir).
