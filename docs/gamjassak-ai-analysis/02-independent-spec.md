# 02. 감자싹 자체 AI 엔진 기능 명세 (클린룸 구현 계약)

원칙: 사람/반려동물 탐지·특징·자세 모델은 **제3자 가중치/체크포인트/teacher 출력 없이**, 새롭게 설계한 네트워크를 무작위 초기화하고 권리 확보된 데이터로 학습한다. 모델 런타임은 별도로 라이선스를 검토한다. 각 기능에서 모델 미학습/미검증을 숨기지 않는다.

## 통합 계약

- 새 엔진은 기존 React/Tauri/SQLite 앱을 유지하고 모델 기능을 독립 인터페이스 뒤에 연결한다.
- 전처리, 좌표계(사진 좌측=left, 우측=right), 후면 처리 정책을 문서화하여 모델 변경에도 UI 의미를 보존한다.
- 미등록 개체를 강제로 등록된 인물/반려동물로 연결하지 않는다.
- 모델별 dataset manifest: 파일 해시, 수집 출처, 권리 증빙, 개인정보/동의, 주석 검토 기록, 학습/평가 분리 메타데이터.
- 모델별 provenance: 네트워크 명세/버전, 초기화 seed, 데이터셋 manifest hash, 학습 config, optimizer/epochs, checkpoint hash, 평가 보고서.
- 기준 사진·검증 사진은 원본/동일 촬영 세션·중복/파생 이미지를 양쪽으로 분할하지 않는다.
- 정확도 60% 목표는 강아지/고양이 각각 측면 Top-1 등 실험 프로토콜로 별도 계산하고 Wilson 95% 신뢰구간 하한까지 보고한다. 달성 전 목표를 달성했다고 쓰지 않는다.
- 휴대폰용 추론을 위해 최종 모델 크기·피크 메모리·p50/p95 추론 시간·발열/배터리를 ARM64 실기기에서 측정한다.

## 단계별 수용 기준

1. **설계 완료:** 완전 독립 기능 계약, 모델/데이터 라이선스 규칙, 가중치 미포함 테스트가 존재.
2. **프로토타입:** 합성 데이터 기반 신경망 학습 및 추론이 실제 실행되고 checkpoint가 무작위 초기화에서 생성되었다는 기록.
3. **실제 학습:** 학습 데이터 권리 증빙을 동반한 데이터셋으로 직접 훈련 후 held-out 평가.
4. **호환 통합:** 사용자 확인/연결·삭제·재분석·다중선택·100장 가져오기 회귀 통과; 기존 DB 롤백 가능.
5. **상업 배포:** 실물 APK/AAB 자산·의존성·권리/개인정보 검토 완료; 외부 사전학습 가중치 0, 외부 네트워크 모델 요청 0.
