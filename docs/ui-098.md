# 0.9.8 사진 직접 등록과 등록 목록 재학습

- 사람 목록의 ‘사진 직접 등록’에서 이름과 사진을 선택해 얼굴 감지 없이 등록한다. 사람·반려동물 상세에서도 같은 버튼으로 사진을 연결하거나 해제한다. 선택은 페이지 이동 뒤에도 유지하며 취소는 저장하지 않는다.
- 사람의 직접 연결은 `person_photo`에 별도로 저장한다. 인물 목록·사진 개수·앨범·내보내기에 감지된 얼굴의 원본과 합쳐 사용하며 중복 원본은 한 장으로 센다. 직접 등록 사진은 얼굴 분석 초기화·재학습 실패·얼굴 미검출에도 남는다. 여러 사람에게 같은 사진을 연결할 수 있다.
- 얼굴로 연결된 사진은 직접 등록 창에서 읽기 전용으로 표시한다. 얼굴의 인물 연결은 기존 사진 정리에서 바꾼다. 같은 이름을 합칠 때 직접 연결한 사진도 함께 옮긴다.
- 사람·반려동물 목록의 ‘등록 목록 다시 학습’과 상세의 ‘등록 사진 다시 학습’은 캐시를 건너뛰고 사진을 다시 분석해 인식 기준의 특징을 갱신한다. 학습 중 진행·중단, 완료 시 갱신·미검출·실패 결과를 표시한다. 모델 가중치를 새로 훈련하는 기능은 아니다.
- 사람은 원본 지문과 얼굴 위치를 확인해 기존 얼굴 ID·확인 여부·대표 얼굴·수동 방향·이름을 보존하며 128/512차원 특징을 갱신한다. 대응이 모호하거나 원본·모델이 달라지면 기존 기록을 유지하고 실패로 보고한다. 직접 등록한 단독 인물 사진은 유일한 사람에게 연결하며, 여러 얼굴이나 여러 등록자가 나온 사진은 자동으로 이름을 확정하지 않는다.
- 반려동물은 동일한 영구 대기열에 재학습 작업을 저장한다. 기존 개체 ID·사진 연결·방향·직접 지정한 영역을 보존하고 기준 특징을 다시 추출한다. 재학습 작업은 중단·앱 재시작 후에도 이어서 실행할 수 있다.
- SQLite 버전 16→17은 직접 연결 테이블과 재학습 플래그만 추가한다. 기존 얼굴·반려동물·사진·대기 작업은 유지한다.

검증: 로컬 빌드·단위 검사 결과 및 최종 브라우저·설치형 Android 결과를 완료 후 기록한다. 개체 식별 정확도나 실제 ARM64 휴대폰 처리 속도 측정은 이 작업에 포함하지 않는다.
