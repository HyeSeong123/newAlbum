# 감자싹 UX/UI · 기획자와 일반 사용자 교차 검토

작성일: 2026-10-23 한국 시간. 대상: 사진 선택, 앨범, 인물·반려동물, 일기장, 즐겨찾기, 탐색·뒤로 가기.

`feature/warm-journal-v2` (`cd3d1be`)를 요청 기준으로 확인했다. 이미 전달한 0.9.17의 인물·반려동물 UX와 기존 모델 제거·영구 서명을 보존하기 위해 실제 수정은 그 통합 결과 `8e7f343`에서 분기한 `feature/app-ux-20261023`에서 수행했다. 원래 브랜치와 master에는 병합하지 않았다. 전체 변경 이력은 [작업 브랜치](https://github.com/HyeSeong123/newAlbum/tree/feature/app-ux-20261023)에서 확인할 수 있다. 앱 버전은 0.9.18이며 DB 버전 19와 인식 모델·저장 스키마는 변경하지 않았다.

**평가 방법:** A는 새로 캡처한 화면과 코드의 이벤트 처리로 설계 원칙을 검토했다. B는 A의 해결안을 적용하기 전에 각 작업의 기대 동작을 별도 문장으로 기록하고 실제 클릭 결과와 비교했다. 이후 A/B의 충돌을 조정해 구현하고 같은 흐름을 재실행했다. 이는 두 관점의 페르소나 시뮬레이션이며 독립된 실제 참여자를 모집한 사용성 실험이 아니다. 점수는 관찰에 근거한 불편도 추정이다.

## A/B 교차 검증과 결정

- A는 공간 확보를 위해 아이콘 위주의 메뉴를 고려할 수 있지만, B에게 화살표만으로는 목적지 이름이 드러나지 않았다. 텍스트 ‘전체 메뉴’를 선택했다. 기존 메뉴·화살표도 유지한다.
- A의 ‘삭제’는 흔한 관리 용어지만 B는 원본 파일 삭제로 읽었다. 사진 등록 해제·앨범 삭제·일기 삭제·사진 첨부 해제를 구분하고 실제 데이터 처리는 유지한다.
- 일기 앨범 지정은 A의 컨테이너 관점에서는 ‘이동’으로 볼 수 있으나 B는 일기장 목록에서 사라질 것으로 예상한다. 실제 목록을 보존하는 ‘연결’이라는 표현을 채택했다.
- 모든 선택 대상에 같은 작업을 붙이지 않는다. 사진은 앨범 만들기·지역 수정·등록 해제, 앨범 자체는 수정·삭제, 일기는 앨범 연결, 얼굴은 이름 지정·다른 인물·미확인·제외를 제공한다. 개수·전체 선택·해제·취소·배치만 공통화한다.
- 선택 중 보조 검색을 접어 사진과 작업 바를 함께 보이게 했다. 검색 조건과 보기 상태를 삭제하지 않으며 선택 취소 시 다시 보여 준다.

## 화면과 검증의 한계

비교 화면은 이번 감사 실행에서 같은 fixture와 Pixel 7 뷰포트로 새로 캡처했다. 최초 전체 페이지 캡처 중 고정 헤더가 중간에 잡히거나 지연 이미지가 비어 있는 프레임은 최종 비교에서 제외하고, 실제 뷰포트·표시 이미지 로딩 확인 후 다시 캡처했다. 변경 전 감사 서버의 외부 의존성 심볼릭 링크 때문에 일기 로컬 글꼴이 빠진 프레임도 채택하지 않고, 동일한 의존성을 작업 트리 안에 복사한 뒤 다시 촬영했다. 과거 보고서 이미지를 이번 근거로 재사용하지 않았다.

브라우저 검사는 테스트용 Tauri 응답을 사용한다. 브라우저의 실제 HTML 파일 선택기와 Android의 네이티브 파일 선택기·SQLite 쓰기·시스템 뒤로는 각 환경에서 따로 확인하며, 두 결과를 구분한다. 실물 휴대폰·TalkBack·실제 사용자 참여 실험은 진행하지 못했다. 모든 기기·화면·보조 기술에서 학습 없이 사용할 수 있다고 보증하지 않는다. 주 메뉴 사이 이동은 별도 화면 전환으로 검색/선택을 초기화하는 기존 정책을 유지하며, 같은 메뉴 재탭·선택 취소·상세 모달 닫기·인물/반려동물 목록 복귀의 상태 보존을 이번에 명확히 했다.
