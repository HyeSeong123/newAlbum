# 0.9.6 사진 가져오기·사람과 반려동물 UI 개선

- Android 갤러리에 감자싹 색상, 정사각형 썸네일, 짧은 날짜, 영상 표시, 선택 체크와 하단 고정 가져오기 버튼을 적용했다. 기존 최근 수정 순 정렬·권한 안내·다중 선택은 유지한다.
- 사람 이름 편집을 별도 대화상자로 이동했다. 이름 없는 사람은 사진을 누르면 등록 창이 열리고, 새 이름 입력과 등록한 사람 선택 중 하나만 사용한다.
- 반려동물 이름·표지·연결할 사진은 스크롤 가능한 본문에 배치하고 취소·저장 버튼을 하단에 고정했다. 두 편집 창 모두 초점 이동과 Escape 닫기를 지원한다.
- 중복 안내 카드를 제거하고 자동 얼굴 비교를 ‘이름 추천 확인’으로 구분했다. 사진 정리 화면은 작업을 고르면 해당 입력과 실행 버튼만 보여 준다.

## 검증

로컬 단위 검사 126개, TypeScript 및 프로덕션 빌드 통과. 기존 얼굴 이동·이름 저장·반려동물 등록·터치 선택 회귀 검사를 새 동선에 맞췄다. 320/360/393px 기본·크게 보기에서 편집 창 하단 버튼을 검사하고 화면을 캡처한다. Android 갤러리 검사에 제목과 선택 개수 표시를 추가했다. [Source validation 38108534597](https://github.com/HyeSeong123/newAlbum/actions/runs/38108534597)에서 JS 단위 126개, 브라우저·브랜딩 286개, Rust 108개와 레거시 SQLite 검사 19개, TypeScript·프로덕션 빌드가 통과했다. 편집 창 캡처 12장을 확보했다. [Android preview 38108534602](https://github.com/HyeSeong123/newAlbum/actions/runs/38108534602)도 성공했다. API 36 x86_64 에뮬레이터에서 갤러리 권한 거부·취소, 최근 수정 순 정렬, 사진 2장과 영상 1개 다중 선택·가져오기, 선택 개수 표시를 확인했다. 기존 오프라인 사람·반려동물 모델 실행과 저장, 100회 분석 및 99회 도메인 전환도 통과했다.

사용자 설치 파일은 해당 실행의 `Gamjassak-Android-0.9.6` 아티팩트에 있는 `Gamjassak-0.9.6.apk`다. 아티팩트 ID는 `11690412785`이며 ARM64 휴대폰용이다. 에뮬레이터 검사는 실제 ARM64 휴대폰 성능이나 인물/개체 식별 정확도 측정을 대신하지 않는다.

## Android 기동 검증에서 수정한 항목

API 36 설치 검사에서 `setContentView` 이전의 `WindowInsetsControllerCompat` 생성이 아직 없는 DecorView를 참조해 갤러리 기동이 실패했다. 시스템 바 설정을 화면 설치 뒤로 옮겼다. 기존 권한 거부·재허용·정렬·다중 선택·Rust 가져오기 검사가 이 경로를 실제로 실행한다. 실패한 중간 APK를 최종 다운로드로 사용하지 않는다.
