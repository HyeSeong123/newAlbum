# 0.9.6 사진 가져오기·사람과 반려동물 UI 개선

- Android 갤러리에 감자싹 색상, 정사각형 썸네일, 짧은 날짜, 영상 표시, 선택 체크와 하단 고정 가져오기 버튼을 적용했다. 기존 최근 수정 순 정렬·권한 안내·다중 선택은 유지한다.
- 사람 이름 편집을 별도 대화상자로 이동했다. 이름 없는 사람은 사진을 누르면 등록 창이 열리고, 새 이름 입력과 등록한 사람 선택 중 하나만 사용한다.
- 반려동물 이름·표지·연결할 사진은 스크롤 가능한 본문에 배치하고 취소·저장 버튼을 하단에 고정했다. 두 편집 창 모두 초점 이동과 Escape 닫기를 지원한다.
- 중복 안내 카드를 제거하고 자동 얼굴 비교를 ‘이름 추천 확인’으로 구분했다. 사진 정리 화면은 작업을 고르면 해당 입력과 실행 버튼만 보여 준다.

## 검증

로컬 단위 검사 126개, TypeScript 및 프로덕션 빌드 통과. 기존 얼굴 이동·이름 저장·반려동물 등록·터치 선택 회귀 검사를 새 동선에 맞췄다. 320/360/393px 기본·크게 보기에서 편집 창 하단 버튼을 검사하고 화면을 캡처한다. Android 갤러리 검사에 제목과 선택 개수 표시를 추가했다. Actions 실행 결과와 실제 렌더링 검증은 완료 후 기록한다.
