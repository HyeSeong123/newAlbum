# 곰고미 캐릭터 그림과 설정 점검

0.9.60은 그림에 맞춰 기본 이름을 고쳤다. 이번에는 현재 그림과 몸짓, 행동 대사, 성장 설명까지 17종 전체를 대조했다. 디자인이 모호했던 갈매기·소보로·인삼을 새 그림으로 교체했다. 다른 지역 친구는 원본 시트에서 각자 한 장씩 분리해 옆 그림 조각이 따라오지 않게 했다. 기존 사진과 연결되는 캐릭터 ID, 저장한 별명·성장·친밀도·대표 선택은 동일한 값을 쓴다.

홈에서 대표를 고르면 도감과 같은 그림을 표시한다. 도움말, 설정, 발견과 성장 알림도 같은 그림을 사용한다. 도감에서 이름을 비워 저장하면 그림에 맞는 기본 이름을 표시한다. 갈매기의 새우 과자와 인삼의 물 주기는 미리 준비한 행동 반응을 표시한다. 말 걸기 및 기존 AI 행동에는 이전 모델을 그대로 사용한다. 지역 친구는 성장 단계마다 같은 실루엣을 사용하고 단계 수와 성장 조건을 보존한다.

기존 원본은 `public/characters/portraits/`에 보존한다. 앱에 표시하는 16개의 개별 WebP는 `public/characters/portraits/current/`에 있다. 고미는 기존 자세별 PNG를 사용하며 홈에서 친구를 불러오는 동안에도 고미를 표시한다. 감자와 고구마는 기존 애니메이션 시트를 사용한다.


## 0.9.62 색연필로 통일한 도감

고미의 부드러운 갈색 윤곽, 색연필 결, 낮은 채도의 따뜻한 색을 기준으로 지역 친구 14종을 다시 그렸다. 날개와 부리, 음식의 재료, 한글의 ㄱ자 실루엣처럼 이름을 알아보는 단서는 유지했다. 감자와 고구마는 고미와 같은 계열의 기존 색연필 애니메이션을 그대로 사용한다.

지역 친구의 새 그림은 `public/characters/portraits/pencil/`에 있다. 공통 캐릭터 그림을 통해 홈·도감·성장 알림·도움말에 적용한다.

해실은 예의와 배려를 중히 여기는 선비다. 홈에서 말을 걸거나 함께하기를 누르면 관계와 행동에 맞는 조선풍 대사를 들려준다. 도움말에서는 정중한 조선풍 한마디 뒤에 현대어로 조작을 안내한다. 해실의 대사는 미리 작성한 여러 문장 중 상황에 맞춰 표시한다.

## 0.9.64 도롱이의 성격과 말투

하회탈 친구의 기본 이름을 해실에서 도롱이로 바꿨다. 도롱이는 먼저 나서기보다 친구가 놓친 일을 조용히 거든다. 불러 주지 않으면 가끔 서운함을 비치고, 가까워지면 기다렸다는 말도 건넨다. 홈과 함께하기에서는 조선풍 하오체와 하게체를 쓰고, 도움말은 짧은 인사 뒤 현대어로 안내한다. 직접 붙인 별명은 그대로 보이며 그림과 성장 기록을 이어 간다.

## 0.9.65 도롱이의 그림, 움직임, 오프라인 AI

색연필로 그린 하회탈과 검은 모자를 살리고, 허리띠와 발이 보이는 선비옷으로 바꿨다. 도롱이는 기지개를 펼 때도 그림 비율을 유지하며 이동과 기울기로 움직인다.

홈에서 말을 걸거나 함께하기를 누르면 기존 오프라인 추론기가 도롱이 전용 가중치로 상황에 맞는 짧은 조선풍 대사를 생성한다. 생성이 실패하면 같은 행동을 다시 시도하거나 기본 대사를 볼 수 있다. 지켜보기와 도움말은 추론을 시작하지 않는다. 고미와 다른 친구들의 가중치와 기존 저장 기록은 유지한다.

도롱이 가중치는 `python local-ai/own/train.py --dorongi --epochs 80`으로 별도 학습한다. `local-ai/own/dorongi-drafts.json`에는 출처를 밝힌 학습 초안이 들어 있다.

## 0.9.66 친구마다 다른 함께하기

대표 친구를 바꾸면 홈의 함께하기에 아래 행동이 표시된다. 각 행동은 화면 속 상상 활동이다. 기존 행동 슬롯과 친밀도 규칙, 활력, 최근 기록 형식은 유지한다.

| --- | --- |
| 고미 | 함께 산책, 간식 주기, 쓰다듬기, 함께 놀기, 함께 쉬기 |
| 알토 | 물 주기, 새싹 박수 놀이 |
| 구마루 | 햇볕 쬐기, 흙 언덕 넘기 |
| 도롱이 | 고요한 길 걷기, 햇볕 나누기, 한 판 두기, 나란히 쉬기 |
| 톡귤 | 귤밭 걷기, 귤 굴리기 |
| 후루 | 김 식혀 주기, 김 모양 맞히기 |
| 끼룩 | 바닷가 걷기, 새우 과자 주기, 연 날리기 |
| 온빛 | 구름 걷어 주기, 그림자 밟기 |
| 짜루 | 면발 길이 재기, 나란히 쉬기 |
| 보슬 | 빵집 골목 걷기, 빵집 놀이 |

| 두두 | 비밀 쪽지 건네기, 호두 탐정 놀이 |
| 삼동 | 숲길 걷기, 물 주기, 열매 숨기기 |

친구 전용 행동에서 바로 표시하는 대사에는 ‘행동 반응’이 붙는다. 도롱이의 버튼은 이미 학습한 행동에 연결하므로 AI가 조선풍으로 답한다. 알토에게 물을 주면 물방울을 보여 주고 구마루는 햇볕을 받는 기존 효과를 쓴다. 도움말은 화면에 보이는 버튼 이름으로 안내한다.
