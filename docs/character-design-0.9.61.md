# 곰고미 캐릭터 그림과 설정 점검

0.9.60은 그림에 맞춰 기본 이름을 고쳤다. 이번에는 현재 그림과 몸짓, 행동 대사, 성장 설명까지 17종 전체를 대조했다. 디자인이 모호했던 갈매기·소보로·인삼을 새 그림으로 교체했다. 다른 지역 친구는 원본 시트에서 각자 한 장씩 분리해 옆 그림 조각이 따라오지 않게 했다. 기존 사진과 연결되는 캐릭터 ID, 저장한 별명·성장·친밀도·대표 선택은 동일한 값을 쓴다.

홈에서 대표를 고르면 도감과 같은 그림을 표시한다. 도움말, 설정, 발견과 성장 알림도 같은 그림을 사용한다. 도감에서 이름을 비워 저장하면 그림에 맞는 기본 이름을 표시한다. 갈매기의 새우 과자와 인삼의 물 주기는 미리 준비한 행동 반응을 표시한다. 말 걸기 및 기존 AI 행동에는 이전 모델을 그대로 사용한다. 지역 친구는 성장 단계마다 같은 실루엣을 사용하고 단계 수와 성장 조건을 보존한다.

기존 원본은 `public/characters/portraits/`에 보존한다. 앱에 표시하는 16개의 개별 WebP는 `public/characters/portraits/current/`에 있다. 고미는 기존 자세별 PNG를 사용하며 홈에서 친구를 불러오는 동안에도 고미를 표시한다. 감자와 고구마는 기존 애니메이션 시트를 사용한다.


## 0.9.62 색연필로 통일한 도감

고미의 부드러운 갈색 윤곽, 색연필 결, 낮은 채도의 따뜻한 색을 기준으로 지역 친구 14종을 다시 그렸다. 날개와 부리, 음식의 재료, 한글의 ㄱ자 실루엣처럼 이름을 알아보는 단서는 유지했다. 감자와 고구마는 고미와 같은 계열의 기존 색연필 애니메이션을 그대로 사용한다.

지역 친구의 새 그림은 `public/characters/portraits/pencil/`에 있다. 공통 캐릭터 그림을 통해 홈·도감·성장 알림·도움말에 적용한다.

## 0.9.63 친구들의 새 기본 이름

직접 붙인 이름이 있으면 홈, 도감, 도움말과 성장 알림에서 그 이름을 먼저 쓴다. 이름을 비워 저장하면 새 기본 이름을 표시한다. 도감에 친구의 모습도 함께 표기한다. 아직 만나지 않은 친구의 이름과 모습은 발견 전까지 숨긴다.

고미의 기본 이름은 고미다. 캐릭터를 연결하는 ID와 저장 기록, 그림과 모델은 유지했다.

해실은 예의와 배려를 중히 여기는 선비다. 홈에서 말을 걸거나 함께하기를 누르면 관계와 행동에 맞는 조선풍 대사를 들려준다. 도움말에서는 정중한 조선풍 한마디 뒤에 현대어로 조작을 안내한다. 해실의 대사는 미리 작성한 여러 문장 중 상황에 맞춰 표시한다.
