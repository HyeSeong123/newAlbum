# 곰고미 캐릭터 그림과 설정 점검

0.9.60은 그림에 맞춰 기본 이름을 고쳤다. 이번에는 현재 그림과 몸짓, 행동 대사, 성장 설명까지 17종 전체를 대조했다. 디자인이 모호했던 갈매기·소보로·인삼을 새 그림으로 교체했다. 다른 지역 친구는 원본 시트에서 각자 한 장씩 분리해 옆 그림 조각이 따라오지 않게 했다. 기존 사진과 연결되는 캐릭터 ID, 저장한 별명·성장·친밀도·대표 선택은 동일한 값을 쓴다.

| 앱 이름 | 현재 그림과 식별 특징 |
| --- | --- |
| 고미 | 살구빛 곱슬털 푸들. 기존 수면·표정 그림 유지 |
| 감자 | 둥근 연노랑 몸과 두 잎. 움직임을 불러오는 동안 같은 그림의 기본 자세 표시 |
| 고구마 | 길쭉한 보랏빛 몸과 하트 잎. 움직임을 불러오는 동안 같은 그림의 기본 자세 표시 |
| 하회탈 | 검은 모자와 웃는 탈. 쓰다듬기 반응은 모자를 언급 |
| 귤 | 초록 잎과 껍질의 점이 있는 둥근 귤 |
| 컵라면 | 빨간 줄무늬 종이컵과 열린 뚜껑 |
| 갈매기 | 새로 그린 흰 깃털, 회색 날개와 긴 노란 부리. 함께하기에서 새우 과자를 건넴 |

홈에서 대표를 고르면 도감과 같은 그림을 표시한다. 도움말, 설정, 발견과 성장 알림도 같은 그림을 사용한다. 도감에서 이름을 비워 저장하면 그림에 맞는 기본 이름을 표시한다. 지역 친구는 성장 단계마다 같은 실루엣을 사용하고 단계 수와 성장 조건을 보존한다.

기존 원본은 `public/characters/portraits/`에 보존한다. 앱에 표시하는 16개의 개별 WebP는 `public/characters/portraits/current/`에 있다. 고미는 기존 자세별 PNG, 감자와 고구마는 기존 애니메이션 시트를 사용한다.
