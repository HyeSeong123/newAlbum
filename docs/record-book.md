# 추억 기록책

## 저장과 호환성

`SavedAlbum.items`는 기존 사진 관리·표지·내보내기와 호환되는 미디어 목록이다. `contents`는 PHOTO / VIDEO / AUDIO / CHAPTER / TEXT를 한 순서로 표현한다. 이전 앨범 응답에 `contents`가 없으면 기존 미디어 순서로 생성한다.

사진·영상·음원은 기존 `album_item`에 저장한다. 챕터와 글은 추가 테이블 `album_page`에 저장하며 두 테이블은 같은 `sequence` 순서를 사용한다. `CREATE TABLE IF NOT EXISTS`로 기존 데이터베이스에도 추가되므로 미디어 테이블이나 기존 앨범 행을 다시 만드는 마이그레이션은 하지 않는다.

구성 편집은 검증 후 트랜잭션 하나로 반영한다. 제목·본문·종류·미디어 존재 여부·재생 시간을 검증하고, 실패하면 앨범 제목과 구성 모두 롤백한다. 원본 파일은 읽기만 하며 앨범에서 제거해도 삭제하지 않는다.

## 편집과 책 보기

앨범 메뉴의 **앨범 수정 → 앨범 구성**에서 삽입 위치를 선택한다. 구성 항목은 위·아래로 이동하거나 제거할 수 있다. 큰 앨범의 구성 목록은 20개씩 편집한다.

챕터와 글은 책의 한쪽 면을 사용하는 페이지다. 사진은 같은 구간 안에서만 세로 4장·가로 2장으로 묶는다. 따라서 사진의 가로·세로 분류가 챕터 경계를 넘지 않는다. 원본 비율, 제목과 촬영 날짜, 책장 넘김을 유지한다.

## 구현 순서와 검증

1. 챕터: 기존 앨범 호환, 삽입·순서·삭제, 전용 책 페이지.
2. 글 페이지: 제목·본문, 삽입·수정·삭제, 미디어 없는 페이지.
3. 스토리: 같은 구성의 사진·영상·글·챕터 재생, 음악, 자막, 시간·전환 설정.
4. 추억: 과거의 오늘·이번 달 기록을 유형별 순수 함수로 추출.
5. 타임라인: 기존 그리드·달력 옆에서 연도·월·날짜별 탐색.

각 단계에서 TypeScript 빌드, 기존 및 신규 단위 테스트, 주요 Playwright 화면 테스트, Windows 패키징과 기존 방식으로 만든 앨범의 저장·재실행 검증을 수행한다. 코드 반영 대상은 `feature/warm-journal-v2`다.
