# 고미의 행동 반응 재학습 ·0.9.54

사용자가 보고한 '나 졸리단 말이야. 조금만 더 같이 해볼까?'는 수면/먹이 상황에 놀이 표현이 섞인 오류다. 이전 생성 성공·길이 검사만으로 자연스러움까지 확인했다고 볼 수 없었다.

사용자가 새로 알려준 행동 기준: 잠든 상태에 간식이나 밥을 주면 눈을 게슴츠레 뜨고 멍하니 있다가 먹으러 온다. 너무 피곤하면 계속 잔다. 실제 대사를 제공한 것은 아니므로 아래 학습용 발화는 AI 개발 도우미가 작성한 파생 초안으로 표시한다.

## 바꾼 부분

- 고미의 기존 문장 조합 초안을 일관된 완성 발화 자료로 교체했다. 사용자 원문30행과 원본 파일은 보존했고, 새 초안을 친밀도5단계·수면·피로·행동·의도로 나눴다.
- PC의 기존 Python3.12.16/NumPy2.4.2 환경에서 자체 신경망을 무작위 가중치부터180epoch 다시 학습했다.343.358초가 걸렸다. 학습 행16,926개는 상태별 반복을 포함한다. 고미 새 초안3,936행, 고미 원문30행, 기존 다른 캐릭터 초안12,960행이며16,926개의 독립적인 사람 원문이 아니다.
- 모델436,521바이트,181,318parameter. SHA256 `affaa21cb0cae8aba316a5643dac0ae33423468a2f0ac41e5b9b6a269a686b52`. 외부 부모 모델/교사 API는 없고, 자체 순전파·역전파·AdamW·앱 추론 코드를 사용한다.
- 문장 경계에서도 최근4단어를 유지한다. 학습 자료의 상황/의도별 연속3단어 연결 안에서 신경망 확률로 다음 단어를 만든다. APK에 완성 대사 목록을 넣어 고르는 경로는 없다.
- 활력0은 극심한 피로, 수면 중 활력1이상은 일반 졸림이다. 간식을 주기 전 피로를 전달하며, 먹기도 전에 활력이 오르지 않는다. 간식 자체를 잠 방해 친밀도 감소로 처리하지 않는다.
- 일반 졸림의 간식 동작은 기존 peek→rest-front→idle 그림 순서로, 극심한 피로는 계속 수면으로 처리한다. 밥은 학습/PC 시험에서 지원하며 앱에 새로운 밥 버튼이나 식사 감지 기능을 추가하지 않았다.
- 최근12개를 우선 피하고 표현을 소진하면 최근3개를 피하며 같은 상황에서 다시 생성한다. 즉시 반복과 다른 행동 대사로의 전환을 피하면서 유한한 학습 표현 때문에 사용이 중단되지 않게 한다.

## 실제 개발 검증

수학/학습 계약 Python5개 통과, 영향받은 Node 검사·타입 검사 통과. PC 개발 표본287상황×12회=3,444회에서 생성 오류0, 정의한 행동/피로/역할 오류0이었다. 단순한 동작 키워드 반복을 강요하지 않고 '아직 못 일어나', '밥은 옆에 놔둬'처럼 문맥상 맞는 생략 표현도 허용한다.

예를 들어 실제 PC 표본에서 일반 졸림의 밥에는 '밥이야? 잠깐만, 나도 갈게.', 극심한 피로에는 '너무 졸려. 밥은 나중에 먹을래.'가 생성됐다. 간식의 일반 졸림에는 '나 일어나고 있잖아. 간식은 남겨놔.', 극심한 피로에는 '지금은 간식도 됐어. 더 잘 거야.'가 생성됐다. 이 문장들을 사용자 원문이나 독립적인 사람의 품질 승인으로 표시하지 않는다.

같은 상황의 미리 쓴 전체 문장을 재현한 경우와 학습에 없던 조합을 구분해 `test-results/own-character-ai.json`에 기록한다. 개발 도우미가 실제 발화 표본을 읽고 검사했지만 모든 한국어·성격 표현의 자연스러움을 보증하는 평가는 아니다. 별도 코드 리뷰에서는 막히는 오류를 발견하지 않았으며, 빠른 연속 동작·애니메이션 도중 앱을 내리는 경우까지 설치 검증했다고 주장하지 않는다.

## PC 사용과 앱 적용

`곰고미-AI-실행.cmd`의3번에서 `간식 75 잠`, `간식 75 피곤`, `밥 75 잠`, `밥 75 피곤`을 비교한다.5번에서 내JSONL 자료를 편집하고2번에서 추가 자료를 포함해 다시 학습한다. 형식과 새 행동 추가는 [전용 AI 안내](../local-ai/own/README.md)를 따른다.

커밋 후 기존 영구 서명키를 사용하는0.9.54 APK를 생성하고, 설치한 에뮬레이터에서8회 수면 터치와 졸림/극심한 피로 간식 버튼을 검사한다. 실제 앱이 읽은 모델 바이트를 위 해시와 비교한다. 최종 빌드·APK·설치 지연은 작업 폴더의 배포 결과에 별도로 기록한다. 갤럭시26 실측은 기기 미연결로 미검증이며, 기존 사진 인식 권리의 남은 확인 사항은 [상업 배포 기록](own-character-ai-commercial-2026-11-15.md)을 유지한다.
