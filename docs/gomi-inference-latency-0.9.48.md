# 고미 실제 4B AI 생성 지연 최적화 (0.9.48)

기준: `final` 0.9.47 / 2026-11-01 실기기 사진: 모델 로딩 0.3초, 메모리 준비 0.1초, 첫 글자 83.4초, 전체 85.7초, 관측 메모리 최대 2994MB.

## 사용자 의도 및 UX 검토
- **목표는 1초 이내에 *실제 학습 모델이 만든 새 답변*을 얻는 것**이지, 기본 대사를 1초 이내 표시하는 게 아니다. 0.9.47의 즉시 기본 대사 모드만으로 문제를 해결했다고 볼 수 없다.
- 기획자: 오프라인·기존 LoRA 학습 내용 보존, 모델·캐릭터별 데이터 분리, 8GB 스마트폰 메모리 안정성이 최우선이다. 단순히 1초를 표기하는 대신 실제 prefill/decode를 분리 측정한다.
- 사용자: 기본값은 **실제 AI 생성**으로 복구한다. 기존 기본 대사는 AI 결과 전 임시 표시로 남기되 출처를 계속 구분한다. 즉시 기본 대사만 원하면 설정에서 명시적으로 선택한다.

## 1차 소스 최적화
1. 고미 프롬프트는 성격·산책·목줄·숟가락질·방문객·애착 규칙을 유지하면서 장황한 반복 설명과 최근 대사를 축소했다. 시스템 규칙을 먼저 두고 동적 기분·친밀도·버튼 정보·최근 말은 뒤로 보내 입력 KV 공통 접두어를 최대화했다. 실제 모르는 생활 사건은 여전히 꾸며내지 않는다.
2. Android llama.cpp JNI는 기존 4B/LoRA를 그대로 사용하되, 홈이 살아 있는 동안 **모델 파일+LoRA 파일 조합이 동일하면 컨텍스트를 재사용**한다. 새 입력과 이전 입력의 공통 토큰 접두어에 대해서만 KV를 남기며 마지막 토큰은 반드시 재계산한다. 다른 캐릭터/모델, 오류·취소, 홈을 떠남, Android 메모리 압력에서는 컨텍스트를 버려 교차 오염을 막는다.
3. 출력 최대 토큰은 192→128로 조정한다. 50자 내외 대사 목적에 맞추되, 실제 한국어 품질에 따라 재조정한다.
4. Native 측정치를 **입력 토큰 수·재사용 토큰 수·입력 처리 시간·컨텍스트 재사용 여부**로 세분화해 기존 AI 반응 설정 > 최근 실행 기록에 표시한다. 입력 문장·개인 정보는 기록하거나 서버에 전송하지 않는다.
5. `companionResponseMode` 신규 설치 기본값을 `generate`로 되돌린다. 이미 사용자가 직접 선택해 저장한 모드는 그대로 존중한다. 빠른 기본 대사 모드는 보조 기능으로만 남긴다.

## 위험과 검증 범위
- 직접 수정한 파일: `companion.cpp`, `model_session.h`, `companionTouch.ts`, `companionChatService.ts`, `CompanionAiSetup.tsx`, `companionResponseMode.ts`, 관련 단위/모바일 브라우저 테스트.
- 단위: `tests/companion-session.test.mjs`가 컴파일하는 실제 C++ helper 검사로 공통 접두어 길이와 마지막 토큰 재계산 확인. `tests/companion-touch.test.mjs`는 고미 프롬프트 길이/공통 성격 접두어/안전한 상황을 점검. `tests/companion-response-mode.test.mjs`는 실제 AI 기본값과 수동 즉시 대사 설정을 확인한다.
- 브라우저: 고미 AI 버튼 → 실제 생성 호출 → 말풍선 출처/관계, 393px 설정 UI·모드 전환.
- Android: 고정된 llama.cpp 커밋으로 JNI 컴파일, APK 서명·기존 기기 업데이트 안전성 검사. **컴파일이나 mock 응답은 실기기 4B 추론 품질/속도 검증이 아니다**.
- 실제 휴대폰 A/B: 홈 첫 요청/동일 행동 재요청/다른 행동/다른 캐릭터 전환 각 5회 평균·p95, `promptTokens`, `cachedPromptTokens`, `promptMs`, `firstTokenMs`, `totalMs`, `rssPeakKiB`, LoRA 실제 적용·말투 검증. 최종 사용자 목표인 1초 이내 실제 생성은 달성 여부가 **미검증**이다.
- 4B CPU 실시간 생성의 1초 보장은 불가하다. 개선이 부족하면 Android GPU/NPU 오프로딩, 고미 학습 결과를 작은 모델에 지식 증류해 0.5~1.5B 온디바이스 추론, 또는 사용자 동의 하 PC/서버 추론을 별도 벤치마크 후 검토한다. 1초를 위해 모델을 몰래 다른 모델로 바꾸거나 구형 모델을 다시 자동 다운로드하지 않는다.
