## 2. 기존 캐릭터·호감도 재사용

- 기존 17종: 고미, 감자싹, 고구마싹, 사과싹, 귤싹, 은행싹, 동백싹, 목련싹, 해국싹, 포도싹, 배싹, 장미싹, 대추싹, 밤싹, 보리싹, 단감싹, 복숭아싹.
- 사용자가 고른 대표 캐릭터, 직접 지은 이름, 성장 단계, CharacterVisual과 기존 승인 리소스·모션을 재사용한다.
- 기존 다섯 호감도 경계 0·20·30·60·90을 유지하고 캐릭터마다 다섯 말투를 제공한다.
- 기능 설명 데이터와 말투 데이터를 분리하여 호감도나 캐릭터가 달라도 필요한 정보는 빠지지 않는다.
- 도움말 열람은 교감·호감도 증가를 저장하지 않는다.
- SQLite 스키마, 원본 사진, 이름·사진 연결, 인식 모델과 기존 성장 조건을 바꾸지 않았다.

이전·다음·건너뛰기·종료·현재/전체 단계를 제공한다. 배경은 inert 처리하여 밝힌 삭제·저장·탭도 기능을 실행하지 않는다. 종료 시 스크롤·포커스·입력·선택을 보존한다. 실제 요소 이동을 ResizeObserver·scroll·visualViewport로 추적하고 화면 밖 대상은 스크롤하며 사라진 대상은 건너뛴다. Escape와 앱의 Android 뒤로 가기 계층에서 도움말을 먼저 닫는다.

외부 AI·이미지 인식·네트워크·신규 제품 UI 라이브러리가 필요하지 않다. 사용자 요청 없이 새 도움말 투어를 시작하지 않는다.

전체 앱 CI가 모두 통과한 상태는 아니다. 남은 광범위 실패는 선택 작업, 지역·달력, 등록 해제/비동기 가져오기, 미확인 인물·반려동물 결과, 기존 브랜딩·배치·복구 시나리오에 포함된다. 같은 실패 시나리오가 기준에서도 있었다는 뜻이며 모든 실패의 내부 원인을 동일하다고 단정하지 않는다. 테스트·문서 전용 최종 커밋의 전체 CI 재실행은 별도다.

실제 확인한 버튼 동작:

- 도움말을 종료한 뒤 사진 제목 저장·다음 사진 이동·확대·배율 조절·닫기를 실행했다.
- 도움말 중 밝힌 삭제·탭을 눌러도 실행되지 않고, 화살표로 배경 사진이 바뀌지 않았다.
- 미확인 얼굴의 후보 변경·이름 저장, 반려동물 영역 취소, 선택·작성 중 일기 제목, 열린 메뉴를 보존했다.
- 앱 뒤로 가기로 도움말만 닫고 인물/반려동물 선택을 유지하는 네이티브 검사도 통과했다.
- 기본 갤러리 정렬·사진/동영상 다중 선택·권한 거부·취소·실제 가져오기, GPS 권한 복구 후 동일 ID/수정 보존, MP4 재생·탐색, 폴더 가져오기·앨범·달력, 일기 저장을 확인했다.
- 수동 인물 연결·미확인 이름 지정·반려동물 재분석 후 이름·연결·객체 ID를 보존했다.
- 오프라인 Worker·네이티브 저장, warm resume, 앱 재시작 후 SQLite·달력·분석 상태, Android 시스템 바와 뒤로 가기를 확인했다.
- 오프라인 실행·움직임 줄이기·키보드 트랩·포커스 복원을 검사했다. 인식 정확도나 물리 휴대폰 성능을 측정한 작업은 아니다.
