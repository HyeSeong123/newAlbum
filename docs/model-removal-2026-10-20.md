# 외부 사전학습 모델 제품 제거

2026-10-20 사용자가 남은 권리 불확실성에 대해 “말고 제거해줘”라고 요청했다. 기존 128차원 얼굴 인식과 기본 반려동물 인식을 유지한다는 이전 범위보다 이 지시를 우선한다.

현재 제품은 `manual-only-no-models`다. FaceAPI SSD·68점 랜드마크·128차원 인식, COCO-SSD/SSDLite 탐지, MobileNet 외형 특징, 고양이 얼굴 cascade, 기존 제외 FaceX512·QuadPose, TensorFlow/ONNX 추론 런타임과 Worker를 제품 배포에서 제외한다. 자동 얼굴/동물 찾기·후보 비교·재분석·분석 대기열 UI와 개발 평가 메뉴를 앱에서 제거했다. 사진 직접 등록·이름/사진 편집·기존 얼굴 기록 수동 이동/제외·앨범/내보내기는 유지한다.

제품 준비 스크립트는 가중치를 public/dist에 내려받거나 복사하지 않는다. 연구용 개발 의존성의 npm 설치 파일 자체에는 모델이 포함될 수 있으나 제품 번들·APK에는 포함하지 않는다. 준비 단계에서 생성된 public/models만 제거하고, 출시 검사는 public/dist 모델 자산·추론 Worker·런타임·모델 코드 재유입을 거부한다. 연구용 의존성은 devDependencies로 격리하며 사용자 앱 번들에는 포함하지 않는다. 명시적 `ai:research:prepare`만 .research/models에 가중치를 준비할 수 있고 public/dist에는 쓰지 않는다. 독립 자체 AI 연구 코드는 유지한다.

SQLite 스키마·마이그레이션·기존 사람/반려동물 ID·사진·수동 확인·과거 특징은 삭제하지 않는다. 과거 모델/권리 문서와 라이선스 고지도 증빙으로 남긴다. 기록을 보존하는 것이 모델을 배포하거나 추론에 사용하는 것은 아니다.

이 조치는 외부 사전학습 가중치를 제품에서 배포·실행하는 경로를 제거한다. 앱의 다른 라이브러리·이미지·개인정보 등 모든 권리에 대한 포괄적 법률 승인으로 표시하지 않는다. 기존 `commercialRightsVerified=false`는 유지한다. 이전 자동인식 APK는 이 변경이 반영된 파일이 아니며 새 빌드와 구분해야 한다.

저장소 현재 소스에 포함됐던 고양이 cascade 가중치 JSON도 삭제한다. 해시와 BSD 고지만 이력으로 보존하며 Git 과거 커밋은 재작성하지 않는다. 외부 모델 연구는 제품과 별개이고 권리가 확인된 private cascade를 .research에 직접 준비해야 한다. 제품에서는 연구 모듈을 import하지 않는다.

## 실제 검증

- [제품 소스 CI](https://github.com/HyeSeong123/newAlbum/actions/runs/39426921646): 단위146, Rust116, browser379 통과·81 제외. 로컬 Python22 통과. 제외81건은 PASS가 아니며, 폐지한 자동인식 UI 검사와 기존 플랫폼 조건을 포함한다. 자체 연구 Worker의 실행/중단 검사는 별도로 유지한다.
- [Windows0.9.12 설치/업데이트](https://github.com/HyeSeong123/newAlbum/actions/runs/39426914144): 실제 이전0.9.11 설치파일에 시험 기록을 넣고 full/update 설치 후 보존 확인 성공. 미디어·앨범·챕터·글·재생·WebView 시험 기록이며 실제 사용자 DB 전체 검증을 의미하지 않는다.
- ARM64 APK를 내려받아 ZIP 및 native library의 모델/Worker 경로 참조를 확인했다. 참조 검출0이며 public/dist 자산 검사·제품 module graph 검사와 함께 확인한다. 압축된 모든 자산을 독립적으로 역직렬화해 바이트 단위로 검사한 것은 아니다.
- 생성된 public/dist 모델0, 추론 Worker0, WASM/ONNX0. JS 전체는5,442,882→908,866bytes. 모델 제거에 따른 번들 변화이며 실행 속도 개선 측정은 아니다.
- Android 새 설치 검사는 갤러리 fixture 표시 단계에서 먼저 실패했다. 파일명 등록만으로 준비 완료를 판단하지 않게 하고 실제 권한 허용 UI로 검사하도록 보완해 재실행한다. 실패를 모델 제거/수동 등록 검증 통과로 바꾸지 않는다.
- 로컬 핵심 수동 동선28통과·6제외. 기존 이름/사진 ID/확인 기록을 유지하고 저장 실패 후 선택 보존, 재실행 복원, Worker/모델/분석 IPC 호출0을 확인했다. 로컬 전체 재실행은 완료 JSON이 남지 않아 통과로 세지 않으며 위 전체 CI 결과를 사용한다.

개별 해시·실행 범위·제한은 [검증 JSON](model-removal-0.9.12-evidence.json)을 따른다. 실제 ARM64 실기기·실제 사용자 DB·전체 접근성은 미검증이다. 현재 변경 리뷰는 승인하되 이를 앱 전체 권리·출시의 포괄적 승인으로 표시하지 않는다.

### Android 재검사 상태

- `39429654455` attempt1: 모델 제외 APK 빌드 성공, 갤러리 fixture 준비 조건에서60초 제한 실패. 저장된36개 항목을 동일 판정식으로 재평가하면 모두 적합했다. 정확한 원인 분리는 완료하지 않았으며 앱의 수동 등록 후반부 검사는 이 실행에서 도달하지 못했다.
- attempt2: SDK 준비 중 NDK28.2.13676358 다운로드가 `Error on ZipFile unknown archive`로 실패. 앱 빌드/실행 이전의 환경 오류다.
- 같은 소스/같은 APK 캐시로 마지막 재시도 중이다. 이 재시도 전까지 Android 통합 smoke는 FAIL/NOT TESTED 범위를 유지하며 ARM64 APK의 모델 경로 미포함 확인과 구분한다.
