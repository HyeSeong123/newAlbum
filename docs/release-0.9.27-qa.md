# 감자싹 0.9.27 회귀 검사 후속 수정

0.9.26 APK 설치 검사는 통과했지만, 추가 [전체 브라우저 검사](https://github.com/HyeSeong123/newAlbum/actions/runs/40140509490)는 595개 통과·44개 실패·65개 제외로 끝났다. 사용자의 확인 후 APK 전달 요청에 따라 실패 로그와 화면 캡처를 확인하고 후속 수정한다. 실패를 통과로 처리하거나 검사 조건을 건너뛰지 않는다.

## 실제 화면 수정

- 사진 상세 닫기 버튼: 모바일 전용 선택자의 우선순위 때문에 44px 규칙보다 작은 폭이 적용됐다. 닫기 버튼 선택자에 44px 터치 영역을 직접 보장한다.
- 사진 도구: 320px 캡처에서 세 열의 긴 버튼명이 넘쳤다. 420px 이하에서는 두 열로 배치하며 기존 버튼 검사에 내용 넘침 확인도 포함한다.
- 도움말 진입: 미확인 인물 목록의 마지막 ‘다음’ 버튼을 우측 하단 `?`가 가렸다. 고정 도움말 위치를 유지하면서 본문 끝에 스크롤 여백을 확보한다. 기존 페이지 이동·다중 선택 검사를 유지한다.
- 시작 화면: 갤러리 비교를 마친 뒤에도 등록 목록 응답을 기다리는 동안 앱을 잠그던 문제를 수정한다. 비교가 끝나면 잠금을 해제하고 목록은 이어서 읽는다. 앨범을 먼저 열어 지역을 수정한 뒤 늦은 목록 응답이 도착해도 수정이 유지되는 기존 검사를 그대로 사용한다.

## 검사 코드 정비

현재의 전체 메뉴·인물 관리·미확인 인물 확인·이름 지정 흐름과 실제 IPC에 맞춰 예전 버튼·팝업·목 데이터만 바꾼다. 원본 보존, 저장 실패 시 초안 유지, 저장 후 조회 실패 시 중복 쓰기 방지, 취소 후 선택 유지, 뒤로 가기와 이름 연결 검증은 유지한다. 고미의 대사 확장을 반영하되 직전 대사와 달라지는지 확인한다. 영상 미리보기 목 데이터와 실제 재생 스트림의 재시도 검사를 구별한다.

## 검증 기록

- 로컬: 프런트 단위 172개, TypeScript, Vite 빌드, 공백 오류 검사 통과. 기존 큰 청크 경고는 유지된다.
- 로컬 Chromium이 없어 실제 클릭·화면 비교는 원격 CI에서 재검사한다. APK는 0.9.27 소스와 기존 영구 서명을 사용한다.
- Android 에뮬레이터 설치 결과와 전체 브라우저 검사 결과는 완료 후 기록한다. 실물 휴대폰 검증과 실제 Windows 설치 검증은 별도다.

첫 재검사에서 도움말과 편의성 집중 검사는 통과했다. 화면 흐름은 328개 통과·1개 실패·31개 제외였으며, 실패는 세 열 고정을 요구하던 기존 검사였다. 430px에서는 세 열, 420px 이하에서는 두 열의 정렬·44px 터치 영역·텍스트 넘침을 확인하도록 맞췄다. 앱 소스와 실행 중인 APK 빌드는 추가 변경하지 않는다.
