# 공개 출시 방향 결정 — 2026-10-20

## 사용자 결정

사용자는 기존 모델의 공개 라이선스, 학습 자료 관련 잔여 쟁점, 스토어 심사와 권리 검토의 차이, 공개 문의 응답 상황을 설명받은 후 다음 방향을 선택했다.

> 그냥 올려보고 이슈있으면 이후에 대처하는 방향으로 가보자

이를 **남은 불확실성을 인지한 상태에서 출시 준비를 계속하고, 구체적인 문제가 제기되면 검토·수정하는 사업상 결정**으로 기록한다. 제작자의 새 이메일이나 GitHub 답변을 받는 일을 일률적인 출시 선행 조건으로 삼지 않는다. 외부 연락 발송 요청이나 모델별 추가 허가를 받은 사실로 해석하지 않는다.

## 적용 기준

- 확보한 MIT·Apache·CC0 및 모델 제작자의 공개 답변을 실제 사용 파일·버전과 연결해 보관한다. 필요한 라이선스·저작권·출처 고지를 배포물에 반영한다.
- 권리 확인 상태와 사용자의 출시 판단은 분리한다. 미확인 항목을 `commercialClearanceConfirmed=true` 또는 법률 검토 완료로 바꾸지 않는다.
- 구체적인 제한이나 권리 문제가 확인되면 해당 모델·기능·배포 버전을 기준으로 대응한다. 사용 중단·교체·수정 배포가 필요한지는 제기된 내용과 권한 범위를 확인해 결정한다.
- 사진·일기·앨범·등록 인물·반려동물·사용자 확인 연결은 대응 과정에서도 보존한다. 특징 추출 모델을 교체하면 기존 특징과 새 특징을 같은 공간으로 비교하지 않는다.
- 실제 학습이 완료되지 않은 자체 모델을 기존 인식 기능의 대체품으로 표시하지 않는다. 완전 자체 AI 개발 목표와 외부 모델을 사용하는 기존 앱의 출시 판단은 구분한다.

## 문제가 제기됐을 때

1. 문제를 제기한 주체, 대상 파일·모델·버전, 주장하는 권리와 제한 조건을 확인한다.
2. 당시 배포물, 파일 해시, 공개 라이선스, 고지와 관련 답변을 보존해 사실관계를 대조한다.
3. 확인된 문제 범위에 따라 기능·모델 수정이나 배포 조치를 진행하고 재검증한다. 필요한 경우 해당 쟁점의 전문 검토를 받는다.
4. 적용 버전과 조치 결과를 기록한다. 문제 제기만으로 사용자 사진이나 확인 연결을 삭제하지 않는다.

## 이 결정 시점의 기술 상태

- 앱 버전은 0.9.9다. 기존 안정 브랜치는 `feature/warm-journal-v2`, 이번 결정 기록은 `feature/gamjassak-native-ai`에 추가한다.
- 신규 자체 AI 브랜치의 기본 모드는 미학습 인식 기능을 비활성화한다. 이 브랜치를 그대로 빌드한 결과가 기존 얼굴 인식 기능을 제공한다고 간주하지 않는다.
- `scripts/native-ai/release-gate.mjs`는 자체 모델 승인·레거시 의존성·최종 배포물 검토를 이유로 상업 빌드를 차단하는 기존 구현이다. 이 문서를 추가하는 것만으로 해당 코드가 변경되거나 출시용 AAB가 생성되지는 않는다.
- 실제 출시용 구성·서명·광고 설정·스토어 등록 및 최종 배포물 검증은 아직 수행하지 않았다. 이번 결정은 제작자 답변 대기를 필수 조건으로 두지 않는 출시 준비 방향의 확정이다.

## 후속 범위 정정 — 0.9.11

사용자는 0.9.10 복구 결과에 대해 “512차원과 반려동물 관련 일부 내용은 권리 때문에 없어져야 하는거 아니었어?”라고 지적했다. 출시 준비 계속 결정을 모든 개발 가중치의 복구 허용으로 확대 해석한 부분을 정정한다.

현재 제품에서 FaceX tiny512와 QuadPose 및 해당 모델에만 필요한 ONNX 런타임은 제외한다. 128차원 얼굴 인식과 기본 반려동물 탐지·외형 비교·수동 등록을 유지한다. 과거 512 특징과 자세 기록은 DB에서 삭제하지 않지만 활성 비교와 자동 방향의 근거로 사용하지 않는다. 사용자 확인 연결과 수동 방향은 보존한다. 이 문서의 앞선 일반 출시 결정이 제외 모델을 재활성화할 근거는 아니다.

구현·검증 범위는 [0.9.11 정정 보고서](../rights-scope-correction-2026-10-20.md)와 `public/notices/ai-release-status.json`의 `activeModelProfile`·`correctionRecord`를 따른다. 이 범위 결정은 남은 모든 학습 데이터 권리가 최종 확인됐다는 의미가 아니다.
