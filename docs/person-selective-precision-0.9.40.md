# 선택적 얼굴 정밀 분석 0.9.40

기준은 `final`의 `4ec28696ee855887a2d5ae556234e1ae6ed16ef0`이다. 기존 PR #20은 병합하지 않았으며, 이번 변경은 별도 작업이다.

| 흐름 | 변경 전 | 변경 후 |
| --- | --- | --- |
| 처음 사진에서 사람 찾기 | 최대 1600px에서 한 번 탐색 | 그대로 유지, 추가 정밀 추론 없음 |
| 못 찾은 사진 다시 찾기 | 같은 방식으로 재실행 | 원본에서 겹치는 4개 구역을 순차 탐색하고 중복 얼굴 통합 |
| 정밀 분석의 불확실한 얼굴 | 축소본 특징 사용 | 최대 4개 얼굴 부분만 원본에서 다시 분석, 위치·특징이 모호하면 기존 결과 유지 |
| 분석 취소·실패 | 빈 얼굴 분석 기록을 먼저 삭제 | 기존 완료 기록을 보존하고 성공 후 갱신하여 다음 정밀 재시도 가능 |
| 여러 확인 기준 사진 | 최근 사진부터 최대 32장 | 확인한 방향별로 고르게 선택, 사진당 하나·인물당 32장 유지 |

기획자는 기존 버튼 이름과 위치를 유지하면서 추가 시간이 필요한 작업을 명시적 재시도로 제한했다. 사용자는 `못 찾은 사진 다시 찾기` → `놓친 얼굴을 정밀하게 찾는 중` → 중단 또는 결과 확인 흐름을 사용한다. 새 사진과 재시도 사진이 섞여도 새 사진은 기본 분석만 한다. 정밀 결과는 사용자 확인 대상으로 남기며 자동 연결 임계값을 넓히지 않는다.

FaceAPI 1.7.15·128차원·기존 학습 가중치, 원본·이름·기존 얼굴 연결·대표 사진·DB 구조·서명은 유지한다. 모델 학습이나 제거했던 FaceX512/QuadPose/전용 ONNX 재도입은 없다.

## 검증 기록

- 선택적 분석/좌표/중복/이웃 얼굴 방어/실패 전파 관련 Node 검사 11개 통과. 핵심 정밀 분석 검사는 미구현 상태의 실패 5개를 확인한 뒤 구현했다.
- 기존 전체 Node 검사 224개 중 223개 통과. `Android preview builds optimize inference kernels even when the APK variant is Debug` 한 건은 로컬 `cmake` 미설치(`spawnSync cmake ENOENT`)로 실행 실패했다.
- TypeScript 검사 통과. 초기 제품 번들 생성은 통과했으나 생성 자산의 미완성 복사본 때문에 배포 검사가 거부했다. 검사 자체를 완화하지 않고 생성 자산을 정리했다. 최종 TypeScript·Vite 번들·모델 자산/고지 검증과 버전 0.9.40 일치 검사는 통과했다.
- 독립 코드 검토에서 취소/실패 후 정밀 재시도 의도가 사라지는 문제를 발견했다. 기존 빈 분석 기록을 삭제하지 않는 방식으로 수정하고 모바일 버튼 검사 및 실제 Worker 검사를 추가했다. 최종 브라우저 검사 3개 통과·1개 조건별 생략: PC/모바일의 중단 → 실패 → 정밀 재시도와 새 사진 기본 모드, 기존 이름·완료 기록 보존을 확인했다. UI/IPC 복구 검사는 추론 경계를 fixture로 격리했고, 별도 실제 Worker 검사에서 원본 ImageBitmap 전달·사람 샘플 3얼굴 유지·개 샘플 오탐 0·정밀 모드 후 기본 모드 추가 탐색 0회를 확인했다. 기능 샘플 결과이며 독립 정확도 측정이 아니다.
- 로컬에 Cargo가 없어 Rust 후보·저장 회귀는 실행하지 못했다. PR CI에서 확인해야 한다. 코드 검토만으로 Rust 실행 통과라고 표시하지 않는다.

로컬 모바일 전후 화면을 캡처했다. 한글 시스템 폰트가 없는 환경이라 글꼴·줄바꿈의 시각 검증은 제한되며 실제 Android 화면 검증을 대신하지 않는다.

## 남은 확인

실제 Android 휴대폰 설치·속도·메모리·발열과 독립 인물 사진의 누락/오연결 전후 측정은 미검증이다. 테스트 샘플의 기능 검사를 인식 정확도 향상 수치로 바꾸지 않는다. 이 소스 변경으로 새 APK 배포나 상업 이용 권리 확인이 완료됐다는 뜻은 아니다.

앱을 내려도 계속 분석하는 기능은 사용자의 별도 가능 여부 문의다. 현재 WebView Worker의 실행 수명만으로 화면 꺼짐·OS 종료까지 보장하지 않는다. Android 포그라운드 서비스와 추론 작업 수명·알림·중단·대기열 복구의 추가 구현 및 실기기 검증이 필요하며 이번 변경에는 포함하지 않았다.
