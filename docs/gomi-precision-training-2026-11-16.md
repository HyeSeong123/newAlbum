# 고미의 무언 성향과 친한 사이 발화 재학습 · 0.9.57

사용자는 친하지 않은 고미가 대꾸 자체를 하지 않고 눈길과 자리를 피한다고 설명했다. 매번 차가운 말로 대답하는 방식과 구분한다. 추가 정밀 학습 후 커밋하고 APK 생성을 시작하되, 결과 확인은 다음 아침에 사용자가 하도록 요청했다.

## 구현 기준

- 정상 상태의 친밀도 60 미만에서는 홈의 기존 생성 전 차단 규칙을 유지한다. 무응답을 말투 학습만으로 보장하거나 AI 오류를 무응답으로 숨기지 않는다.
- PC 시험과 개발 평가도 홈과 같은 친밀도 기준을 쓴다. 추움·컨디션 저하 때 보호자에게 안아달라는 기존 원문과 PC의 명시적 상태 명령은 유지한다.
- 저친밀도 발화 자료를 원본 파일에서 삭제하지 않는다. 새 발화 코퍼스에서만 제외하며 빈 문자열이나 행동 지문을 대사인 것처럼 학습시키지 않는다.
- 친밀도 60 이상에서 교감·산책·간식·밥·쓰다듬기·놀이·휴식을 다듬는다. 차분한 자기주장을 유지하며 노골적인 핀잔을 보강하지 않는다. 졸리지만 먹으러 오는 경우와 극심한 피로로 계속 자는 경우를 구분한다.
- 사진·기록·캐릭터 ID·성장·친밀도 저장 규칙과 영구 서명을 보존한다.

## 실제 학습 입력과 절차

기존 자체 WordNet의 순전파·역전파·AdamW와 NumPy 행렬 연산으로 무작위 초기화부터 200 epoch 재학습한다. 외부 사전학습 가중치·LoRA·교사 API를 쓰지 않는다. GPU용 외부 모델로 교체한 작업이 아니다.

새 gomi-bonded-refinement.json은 AI 개발 도우미가 사용자 설명을 바탕으로 쓴 초안이며 사람의 원문이나 검토 완료 자료가 아니다. 상태별 432행을 3회 가중해 1,296행으로 사용한다. 모두 독립적인 발화라는 뜻이 아니다. 새 전체 코퍼스는 16,158행이다.

| 입력 | 행 수 |
| --- | ---: |
| 기존 사용자 원문 | 30 |
| 기존 고미의 발화 가능 상황 초안 | 1,872 |
| 고미 보강 초안(3회 반복 포함) | 1,296 |
| 기존 다른 캐릭터 초안 | 12,960 |

정상 저친밀도 발화 2,064행은 새 발화 코퍼스에서 제외했다. 원문과 이전 모델은 Git 이력에 남고 실행 전 모델·코퍼스·학습 보고서도 별도 로컬 기준본으로 복사했다.

## APK 교감 검사 보완

앞선 0.9.56은 APK 생성·서명을 마쳤지만 설치 후 간식 검사의 무언 반응 확인이 1초 제한으로 실패했다. 수면 터치 8회는 새 완료 번호와 추론 요청 0회로 완료됐다. 간식 이후에는 캐릭터 위쪽이 Android 고정 메뉴에 가려져 있었다.

검사기는 새 완료 번호 확인 후 캐릭터를 화면 가운데로 가져와 가림과 렌더링을 다시 확인한다. 실제 모바일 viewport·고정 헤더·클릭 직후 스크롤 이동으로 이전 실패를 재현하고 수정 뒤 통과를 확인했다. 무동작 버튼이나 이전의 조용한 상태를 성공으로 세지 않는다. 지연 기준을 낮추거나 무언 상태를 생성 대사로 계산하지 않는다.

## 검증과 배포

학습 완료 후 실제 가중치를 재로딩해 상황별 발화와 무언 정책, 반복·먹이/놀이 혼동·피로·역할 오류를 검사한다. 수학·데이터 계약 검사, 관련 Node 검사, 타입·빌드·에셋 검사를 수행한 뒤 결과를 기록한다. 개발 자료 검증은 독립적인 사람의 품질 승인이나 Android 실기기 성능 측정이 아니다.

사용자 요청에 따라 커밋 후 APK 빌드를 시작하는 단계에서 종료하며 해당 APK의 생성·설치 성공 확인은 다음 아침에 남긴다.

## 완료한 개발 검증

- 실제 200 epoch 학습은 377.4초에 완료됐다. 모델 449,148바이트, 185,738 parameter이며 SHA256은 `5baa8a22e68172e9cc0d251b792881da9741c4b8968c63e4420a11231ccbeee7`이다. training-result.json에 실제 시간·손실·입력·코드 해시가 남는다.
- 가중치 재로딩 후 287개 상황의 3,444건 검사: 발화 1,680건, 무언 1,764건, 생성 오류 0, 정의한 의미 오류 0. 무언 사례는 생성 대사나 발화 지연 표본에 포함하지 않았다.
- 별도 상태 조합 평가에서 발화 608건·무언 84건을 확인했다. 사용자 원문 30행과 다른 캐릭터 12,960행은 이전 코퍼스와 ID를 제외한 모든 내용을 비교해 일치했다. 상태 조합을 따로 뽑은 개발 평가이며 독립적인 언어 자료 평가는 아니다.
- Python 수학·학습 계약 6개, 관련 Node 검사 43개, 모바일 검사기 3개 통과. TypeScript·프로덕션 빌드·에셋 검사 통과. 실제 홈 코드와 저장 인터페이스를 사용한 브라우저 검사에서 새 모델 바이트와 일치하고 무언 교감 10회·추론 요청 0회를 확인했다. 이 실행의 저장은 브라우저용 모의 저장이며 Android 새 APK 설치 결과가 아니다.
- 개발 평가의 좁은 키워드 검사에서 올바른 ‘조금 더 자도 되지?’를 수면 의도로 인식하도록 보완했다. 같은 문장 뒤 ‘지금 먹으러 갈게’가 붙는 모순은 계속 거부한다. 임의의 모든 자연어에 대한 의미 이해를 보증하지 않는다.
- 별도 코드 검토에서 중대한 결함은 발견되지 않았다. 새 APK의 결과 확인은 사용자 요청대로 수행하지 않는다.
