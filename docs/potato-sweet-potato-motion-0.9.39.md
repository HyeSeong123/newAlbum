# 감자·고구마 홈 행동 확장 (0.9.39)

기준: `final` 0.9.38 / 사용자 요청: 감자·고구마가 단순히 찌그러지는 행동을 넘어 다양한 움직임을 보이게 한다.

## UX 검토
- 기획자: 이전 전신 애니메이션은 2~3px 흔들림·크기 변형으로 행동 의미를 파악하기 어려웠다. 감자는 호기심 많고 수줍은 동생, 고구마는 다정하고 장난기 많은 형의 리듬을 구분한다.
- 일반 사용자: 대표를 선택하고 홈에 돌아왔을 때 첫 자세, 터치 4번과 함께하기 5종이 서로 달라야 한다. 화면 이동/앱 배경 전환 후 동작이 남지 않고 원본 그림·친밀도는 유지한다.

## 구현
- `brothersMotion.ts`: 두 친구의 서로 다른 홈 자세 4종, 터치 4종, 함께 산책·햇살 선물·쓰다듬기·함께 놀기·함께 쉬기 궤적과 속도. 단순 scale 변형 대신 x/y 이동과 회전을 사용한다.
- `BrothersEffects.tsx`, `characters.css`: 의미에 맞는 작은 SVG 효과(발자국·햇살·하트·별·잠 표시), 안정적인 바닥 그림자. 승인을 받은 PNG와 기존 clipPath는 변경하지 않고 같은 DOM 노드에 남긴다.
- `companionBehavior.ts`: 감자/고구마만 전용 궤적을 사용한다. 고미와 다른 14종은 기존 정책대로 유지한다.
- `useCompanionBehavior.ts`: 동작 복귀 타이머를 DOM 반영 직후 설치하도록 조정한다.
- 화면 관련 변경은 홈 대표 친구에만 적용한다. 친구들 도감에서 그림 보기·이름 바꾸기·대표 설정은 교감으로 취급하지 않는다.
- 모델/DB/사진/앨범/일기/등록 인물·반려동물/신호/키·서명 정책은 그대로 유지한다.

## 검증 계획 및 실제 결과 구분
- 관련 순수 동작 검사: `tests/companion-behavior.test.mjs`에 감자/고구마 각각 5개 행동 궤적, 4개 터치, 감속 모드 정적 자세, 원본 변형 금지를 추가한다.
- 브라우저: `tests/characters.spec.ts`의 모바일/데스크톱에서 두 캐릭터 각각 4번 터치 및 5개 버튼, 시각 효과, portrait DOM 동일성, 친밀도, 가로 넘침을 확인하고 모바일 캡처를 저장한다.
- 0.9.38의 CI에서 캐릭터 복귀 타이머와 reduced-motion 테스트가 실패했으므로 이번 검증에서 함께 다시 확인한다.
- Android 에뮬레이터·실물 휴대폰·Windows는 실제 빌드 및 CI 결과 확인 전까지 통과로 기록하지 않는다. 새 코드의 테스트 성공 역시 실행 기록이 있어야만 통과로 표시한다.
