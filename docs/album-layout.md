# 앨범의 사진 비율별 배치

- 세로 사진(`height > width`): 한쪽 페이지에 4장, 2×2 배치.
- 가로 사진: 한쪽 페이지에 2장, 위아래 배치.
- 정사각형·크기 미확인·오디오: 한쪽 페이지에 최대 2장. 정사각형이 포함되면 좌우 배치.
- 세로 사진이 다른 방향의 사진 사이에 섞여 있어도 같은 방향끼리 모은다. 같은 방향 안에서는 원래 순서를 유지한다.
- 다음 페이지의 방향은 아직 표시하지 않은 사진 중 원래 순서가 가장 앞선 사진을 기준으로 고른다.
- 세로 사진이 4장이면 왼쪽 4장, 오른쪽 0장이다. 5장이면 4장+1장이다. 좌우 균형을 위해 완성된 4장 페이지를 다시 분할하지 않는다.
- 마지막 묶음이 부족할 때만 남은 사진을 표시하며, 빈칸을 채우려고 사진을 중복하지 않는다.

책으로 볼 때의 표시 순서만 조정한다. 저장된 앨범 순서와 사진 목록 보기의 순서는 변경하지 않는다. 원본 크기(`width`, `height`)를 재사용하므로 별도 방향 컬럼이나 DB 마이그레이션은 필요하지 않다. 제목·날짜와 `object-fit: contain`을 유지한다.

크기 메타데이터가 나중에 도착해 페이지 구성이 바뀌면 진행 중인 넘김을 취소하고 첫 펼침으로 이동한다. 제목이나 별점만 바뀔 때는 현재 펼침을 유지한다.

Windows 앱에서는 사진 등록 시 이미지 헤더와 EXIF 회전 정보를 읽어 표시 기준 너비·높이를 저장한다. 기존 라이브러리의 크기가 비어 있으면 목록을 불러올 때 백그라운드 작업에서 보완한다. 원본 파일과 기존 제목·별점은 변경하지 않는다. 읽을 수 없는 파일이나 현재 디코더가 지원하지 않는 형식은 크기 미확인 상태로 유지한다.
