# 고미 AI 말투·출처 확인 개선 (0.9.46)

기준: `final` 0.9.45 / 증상: 사용자에게 학습 전과 학습 후 대사의 체감 차이가 작다.

## 먼저 확인한 사실

- 0.9.45 앱의 고미 LoRA v4 적용은 실험용 4B 본체와 고미 요청에만 적용한다. 기존 1.7B에는 적용되지 않는다.
- 홈은 **기본 대사를 즉시 표시한 뒤** 모바일 AI 생성이 성공한 경우에만 교체한다. 렌더링만으로 대사 생성이 수행되지는 않는다.
- 앱 입력에는 터치·함께 산책·간식·쓰다듬기·놀이·휴식과 기분·친밀도·시간대만 있다. 외출, 귀가, 방문객, 추위, 실제 급식, 새벽 베개, 배변 사건을 인식하지 않는다.
- 기본 산책 대사의 '나가기 싫어', '한 바퀴만', '덜 귀찮아' 등은 사용자가 제공한 최신 고미 성격(산책을 좋아하지만 목줄을 피함)과 충돌한다.
- 0.9.45의 실측 WSL 모델 평가에서는 기본과 LoRA 적용의 logits 차이가 검증되었지만 대사 품질은 `qualityApproved=false`다. 단순히 어댑터를 켰다는 이유로 고미다운 말투를 보장하지 않는다.

## 기획자·실사용자 UX

- 기획자: 기본 대사와 AI 생성 결과의 출처를 구별해야 실제 모델 개선 여부를 판단할 수 있다. 설정에서 '4B 설치'와 'LoRA 적용됨'을 같은 뜻으로 사용하면 안 된다.
- 일반 사용자: 고미를 터치했을 때 바로 표시된 기본 대사를 AI 학습 결과로 오해하기 쉽다. 모델이 느리거나 실패해도 홈 버튼은 즉시 반응해야 하며, 로딩 문구·화면 깜박임을 반복해서는 안 된다.
- Android: 말풍선 상단의 작고 고정된 출처 표시만 사용한다. 텍스트 높이·버튼 위치와 원본 그림은 변경하지 않고, 학습 성공 여부는 AI 반응 설정에서 최근 실행 기록으로 확인한다.

## 구현 사항

1. `companionTouch.ts`: 고미 프롬프트를 '한숨, 귀찮음' 중심에서 당당한 요구·애착·행동 의도 중심으로 보강. 각 버튼의 의미를 구분하고 앱이 관측하지 않은 생활 상황을 지어내지 않게 함. 다른 캐릭터 프롬프트는 유지.
2. `companionActivities.ts`/`companionFallback.ts`: 기본 산책 대사와 반복 뒷말을 최신 고미 성격과 일치시킴. 화면상 가상의 활동일 뿐 실제 GPS 산책을 주장하지 않음. 다른 캐릭터와 수면 중 반응은 기존 규칙 유지.
3. `HomeView.tsx`/`home.css`: 고미 말풍선의 기존 `data-source`에 따라 조용히 '기본 대사' / 'AI가 만든 말'을 표시. 새 비동기 작업이나 반복 로딩 상태 없음.
4. `CompanionAiSetup.tsx`: 고미 설정에서 1.7B에는 학습 적용이 안 됨을 명시. 4B의 준비와 최근 고미 응답에 v4가 실제 적용된 기록을 구분. 생성 실패 시 기본 대사를 보여준 상태도 구분.
5. 모델의 가중치, LoRA 파일, 본체 해시, 모델 다운로드, 서명키, Android 앱 ID, 사진/SQLite/일기/앨범/인물/반려동물 데이터는 변경하지 않음.

## 검증 방법과 제한

- 관련 Node 테스트: `tests/companion-touch.test.mjs`, `tests/companion-activities.test.mjs`, `tests/companion-fallback.test.mjs`. 프롬프트/5개 버튼/수면 분기/기본 산책 성격을 검증.
- 브라우저: `tests/companion-chat.spec.ts` 모바일 폭 393px에서 기본→AI 반응 표시, 1.7B에는 학습 미적용, 4B 최근 적용 표시와 캡처 확인. 기존 버튼·말풍선 안정성 회귀.
- 프런트 타입/빌드·동결 모델 자산/버전·APK는 GitHub Actions에서 검증 결과를 별도로 확인한다.
- **미검증/유의:** 사용자 실제 휴대폰에서 학습 어댑터 로딩 성공 여부와 응답 시간은 별도 실기기 검증이 필요하다. 프롬프트 변경은 가중치를 다시 학습한 것이 아니므로 0.9.45 v4 학습 당시 프롬프트와 다르다. 실제 4B 텍스트 생성의 성격 품질 향상은 동일 문항의 학습 전/후 새 생성 평가 없이 합격이라고 하지 않는다.
- 새 모델/새 학습이라고 홍보하지 않는다. 사용자 개인 대화나 사진/일기를 모델에 자동 제공하지 않는다.
