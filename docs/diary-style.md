# 종이 일기장과 앨범 목록 (2026-09-28)

승인한 PAPER DIARY 시안을 기존 그루터기 앱에 적용한다. 일기 목록은 날짜·날씨·기분·본문·첨부 사진을 종이 카드에 표시하고, 작성창은 줄노트와 사진 인화지 형태를 사용한다. 기존 공통 메뉴와 작은 글자 크기를 유지한다.

## 사진 저장

- 일기당 최대 6장. 추가 전 남은 장수를 검사하고 같은 사진 ID는 중복 첨부하지 않는다. 추가·삭제·장수 표시, 저장 실패 시 초안 유지.
- 데스크톱은 기존 미디어 등록 경로를 재사용한다. SQLite v4의 `diary_photo`가 일기와 미디어 ID, 표시 순서를 연결한다. 일기 본문과 첨부 관계를 한 트랜잭션으로 저장한다.
- 일기 또는 첨부를 삭제해도 원본 파일이나 미디어 등록을 삭제하지 않는다. 미디어를 등록 해제하면 해당 첨부 관계만 함께 해제한다.
- 브라우저 미리보기는 사진 data URL과 일기를 IndexedDB에 저장한다. 기존 localStorage 일기는 처음 읽고 다음 저장 때 이전하며 원래 localStorage 값은 백업으로 남겨 둔다. 저장 완료 전에 화면 목록을 갱신하지 않는다.
- JPG/JPEG, PNG, WebP, HEIC를 기존 지원 형식에 맞춰 선택할 수 있다. 실제 디코딩이 지원되지 않거나 원본이 이동된 경우에는 사진을 불러올 수 없다는 대체 표시를 제공한다.

## 앨범 목록

표지 사진을 자르지 않고 인화지 카드 안에 표시한다. 제목 옆 `⋯` 메뉴에 앨범 수정·내보내기·삭제를 배치한다. 목록의 ‘책으로 보기’ 배지와 별도 수정/더 보기 행은 제거했다. 앨범 내부의 책장·사진 목록·스토리 기능은 유지한다.

## 자산과 검증

- `public/textures/diary-paper.webp`, `diary-tape.webp`: 이 작업에서 생성한 종이/테이프 텍스처. 본문이나 버튼을 이미지에 포함하지 않는다.
- Noto Serif KR 400/500: `@fontsource/noto-serif-kr` 패키지로 로컬 번들에 포함. 오프라인 실행 시 외부 글꼴 요청이 필요 없다. 패키지의 SIL Open Font License를 따른다.
- 브라우저 사진 저장·6장 제한·기존 일기 이전: `tests/diary-photos.spec.ts`.
- 첨부 순서·6장 제한·잘못된 첨부의 원자적 거절·원본 보존·v3 마이그레이션: `src-tauri/src/diary.rs` 테스트.
