# 0.9.27 홈 캐릭터 활동·AI 연결 기반

기준: final (8010c1f). 이 변경은 버전을 올리지 않으며 0.9.27의 기존 APK를 수정한 것이 아니다.

## 기획자·사용자 관점
- 변경 전: 캐릭터 누르기만 가능해 반복 대사로 수렴한다. 17종 성격은 이미 정의되어 있지만 홈 행동은 공통 클릭 하나였다.
- 변경 후: 홈의 대표 친구에게만 '함께하기' 버튼이 표시되고, 펼치면 산책·선물·쓰다듬기·놀이·쉬기를 선택한다. 선택 후 성격별 말풍선·기분·표정 반응이 바뀐다.
- 식물에게 음식을 주는 표현을 피하기 위해 '햇살 선물'로 바꾸었다. 실제 위치 추적이나 소비되는 아이템은 없다.

## 데이터와 AI 아키텍처
- 새 `companionActivities.ts`: 기존 17종 정의를 사용한 활동 5종, 호감도별 고미 반응, 기분·활력(0~5), 최근 행동 12개 저장 및 최근 행동을 반영한 1~2문장 프롬프트.
- `companionLlm.ts`: 향후 Android 온디바이스 추론 모듈을 주입하는 비동기 인터페이스와 오류·모델 부재 시 로컬 대사 복귀. **이번 변경에는 실제 llama.cpp/JNI 추론 실행기, Qwen 가중치, 모델 다운로드 기능이 포함되지 않는다. 현재 UI 대사는 오프라인 규칙 기반이다.**
- 기존 SQLite 스키마에 손대지 않으며, 별도 `gamjassak:companion:v1:<characterId>` localStorage에 행동 12개를 저장한다. 저장 실패 시 같은 세션에서는 동작한다. 이전 SQLite 데이터, 원본 사진, 서명 설정은 불변이다.
- 기존 캐릭터 누르기는 이전처럼 하루 한 번만 친밀도를 올린다. 추가 행동 버튼은 친밀도·성장에 영향을 주지 않는다. 고미는 직접 누른 경우 기존 수면 방해 반응을 그대로 유지한다.
- 사진 인식 AI는 홈 화면으로 돌아와도 백그라운드에서 실행할 수 있으므로, 추론기는 Android 기기 검증 후 별도로 연결해야 한다.

## 필요한 다음 검증
- 단위: 17종×5활동, 고미 호감도 차이, 저장·손상 복구, 로컬 모델 부재 fallback.
- Android 모바일: 320/393px 버튼 길이·접기, 말풍선·캐릭터 겹침, 스크롤, 접근성, 앱 종료·재진입 저장.
- 미검증: 네이티브 모델 로딩·8GB 실기기 메모리/지연/발열, Play 배포 용량, 실제 사용자 연구.
