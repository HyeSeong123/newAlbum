# 고미의 낮은 친밀도 무언 반응

사용자의 최신 설명: 친하지 않은 고미는 상대를 피해 다니고 눈을 잘 맞추지 않으며, 대꾸 자체를 하지 않는다. 매번 차가운 말로 응답하는 것은 이 성격과 다르다.

기존의 친한 사이 기준인 친밀도 60을 그대로 사용한다. 60 미만의 홈 교감과 함께하기에서는 AI 대사를 요청하지 않고 말풍선도 표시하지 않는다. 표정은 혼내거나 화내는 인상 대신 중립적으로 시선을 피하는 원화와 작은 회피 움직임으로 표현한다. 60 이상은 기존 AI 교감과 앞발·핥기 친밀도 규칙을 유지한다. 수면 방해의 눈 뜨기·화난 반응과 저장 규칙은 유지한다.

무언 반응도 기존 홈 교감으로 저장하며 하루 한 번 친밀도 상승은 유지한다. 저장 결과의 친밀도를 기준으로 말할지 판단하므로 59에서 60이 되는 교감은 새 관계에 맞게 AI 대사를 요청한다. 저장 실패를 무응답 성격으로 숨기지 않는다. 도움말 기능은 항상 제공하며 낮은 구간의 불필요한 핀잔은 중립적인 짧은 안내로 바꾼다.

AI 가중치나 사용자 학습 원본을 삭제·재작성하지 않는다. 이번 수정은 무응답 의사를 AI 생성 실패와 분리하고, 실제 홈 호출 정책과 그림을 바로잡는 작업이다. 기존 캐릭터 ID·이름·호감도·성장 기록·서명 설정은 보존한다.

## 구현·검증 계획

- 실패하는 검사: 60 미만의 고미를 터치해도 정상 AI Worker로 요청이 전달되지 않으며 무언 상태가 표시된다. 다른 캐릭터의 AI 반응은 유지한다.
- 저장된 59→60 경계에서는 AI에 60이 전달되고 정상 응답한다. 무언 터치도 저장 횟수를 추가하지 않는다.
- 시선 회피 원화를 별도 PNG로 추가하고 기존 그림은 보존한다. 움직임 줄이기에서는 회피 자세만 유지한다.
- 도움말·수면·친밀도 경계 및 원화 로드, 모바일 홈을 확인하고 관련 단위·타입·빌드를 검증한다.
- 검증한 변경을 final에 커밋하고 새 APK 자동 빌드 상태와 다운로드를 확인한다.

## 변경·검증 결과

- `HomeView`는 저장된 친밀도가 60 미만이면 AI Worker를 호출하기 전에 무언 반응으로 완료한다. 무언 상태는 말풍선과 오류 안내를 띄우지 않으며, 화면 읽기 도구에는 상태 설명을 제공한다.
- 홈 진입 때 뽑은 원래 자세는 별도로 보존한다. 59→60에서 원래 자세가 드러나고, 다음 친밀한 반응 후에도 그 자세로 복귀한다. 친밀도 변경으로 수면이나 홈 자세를 다시 뽑지 않는다.
- 무언 응답의 완료 번호는 저장 완료 후에만 바뀐다. APK 검사도 새로운 완료 번호와 실제 화면 렌더링을 기다리므로 이미 조용한 화면의 무동작 버튼을 성공으로 계산하지 않는다.
- 관련 단위 검사 49개, 모바일 브라우저 검사 41개, TypeScript·프로덕션 빌드·배포 에셋 검증 통과. 실제 홈과 저장 인터페이스를 사용하는 브라우저 검사에서도 수면 터치 8회와 간식 2회가 새 무언 응답으로 완료됐고 추론 요청은 0회였다. 회피 이동은 좌우 14px로 확인했다. 이 브라우저 결과는 Android 실기기 성능 측정이 아니다.
- 전체 로컬 단위 검사는 287개 중 280개 통과, 3개 건너뜀, 기존 환경 문제 4개 실패(Java/Javac 없음 3개, Windows 심볼릭 링크 권한 1개). 서명·모델·학습 원본은 변경하지 않았다.

## 원화

`public/characters/gomi/avoid.png`는 기존 `idle.png`를 참조해 ImageGen으로 만든 별도 1254×1254 투명 PNG다. 요청 방향은 기존 강아지의 체형·귀·무늬·색연필 질감을 유지하고 고개와 시선만 옆으로 돌리는 중립적인 회피 자세이며, 화난 눈썹·찌푸림·위협적인 표정을 넣지 않는 것이다. 기존 원화는 덮어쓰지 않는다.

앱 버전은 0.9.56이다. APK 서명과 설치·교감 검사는 기존 Android preview 워크플로에서 수행한다.
