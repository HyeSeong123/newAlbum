# 0.9.7 반려동물 사진 찾기와 갤러리 선택

- 반려동물 목록과 상세 화면에 ‘등록된 사진에서 찾기’를 배치했다. 연결한 사진을 먼저 인식 기준으로 등록하고 전체 등록 사진을 같은 영구 분석 대기열에 넣는다. 이미 분석한 사진은 버전·사진 지문이 같으면 결과를 재사용한다.
- 찾은 사진은 동물 영역과 이름, ‘사진 연결’ 버튼으로 표시한다. 여러 동물이 나온 사진은 개체별로 구분하고 다른 개체의 확인 내용을 덮어쓰지 않는다. 유사 후보는 자동으로 연결하지 않는다.
- ‘인식 기준·결과 확인’ 메뉴와 해당 복잡한 모달, 모달에 딸린 검증 자료·기기 성능 측정 화면을 제거했다. 필요할 때 사진 상세에서 개체 연결을 수정할 수 있다. 설정의 고급 평가 기능과 개발용 측정 스크립트는 유지한다.
- 연결 사진이 없는 반려동물은 기준 사진을 먼저 연결하도록 안내한다. 저장 실패 시 후보가 남아 재시도할 수 있다.
- Android 갤러리는 기본 GridView가 길게 누르기로 판정한 뒤에만 드래그 선택을 시작한다. 일반 스와이프는 기본 스크롤을 그대로 사용한다. 선택된 사진을 길게 누르면 드래그로 해제한다. 같은 사진은 한 제스처에서 한 번만 처리하며 가장자리 자동 스크롤, 터치 취소·다중 터치 정리, 기존 500개 제한을 적용했다.
- 선택 표시만 갱신해 불필요한 썸네일 작업 취소·재시작을 줄였다. 분석 대기열은 100개씩 읽고 현재 사진 목록을 재사용한다. 이름만 수정할 때는 기준 사진을 다시 분석하지 않는다.

검증: 로컬 TypeScript 빌드, 단위 검사 126개 통과. 브라우저와 설치형 Android 검사는 CI 결과 확인 후 기록한다.

개체 식별 정확도와 실제 ARM64 휴대폰 성능 수치가 새로 검증된 것은 아니다.
